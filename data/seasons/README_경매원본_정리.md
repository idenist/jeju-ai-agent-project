# 제주 감귤 경매 원본 데이터 · 4개 시즌

이 ZIP을 프로젝트 루트(C:\SKN projects\jeju, app.py가 있는 폴더)에 **압축 해제**하면
`data/seasons/<시즌>/raw/` 아래에 수집 당시 CSV가 그대로 배치됩니다.

- 2023-2024: 2023년 10월 ~ 2024년 2월 (1개 CSV, 원래 파일명 `source_01.csv`)
- 2024-2025: 2024년 10월 ~ 2025년 2월 (5개 CSV)
- 2025-2026: 2025년 10월 ~ 2026년 2월 (5개 CSV)
- 2026-2027: 2026년 10월 ~ 11월 13일 (2개 CSV; 진행 중인 부분 시즌)

### 포함 범위
**경매 원본 CSV만 수록합니다.** `data/processed`의 운영 데이터 및 이미 저장소에 존재하는
`data/seasons/2024-2025/`·`2025-2026/` 가공 CSV는 변경하지 않습니다.
이 ZIP을 푼 것만으로 Agent가 4개 시즌을 자동으로 조회하는 것은 아닙니다.

### Git 추적
동봉된 `data/seasons/.gitignore`는 각 시즌의 raw/ 폴더만 Git에서 제외합니다.
가공 데이터 파일·보고서·시즌별 코드의 추적을 막지 않습니다.

### 주의
기존 `data/seasons/2024-2025/보고서/시즌통합_검증.json` 등의 원본 파일 경로가
`artifacts/...`로 기록된 것은 이 ZIP에서 변경하지 않았습니다.
원본을 옮긴 후에는 해당 검증 명세의 source_file 경로를 정리해야
`scripts/run_auction_pipeline.py --season all`을 새 위치만으로 재현할 수 있습니다.
기존 가공본을 덮어쓰지 않기 위해 검증 보고서는 이번 압축에서 제외했습니다.

파일별 SHA-256과 크기는 `경매원본_파일목록.json`에 기록했습니다.
