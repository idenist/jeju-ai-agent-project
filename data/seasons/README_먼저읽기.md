# 제주 감귤 팀 공용 시즌 데이터 V2 — 사용 안내

**기준일:** 2026-11-13 | **자료 작성:** seunghyuk 브랜치 개인 데이터 실험에서 선별한 팀 인수본

## 압축 해제 위치

이 ZIP은 **프로젝트 루트(`app.py`가 있는 폴더)** 에 풀어주세요. ZIP 내부에 `data/seasons/` 경로가 포함되어 있으므로 폴더가 없어도 압축 해제하면서 생성됩니다. Windows 탐색기에서 압축을 푼다면 '대상 폴더'를 프로젝트 루트로 지정하고 ZIP 이름의 추가 폴더 안에 풀리지 않게 주의하세요.

```text
<프로젝트 루트>/
├─ app.py
└─ data/
   ├─ raw/                  # 기존 자료: 변경하지 않음
   ├─ processed/            # 기존 Agent 자료: 변경하지 않음
   └─ seasons/              # 신규 팀 공유 자료
      ├─ 2024-2025/         # 시즌1 가공가격·가격쌍 및 검증 보고서
      ├─ 2025-2026/         # 시즌2 가공가격·가격쌍 및 검증 보고서
      ├─ prediction_v2/     # train·validation·partial_evaluation CSV 및 계약
      ├─ analysis/          # 공통규격 품질 분석
      ├─ README_먼저읽기.md
      └─ 파일_해시_검증.json
```

**중요:** `data/seasons/`는 `.gitignore`의 `artifacts/`와 달리 Git에 추적 가능한 팀 공용 경로입니다. 단, 압축 해제만으로 자동 커밋되지는 않습니다. **공식 저장소에 반영하려면 팀 합의 후** `data/seasons/`만 선택적으로 `git add`하고, 용량·이용 조건·검증 결과를 확인해야 합니다. 팀원마다 ZIP을 중복 커밋하지 마세요.

## 사용 원칙

1. **기존 `data/raw/`, `data/processed/`, `data/reports/`, `data/metadata/`는 수정하지 않습니다.** 현재 Agent의 기본 CSV 경로는 그대로이며, `data/seasons/`를 자동 조회하지 않습니다. 서비스 반영에는 별도 경로 연결·원천/가격쌍 해시 검증·회귀 테스트가 필요합니다.
2. `2024-2025/`와 `2025-2026/`의 `daily_prices.csv`·`price_comparisons.csv`·`price_comparison_availability.csv`·해당 보고서는 **동일 시즌 묶음**으로 취급합니다. 서로 다른 시즌의 가격·가격쌍을 섞지 마세요.
3. `prediction_v2/2024-2025_train.csv`는 학습, `2025-2026_validation.csv`는 검증, `2026-2027_partial_evaluation.csv`는 **미완성 시즌의 잠정 평가** 자료입니다. 파일에는 정답(`target_price_kg`)이 들어 있으므로 모델 입력으로 사용하면 안 됩니다. 모델 입력은 `prediction_v2/데이터계약_v2.json`의 `model_input_fields`만 사용하세요.
4. **2026년 잠정 평가 자료는 이미 탐색한 데이터**입니다. 완전한 미공개 평가 결과로 주장하거나 반복 튜닝에 사용하지 마세요.
5. 경매가격의 날짜는 거래 정산일이며 실제 농가 출하일이 아닙니다. 경락가격은 농가 실수취액도 미래 가격 예측값도 아닙니다.
6. 품종코드 `08`→황금향은 거래명에 근거한 잠정 매핑입니다. `07`, `09`, `99` 등 미확정 품종 코드를 임의로 재해석하거나 합치지 마세요.
7. 정답쌍은 3·7·14일 후 **정확히 같은 규격의 경고 없는 관측값**이 있는 경우에만 존재합니다. 결측은 보간하지 않으며 서로 겹치는 날짜쌍은 독립 표본이 아닙니다.
8. `파일_해시_검증.json`의 `files` 항목은 `data/seasons/` **내부를 기준**으로 한 상대 경로의 SHA-256입니다. 파일 이름 변경이나 재가공 시 해당 파일과 명세를 함께 검증하세요.
9. ZIP에는 원본 API 응답·개인 캐시·API 키·`.env`가 들어 있지 않습니다. 추가 원천 수집이나 재처리는 별도로 협의해야 합니다.

## 팀원별 사용

- 과거 가격 분석 담당: `2024-2025/`, `2025-2026/`의 동일규격 가격·가격쌍
- 모델 담당: `prediction_v2/`의 데이터계약과 train·validation 자료
- Agent·UI 담당: 신규 자료 형식과 품질 보고서 확인 후 별도 연동 설계

**이 자료는 인수용으로 검증된 가공 데이터이며, 현재 Agent의 기능·실서비스 예측 성능을 검증했다는 뜻은 아닙니다.**
