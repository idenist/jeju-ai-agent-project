# 제주 감귤 시즌별 경매가격 자료

각 시즌 폴더에 일별·품종별 가격, 동일 규격 가격쌍과 품질 보고서가 있습니다.
앱의 여러 시즌 경락가 조회와 손익분기 단가 비교는 각 폴더의 `daily_prices.csv`를 사용합니다.
기본 가격쌍 조회는 `data/processed/`를 사용하며, 시즌별 가격쌍은 `python -m scripts.check_season_scenarios`에서 점검합니다.

- 2026–2027 시즌은 일부 관측 기간만 포함합니다. 없는 날짜와 거래 규격은 추정하지 않습니다.
- 일자는 경매 정산일입니다. 경락가는 수수료 차감 전 가격이며 농가 실수취액이나 미래가격이 아닙니다.
- 다른 시즌·규격의 자료를 결합하거나, 잠정 품종코드 매핑(`08` → 황금향)을 다른 코드에 적용하지 않습니다.
- [인수 파일 해시](파일_해시_검증.json)는 2024–2025 및 2025–2026 시즌의 인수 당시 가공본과 보고서에 적용됩니다.
  원천 CSV 관리 방법은 [경매원본 정리](README_경매원본_정리.md)를 참고하세요.
