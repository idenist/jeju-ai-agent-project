# 감귤 저장 문헌·시험 기록

이 폴더의 CSV는 공개 문헌·기술자료에서 확인한 과거 시험 기록을 보존한다. 현재 농가의 감모율 예측 데이터셋은 아니다.

- `citrus_storage_reference.csv`: 1994-1995 흥진조생 표, 1998년 제주 홍진조생 저장시험, 1999년 제주 궁천조생 연구, 2020년 중국 후난성 상온시험의 공개 요약값을 모았다. 1998년 시험은 90일 결과와 실험조건은 있지만 예조를 포함한 과거 단일 시험이고 7·14일 로트 원자료가 없다. 2020년 시험은 10~40일 관측이 있지만 25℃ 실험실 조건으로 제주 농가 저장과 다르다. 어떤 행도 일반 농가의 예측값을 뜻하지 않는다.
- `citrus_quality_storage_reference.csv`: 2002년 눈 맞은 과실의 5~30일 부패율·품질 표. 중량감소율이 아니며 특수한 수확 전 조건이다.
- 두 파일 모두 `training_eligible=false`다. 모델의 학습·검증, 기본 감모율, 예측 사전값에 사용하지 않는다.
- 권장 예조 감량은 저장 중 감모 관측과 다른 항목이므로 이 파일의 관측값으로 섞지 않았다.
- 논문·자료에 수치가 없는 필드는 빈칸으로 둔다. 빈칸을 0으로 해석하지 않는다.

기후 변화 근거, 각 출처의 한계, 현장 자료 확보 계획은 [미래가격·감모율 예측 데이터 확보 및 실행 계획](../../docs/17_미래가격_감모율_예측_데이터확보_실행계획.md)에 기록했다.
