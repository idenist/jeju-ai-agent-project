# 감귤 경락가격 전망 1차 모델 실험

실행일: 2026-11-17  
상태: **연구용 후보 · 일반 Agent 미연결**

## 실행한 모델

`experiments/train_price_forecast.py`로 2024-2025 시즌 학습 자료에서 Ridge, HistGradientBoosting, ExtraTrees 후보를 학습하고 2025-2026 시즌에서 선택했습니다. 2026-2027 부분 자료는 모델 선택에 넣지 않고 진단용으로만 평가했습니다.

학습·평가 자료는 시장·품종·등급·크기·포장 규격별로 묶인 경락가격입니다. 모델은 기준일 가격과 최근 거래·가격 흐름, 계절 위치를 사용해 기준일 대비 3·7·14일 뒤 가격 변화를 추정합니다. 농가 실수취가나 손익 자체를 예측하지 않습니다.

선택된 모델은 세 간격 모두 HistGradientBoostingRegressor입니다. 결과 산출물은 Git에서 제외되는 `artifacts/seunghyuk/price_forecast_v1/20261117_001022_247784/`에 저장됐습니다. 재현 환경은 [requirements-forecast.txt](../requirements-forecast.txt)로 고정했습니다.

## 검증 시즌 결과

MAE는 대상일 경락가격과의 평균 절대 오차이며 단위는 원/kg입니다.

| 예측 간격 | 모델 MAE | 현재가 유지 | 단순 최근 7일 평균 | 해석 |
|---:|---:|---:|---:|---|
| 3일 | 412.85 | 427.33 | 447.03 | 두 기준선보다 낮은 오차. 제한된 후보로 계속 평가할 가치가 있음 |
| 7일 | 529.40 | 542.03 | 498.59 | 현재가 유지보다는 낮지만, 더 단순한 7일 평균보다 나쁨 |
| 14일 | 595.44 | 580.52 | 560.95 | 두 기준선보다 나쁨. 예측에 사용하지 않음 |

모델 선택 코드는 현재가 유지 기준만 비교했지만, 별도 기준선 평가에는 단순 7일 평균도 있습니다. 따라서 7일 모델을 단순 기준선보다 나은 모델로 채택하지 않습니다. 운영 판단에서 기준선 비교를 빠뜨리지 않도록 학습 파이프라인을 보완해야 합니다.
