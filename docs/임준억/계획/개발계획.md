# 제주 감귤 Agent MVP 개발계획

기준일 2026-11-09 KST / 개인 브랜치 dev/juneok / 공통 main 28e8af97 기반. 개인 개발·검증 계획이며 팀 최종 채택·통합 일정과 구분합니다. 이전 계획은 날짜별 작업기록에 보존합니다.

## 목표와 적용 조건

출하일을 조정할 수 있고 실제 제시가격·비용을 확인할 수 있는 감귤 농가 또는 출하 담당자가 즉시 출하와 보관 후 출하의 필요한 가격 조건·가정·실행 제약을 비교합니다. 미래가격 예측·최적 출하일·수익 개선을 입증한 자동 권고로 표시하지 않습니다.

일반 사용자는 준비된 CSV로 바로 시작합니다. 대화로 아는 값을 제공하고 같은 조건 카드에서 확인·수정한 뒤 결과·출처·미확인 조건을 읽고 PDF를 저장합니다. CSV 교체와 키/설치·진단은 별도 관리 과업입니다. 과거 #855와 시장 경락가격을 현재 공급·농가 실수취가격으로 혼동하지 않게 합니다.

## UI 논의 전 4단계 계획 점검

| 원래 단계 | 이번 작업 후 판단 | 남는 과업 |
| --- | --- | --- |
| 1. CSV 입력·자료 확인 | 지원 경매 원본에 대해 구현·검증 | 다른 센터 명세/#855 교체/가공본은 자동 지원하지 않음. 필요시 별도 어댑터 |
| 2. 조건 확인·수정·설명 | 공유 상태·미리보기/PDF로 보완 | 실제 사용자의 이해도는 미검증. 새 UI를 최종 선호로 확정하지 않음 |
| 3. 변경 기능·공개 사양 검증 | 새 환경·모델 교차·PDF·독립 검토 실행 | 최종 이동 ZIP의 해시·폰트·doctor·139개·공개 사양/PDF 통과. 실제 장비 접근을 대기 조건으로 추가하지 않음 |
| 4. 팀 공유·실행·제출 준비 | 로컬 인수 후보·매뉴얼·시연 자료 준비. 팀 인수는 미실시 | 팀 채택/충돌점·설명자료·시연·인수·공식 제출물 검수 |

UI 개선이 팀 통합·제출 준비 완료를 대신하지 않습니다. 구현·모델·PDF·패키지 검증 결과는 검증 보고서에서 각각 구분합니다.

최신 보고서 보완: [서식과 이용 안내](../검증/2026-11-09_보고서서식과이용안내.md). 상단 문구 제거·하단 안내 통합·문서/표 번호를 반영했고139개/8페이지를 확인했습니다. 다음 과업 순서는 유지합니다.

## 인수 준비 상태와 다음 과업

1. **로컬 자료 준비 완료 / 팀 인수 미실시:** 공통 코드/CSV와 개인 기여를 구분하고 기존 팀 기반과 Agent·도구 계약·모델·출처·실행 방식을 대조합니다. 완료기준은 팀이 읽고 실행·비교할 수 있는 안내와 충돌/선택 사항 목록입니다. 채택·원격 반영은 팀 결정을 대신하지 않습니다.
2. **매뉴얼·시연 대본·자동 재생 준비 완료 / 사람 리허설 미실시:** 대화→카드 수정→가정 범위→PDF, 자료 없음·API 실패·잘못된 CSV 복구를 보여줍니다. 완료기준은 예시 조건과 실제 CSV 관측의 구분, 동일 조건으로 재현 가능한 단계·결과·한계입니다.
3. **다음 제작 과업 — 기획서·결과 설명자료:** 문제·필수 데이터 활용·Agent 자율 수행/도구·센터 실행·평가 증거·검증 한계·개인 기여를 설명합니다. 최신 공식 제출 규정·형식·필수 항목과 대조하고 비밀정보가 없는지 확인합니다.
4. **최종 통합 후 제출 후보 고정:** 팀 통합에서 바뀐 범위만 추가 검증하고 ZIP·설치·문서·시연을 함께 고정합니다. 외부 제출·push·PR·병합은 이 로컬 구현 완료와 구분합니다.

사용자가 요청한 검증 루프의 종료기준은 치명/주요 회귀 미해결0, 동일 상태/철회/기간 재확인/낡은 출력 차단, 화면·PDF 수치/버전 일치, 새 환경·이동 실행 재현입니다. 사람 검증이 없는 사실은 결과에 계속 명시합니다.

## 유지 기준과 범위 밖

- 단일 Agent+Python 하네스·계산·검증을 유지하고, 화면은 Streamlit입니다. 프레임워크 전환을 추가하지 않습니다.
- 검증 모델은 기존 gpt-6-luna입니다. 실제 호출은 제품 .env/OS 설정을 따릅니다. 키를 브라우저·문서·ZIP에 포함하지 않습니다.
- 데이터 조회는 로컬 CSV입니다. DATA_GO_KR_KEY는 운영자의 사전 수집용이며 센터 조회·카드·PDF에는 필요하지 않습니다.
- #855는 2018-01-01~2025-09-17 과거자료입니다. 품종·시장·단위·기간을 임의 매핑하거나 미관측을0으로 채우지 않습니다.
- PDF는 배포한 한글 글꼴과 고정 의존성으로 생성합니다. 미리보기와 PDF는 LLM 재작성 없이 같은 결과를 사용합니다.
- 개인 문서는 docs/임준억의 한글명으로, 기록은 [작성기준](../작업기록/작성기준.md)으로 관리합니다. 커밋은 제목→변경 불릿→필요시 맥락 형식입니다.
- 다품종/다른 농작물 범용화·생애주기는 [확장방향](확장방향.md)에 보존합니다. 모델 학습·미래가격 예측·다중 Agent·자동 거래·새 DB/클라우드는 현재 필수 범위가 아닙니다.
