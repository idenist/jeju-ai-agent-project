2026년 11월 9일 제품 개발 위치를 고정했고, 같은 날 개인 문서를 제품 docs/임준억 아래로 통합했습니다. 루트 docs에는 위치 안내만 둡니다.

제품 의존성 설치·실행·Git 작업은 jeju-ai-agent-project 안에서만 수행합니다. .review의 사본을 수정해 제품으로 사용하지 않습니다. 기존 발표자료와 검증 경로는 보존해 과거 증거 링크가 깨지지 않도록 합니다.

현재 개인 브랜치는 dev/juneok입니다. 원격 push·PR·팀 브랜치 병합은 이번 로컬 구현과 별개입니다. 개인 기능은 agents/juneok에 배치하고 공통 원본·전처리는 보존합니다. 제품 폴더 밖에는 가상환경, .env, 실행 로그, 임시 제품 소스를 만들지 않습니다.

개인 문서의 단일 위치는 docs/임준억이며 루트에 같은 계획 사본을 유지하지 않습니다. 기존 영문 이름은 [이동 대조표](../작업기록/문서이동대조표.md)에서 현재 위치를 확인합니다.
