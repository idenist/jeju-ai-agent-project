# 하네스 외부 레퍼런스 검토

최신 우선순위는 [센터·챌린지·팀 기준 재검토](센터와팀기준의하네스재검토.md)를 따릅니다. 아래 내용은 기술 가능성과 당시 권고의 이력입니다.
확인일 2026-11-09 KST. 사용자는 외부 조사가 유의미하면 진행해 보고하고, 의미가 적다면 기존 후속 과업을 진행하도록 요청했습니다. 이번에는 공식·개발사 1차 자료를 현재 로컬 하네스와 대조하는 제한된 조사가 유의미하다고 판단했습니다. 코드·SDK 교체·유료 모델 재호출은 하지 않았습니다.

## 결론

현재 단일 Agent + Python 하네스·공유 상태·계산/CSV 도구 구조를 유지합니다. 새 프레임워크·다중 Agent·클라우드 tracing 도입의 필요성은 이번 검토에서 입증되지 않았습니다. 보완 가치는 실패 분류·반복 감지·사용자 표현 중심 반복 평가·실행 기록 정규화에 있습니다. 아래 우선순위는 자료와 코드에 근거한 프로젝트 권고이며 외부 문서의 의무사항이 아닙니다.

## 기존 성과를 유지할 검증 기준

- 계산·CSV·공유 상태·PDF·JSON과 기존 회귀 162개를 유지합니다. 이번 조사는 검사를 재실행한 결과가 아닙니다.
- 새 검사에는 모의 타임아웃·동일 잘못된 호출 반복·인수 수정 복구·부분 결과 보존·서로 다른 사용자 턴을 포함합니다.
- 자연어 평가에는 기간 변경/감모 재확인, 단가 철회, 실제 감모 미확인+명시적 가정, 미관측 브리핑, 저장 복원 후 재질문 등을 넣습니다.
- 결과에는 전체 과업 완료와 일부 도구 성공을 구분합니다. 임의 가격/감모 생성·품종 자동 매핑·출처 없는 권고는 실패입니다.
- 실제 모델 반복 평가는 호출 수·토큰·시간과 시행 수를 함께 남깁니다. 3회 반복의 모두 성공이 실제 서비스 성공확률 추정을 뜻하지는 않습니다.

권고 순서는 실패 분류/반복 감지 보완 → 사용자 표현 중심 핵심 반복 평가 → 기록 정리·기존 회귀 확인 → 개인 확장 원격 반영 준비입니다. 데이터 이용조건·라이선스·시연 검수는 병행 가능한 기존 후속 과업이며, 팀 대표 구성·통합은 중간발표 이후 합의 항목으로 유지합니다. 이번 검토로 추가 보완이 구현 완료됐다고 표시하지 않습니다.
