# 제주 감귤 출하 검토 Agent 기획서

임준억 개인 구현 후보 / 2026-11-09 KST / 중간발표·팀 검토용 초안

## 서비스 개요

출하일을 조정할 수 있는 감귤 농가·출하 담당자가 현재 제시가격, 보관기간, 비용, 감모 가정을 확인하고 즉시 출하와 보관 후 출하의 필요한 가격 조건을 비교하는 서비스입니다. 제주데이터허브 #855 과거 출하통계와 확보한 경매 CSV를 참고자료로 함께 검토합니다.

핵심 흐름은 조건 확인 → 자료 조회 → 대안·가정 비교 → 판단 조건 설명 → PDF 공유 → 비교 건 저장·복원입니다. 단일 Agent가 허용된 도구를 선택하고, 계산과 수치 설명은 Python 도구가 담당합니다.

추가 구현은 실제 거래규격 탐색/선택, 제안단가에서 허용 감모·보관비 역산, 저장한 비교와 현재 조건의 변경 검토입니다. 같은 상태·계산·보고서 경로를 사용하며 품종/가격 자동대입·조건 자동복원은 하지 않습니다.

현재 구현·자동 검증은 완료한 범위와 증거로 제시합니다. 농가 실증·수익 효과·팀 채택·실제 센터 장비 실행은 미검증 또는 미합의입니다. 이 문서는 팀 최종 기획서나 제출 완료본이 아닙니다.

공식 기준은 [대회 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)를 2026-11-09에 확인했습니다. 기획서 15페이지 이내의 구현목표·서비스 제안·Agent 구성·데이터 활용·개발 및 탑재 계획을 이 문서에 대응했습니다.

## 1. 문제 정의와 구현목표

지금 팔지 보관할지 비교하려면 제시가격뿐 아니라 수수료, 별도 비용, 보관비와 기간 전체 감모를 같은 기준으로 계산해야 합니다. 이때 과거 시세를 미래가격으로 오해하거나 포함 비용을 이중 차감할 수 있습니다. 이는 해결하려는 업무 가설이며 농가 인터뷰로 빈도·중요도를 측정한 결과는 아닙니다.

구현목표는 미래가격을 맞히는 것이 아니라 사용자가 제공한 조건에서 기다리려면 필요한 최소단가와 지정 가정별 비교금액을 재현 가능하게 제공하는 것입니다.

| 사용자 과업 | 제공 기능 | 제한 |
| --- | --- | --- |
| 아는 조건으로 비교 | 대화·조건 카드의 공유 상태 | 모르는 값을 자동 생성하지 않음 |
| 자료와 함께 검토 | #855·선택적 동일규격 경매·계산의 브리핑 | 분류·기간을 임의 연결하지 않음 |
| 결과가 바뀌는 조건 확인 | 지정한 감모·미래단가 조합의 설명 | 예측·확률·최적 추천 없음 |
| 재방문·공유 | PDF·JSON 저장과 명시적 복원 | 계정·DB·자동 거래 없음 |

실제 제시가격·감모·비용이 없으면 부족한 입력으로 안내하거나 사용자가 정한 가정으로 비교합니다. 저장시설·계약·납기·출하일 변경 가능성은 경제성 계산과 별도로 확인합니다.

## 2. 서비스 제안과 사용자 흐름

준비한 CSV를 배포하므로 일반 사용자가 먼저 자료를 수집할 필요가 없습니다. 키가 있으면 자연어로 조건을 제공하고, 없으면 같은 조건 카드를 직접 사용합니다.

1. 물량·가격 기준·이미 포함된 비용·보관기간·기간 전체 감모·하루 보관비를 확인합니다.
2. 계산 도구가 필요한 최소단가를 산출합니다. 조건 수정 중 이전 결과·다운로드는 숨깁니다.
3. 출하통계의 품종·월·연도를 명시적으로 선택해 브리핑합니다. 시장 참고는 규격을 확인한 경우에만 선택합니다.
4. 사용자가 정한 감모·미래단가 목록으로 가정 비교와 판단 조건 설명을 받습니다.
5. 조건·출처·미확인 사항을 PDF로 공유하고 JSON으로 저장합니다.
6. 저장 파일을 확인한 뒤 복원하면 현재 세션 조건으로 다시 계산합니다. 당시 결과는 현재 결과로 실행하지 않습니다.

CSV 추가는 자료 관리자의 선택적 과업입니다. 원본 형식 검사 → 유효 관측·제외 내역 확인 → 명시적 적용을 거칩니다. 일반 사용자의 비교 여정과 구분합니다.

농가의 반복 사용 의향·입력 부담 감소·화면 친숙함은 사람 검증 전입니다. 현재는 자동 UI 과업과 시나리오로 동작을 확인했습니다.

## 3. Agent 구성과 자율 수행 범위

사용자 → Streamlit 대화/카드 → 단일 AgentSession·ScenarioStore → 허용된 Python 도구 → 검증된 결과·미리보기/PDF의 구조입니다. 대화와 카드가 서로 다른 조건을 만들지 않습니다.

| 구성 | 역할 |
| --- | --- |
| 모델 | 한국어 요청 해석·누락 확인·허용 도구 선택·인수 구성 |
| 하네스 | 버전 검사·원자 갱신·철회·도구 반복/시간 제한·오류 복구·종료 |
| 계산 도구 | Decimal 비용·감모·손익분기·가정 조합·판단 조건 계산 |
| 자료 도구 | 출처·품종·기간·규격이 명시된 CSV 조회 |
| 보고서 | 같은 Python 결과의 수치·출처·가정·부분 실패 표시 |

브리핑은 build_review_brief 도구로 비교·명시한 출하통계·선택적 시장 참고·민감도·판단 조건을 묶습니다. 요청 항목이 누락·미관측·오류이면 부분 검토로 남깁니다. explain_decision_conditions는 지정 조합의 금액 차이를 분류하며 상태를 바꾸지 않습니다.

하네스는 API/내부 오류·반복/예산 초과를 구분합니다. 동일 무진전 호출은 2회 뒤 차단하고, 최대 4턴·input 32,000자 안에서 최신 조건과 이번 비교의 조회조건·가정·미확인 항목을 제공합니다. 보관기간 변경은 이전 가정 목록을 무효화합니다. JSON v2에 맥락을 저장하며 v1 읽기를 유지합니다. 사용자 장기 프로필은 후속 후보입니다.

모델은 입력값을 추측하거나 경락가격을 농가 제시가격으로 대입하지 않습니다. 저장 파일은 임의 코드를 실행하지 않고 검증·복원합니다. 실행 거래·계약·자동 데이터 학습은 하지 않습니다.

설정 모델은 gpt-6-luna로 실제 연결을 검증했습니다. Responses API의 strict 함수 스키마와 프로그램 측 인수 검사를 사용합니다. [OpenAI 공식 도구 호출 문서](https://developers.openai.com/api/docs/guides/function-calling)

## 4. 데이터 활용과 전처리

| 자료 | 활용 항목·범위 | 처리·해석 |
| --- | --- | --- |
| 제주데이터허브 #855 신고소별 감귤류 및 만감류 출하량 통계 | 날짜·품종·신고소별 물량, 2018-01-01~2025-09-17 | 신고소 합산·일/월 집계·관측일 수·부분월·날짜 누락 기록 |
| 전국 공영도매시장 경매원천정보 API 수집 CSV | 거래일·시장·품종·등급·크기·포장·중량·금액 | 유효 경매만 선별, 규격별 총금액/총중량으로 원/kg 계산 |
| 사용자 입력 | 실제 제시가격 또는 가정·비용·감모·실행 제약 | 관측자료와 구분해 상태·변경 이력 보존 |

#855는 필수 데이터 활용입니다. 브리핑에서 선택 월의 연도별 물량과 관측 범위·경고를 제공하며, 원자료가 없는 기간을 0으로 채우지 않습니다. 기존 도구의 요약은 부분월을 제외합니다. 이것만으로 당해 수급이나 가격 인과관계를 주장하지 않습니다.

Git 공통 경매 CSV는 2026-10-01~11-03, 현재 인수 스냅샷은 조회범위 11-08까지 중 실제 마지막 유효 관측 11-06입니다. 실행 시 선택 자료의 관측기간을 표시합니다. #855와 가격자료의 시기가 달라 동시점 상관분석으로 표현하지 않습니다.

원본·공통 전처리를 보존하고 메타데이터 해시와 별도 활성 가격 버전을 관리합니다. 경매 품종과 출하 품종은 자동 매핑하지 않습니다.

출처: [제주데이터허브 #855](https://jejudatahub.net/data/view/data/855), [경매원천정보 API](https://www.data.go.kr/data/15141810/openapi.do). 경매는 공식 ‘이용허락범위 제한 없음’ 표시를 확인했습니다. #855의 개별 이용·재배포 범위는 미확인입니다. Python49개 공지97개와 글꼴 OFL을 동봉하며 팀 외부 코드 추가 때 재검수합니다.

## 5. 개발·탑재 계획과 외부 의존성

Python 3.13·Streamlit·OpenAI SDK·python-dotenv·requests·reportlab·pypdf를 사용합니다. requirements-juneok.lock에 설치 버전을 고정하고 setup-center.cmd와 run-juneok.cmd를 제공합니다. 정확한 목록은 lock 파일을 기준으로 합니다.

| 과업 | 필요한 외부 의존성 |
| --- | --- |
| 최초 설치 | Python·패키지 저장소 접근·설치/파일 쓰기 권한 |
| 자연어 Agent | OPENAI_API_KEY·설정 모델 접근·외부 HTTPS |
| 카드·CSV·브리핑·판단 설명·JSON·PDF | 설치 후 로컬 CSV·파일·글꼴. 모델 키 없이 직접 사용 가능 |
| 운영자의 선택적 경매 수집 | DATA_GO_KR_KEY·공공데이터포털 API |

.env는 실행자가 로컬에 작성합니다. 코드·ZIP·영상에 키를 넣지 않습니다. OS 환경변수가 제품 .env보다 우선합니다. 코드 기본값과 배포 예시는 gpt-6-luna이며 모델 설정이 없거나 비어 있으면 이 값을 사용합니다.

공식 최소사양은 i7-8700·GTX 1060·RAM 32GB입니다. 로컬 Windows 11/Python 3.13 새 환경·단일 논리 CPU 조건에서 CSV·UI·PDF 공개 사양 검증을 수행했습니다. GPU 로컬 모델을 요구하지 않으며, 특정 CPU/GPU 실물에서 실행했다는 주장은 아닙니다. 실제 센터 계정·네트워크·설치 권한은 미확인입니다.

한글 PDF는 Nanum Gothic TTF와 SIL OFL 1.1을 동봉해 인터넷·OS 글꼴 없이 생성합니다. 파일 출처·해시는 assets/fonts/SOURCE.json에 기록합니다.

## 6. 실행 결과와 검증 계획

가상 예시 3,000kg·수수료 차감 후 3,000원/kg·7일·감모 2%·하루 보관비 20,000원에서 남는 물량은 2,940kg, 추가 보관비는 140,000원, 필요한 원 단위 최소단가는 3,109원/kg입니다. 감모를 4%로 바꾸면 3,174원/kg이며 다른 조건은 유지합니다.

감모 1/2/4%와 미래단가 3,000/3,300원/kg의 6조합에서 3,300원/kg 가정의 지금 대비 차이는 각각 661,000/562,000/364,000원입니다. 지정 조합의 계산이며 발생 확률이나 권고가 아닙니다. 2025년 11월 #855는 관측 없음으로 남깁니다.

| 검증 | 증거와 한계 |
| --- | --- |
| 기존 회귀 | 확장 전 140개 통과. 데이터·계산·상태·UI/PDF·오류 포함 |
| 신규 검사 | 추가 22개 통과. 브리핑·미관측/오류·JSON 변조/복원·경계·업로드·PDF |
| 전체·배포 | 탐색·역산·변경 검토 포함226개 전체 통과. 분리 판정은 handoff-package/latest.json 기준 |
| 실제 모델 | 확장 4개 대화·4회 요청에서 9개 기준 통과. 원시 결과와 소스 해시 보존 |
| 기존 모델 회귀 | 25개 기능 확인. 최종21건+연결 오류4건 재시도, 동일 소스/자료 대조. existing-functional-verdict.json 참조 |
| 한국어 맥락 반복 | 6종×3회 18/18. 과거 턴 제거·철회·기간 재확인·미관측/가정 유지 |
| 신규 제품 과업 | 8종×3회24회. 실제 규격·상한 경계·가격 누락·변경 검토와 파일 누락 검사. 최종 실행별 판정 별도 보존 |
| 사람 검증 | 농가·비전문가 0명. 이해도·효과·만족도·소요시간 미측정 |

기능 실패가 발견되면 수정 → 관련 검사 → 전체 회귀 → 분리 패키지 재현 순서로 검증합니다. 자동 검사·AI 보조 검토를 사람 실증으로 표시하지 않습니다.

## 7. 센터 활용·기여·후속 계획

센터에서는 설치·자료 갱신을 담당자가 수행하고, 이용자는 배포 CSV와 직접 조건 비교로 시작합니다. 필요한 경우 모델 계정으로 자연어를 사용합니다. PDF로 검토 내용을 공유하고 JSON을 로컬에 보관해 다음 방문에 이어갈 수 있습니다. 농가별 계정·개인정보 DB는 없습니다.

공통 자산은 main의 원본/가공 CSV·수집/전처리와 기존 출처 안내입니다. 임준억은 격리된 agents/juneok 하네스·상태·비교·근거/브리핑·JSON·UI/PDF·검증·문서를 구현했습니다. 팀원 선행 검산 참고는 도구 계약에 기록했습니다. ChatGPT/Codex는 설계 검토·코드/문서 작성·검사 보조에 사용했으며 사람이 최종 검토해야 합니다.
