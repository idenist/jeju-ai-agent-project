# 제주 감귤 출하 의사결정 지원 Agent · 결과 설명

이 문서는 11월 18일 로컬 검수 후보의 실행 범위와 시연 결과를 설명합니다. 제출 파일은 검수 기록의 Git 커밋과 데이터 해시로 식별합니다.

## 해결하려는 질문

출하를 늦출 때 판매할 수 있는 물량과 보관 비용이 달라집니다. 감귤 농가나 출하 담당자가 가능한 날짜·실제 제시 단가·비용을 말하면, 앱은 두 선택지의 비교금액과 나중 출하에 필요한 최소 단가를 계산합니다. 과거 경락가격과 과거 신고 출하량은 각 자료의 관측기간과 함께 참고로 제시합니다.

## Agent와 분석 도구

| 구간 | 담당 | 확인할 결과 |
| --- | --- | --- |
| 질문과 조건 | `gpt-6-luna`, 자연어 도구 호출 및 기존 조건 확인 | 짧은 답도 직전 질문과 연결하고 빠진 금액과 단위를 확인 |
| 근거와 계산 | Python의 로컬 CSV 조회, A/B 비교, 출하량 조회 | 같은 거래규격과 날짜의 근거, 보관·감모·비용을 적용한 비교금액 |
| 화면과 파일 | Streamlit, 보고서 생성기 | 비교 결론과 출처, PDF, 결과 기록 JSON |
| 운영 경로 | Windows의 Python 3.13과 잠긴 의존성 | 키를 설정하면 대화 가능, 직접 비교·CSV 조회·PDF는 키 없이 이용 |

출하 예약, 계약, 판매는 사용자가 합니다. 입력한 값과 과거 관측자료는 화면에서 구분합니다. 조회·계산 도구는 알 수 없는 감모율이나 비용을 임의로 채우지 않습니다.

## 기획서와 같은 시연 사례

1. **직접 입력 → 두 출하일 비교**를 엽니다. 비교 물량 3,000kg, 보관 시작일 2026-11-17, 수수료 차감 후로 입력합니다.
2. A안 3일·3,000원/kg·감모 2%, B안 10일·3,300원/kg·감모 5%를 입력합니다. 전체 물량 하루 보관비는 두 안 모두 20,000원, 별도 비용은 각각 0원으로 입력합니다.
3. 비교금액과 손익분기 단가를 확인하고 PDF를 저장합니다. 대화에서는 같은 비교 결과를 다시 요청할 수 있습니다.

| 항목 | 시연 가정으로 계산한 값 |
| --- | ---: |
| 11/20 출하 A안 | 8,760,000원 |
| 11/27 출하 B안 | 9,205,000원 |
| B안과 A안의 차액 | +445,000원 |
| B안이 A안과 같거나 높아지는 최소 정수 단가 | 3,144원/kg |

계산은 판매 가능량에 단가를 곱하고, 기간 전체 보관비와 별도 비용을 뺍니다. 이 예시는 수수료 차감 후 단가를 사용해 수수료를 추가로 빼지 않습니다. 사용자가 입력한 가정의 결과이며 농가의 실제 수익은 거래와 정산 후 확인합니다.

### 함께 보여줄 경로

- **대화 → 가능한 다음 단계** · 11/23부터 11/30까지 출하할 수 있으나 단가를 모르면, 품종을 확인해 두 날짜의 과거 출하량을 조회할 수 있습니다. PDF를 열어 관측 연도와 품종을 확인합니다.
- **과거 경락가격 → 자료 없음 → 직접 단가** · 지원하지 않는 출하일 간격에서는 가격을 대신 채우지 않고 사용자가 B안 단가를 넣을 수 있게 안내합니다. B안만 바뀌면 A안 가격을 유지합니다.
- **보고서 재요청** · “방금 비교 보고서로 줘”와 “과거 출하량 PDF로 줘”는 각각 유효한 비교·출하량 보고서를 찾습니다. 비교 조건이 바뀐 뒤에는 다시 계산합니다. 화면의 두 출하일 비교 JSON은 결과 기록용입니다. 일반 비교는 사이드바에서 저장한 비교 파일로 조건을 다시 불러올 수 있습니다.

## 검증 범위와 센터 사용

- 검산은 Python 계산 경로, 실제 모델 대화, Chromium에서 파일 내려받기 순으로 확인합니다. 자동 테스트 수치와 변경 전후 차이, 재현 사례는 함께 전달하는 로컬 검수 기록을 기준으로 봅니다.
- 센터 운영자는 압축을 푼 Windows 폴더에서 `setup-center.cmd`와 `run-juneok.cmd`를 실행합니다. 평가용 OpenAI 연결은 평가 담당자가 설정합니다. 이 PC에서 압축 해제본을 검증했으며 실제 센터 PC와 농가 대상 사용성은 추가 확인이 필요합니다.
- 기본 A/B 경락가격은 **2026-10-01~11-03** 파일을 사용합니다. 2026~27 다년도 자료는 **2026-10-01~11-13**까지로 별도입니다. 제주데이터허브 #855 신고 출하량은 **2018-01-01~2025-09-17** 유효 날짜가 있는 로컬 스냅샷입니다. 이 범위로 2025년 11월 실적을 제시할 수 없습니다.
- 과거 사례 수는 가격 상승 확률로 사용하지 않습니다. 미래가격 예측 모델은 현재 시연 화면에 연결돼 있지 않습니다.
- 제출할 CSV 버전과 #855 원본·가공본의 동봉 범위는 팀 확인 사항입니다. [데이터 활용 명세](데이터활용명세.md) · [공식 제출 기준](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)
