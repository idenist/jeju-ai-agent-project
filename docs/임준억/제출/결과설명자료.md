## 2. 구조와 Agent의 역할

모델은 사용자 요청을 해석하고 허용 도구를 선택합니다. Python 하네스는 원자 상태 갱신·조건 버전·철회·기간 변경 감모 재확인·도구 종료·호출 횟수/시간 제한·오류 복구를 담당합니다. 모델의 자유 문장은 검증된 계산·시장 수치를 대체하지 않습니다.

build_review_brief는 저장 조건을 바꾸지 않고 비교·출하통계·선택 시장·민감도·판단 설명을 호출합니다. 각 구성 결과를 유지하고 하나라도 누락·미관측·오류이면 PARTIAL로 표시합니다. 함수 자체가 성공했다는 OK와 검토가 완전하다는 COMPLETE는 구분합니다.

explain_decision_conditions는 Decimal 계산 결과에서 HIGHER/LOWER/EQUAL/PRICE_UNKNOWN을 산출합니다. 지정 목록 사이 값을 보간하거나 확률·최적 대안을 만들지 않습니다. 실행 가능성은 금액과 별도로 표시합니다.

JSON v2는 조건·가정 구분·이력·자료 버전·당시 결과와 이번 검토의 조회조건/미확인 항목을 저장합니다. v1 읽기는 유지합니다. 복원 결과를 명령으로 실행하지 않고 현재 자료로 재계산합니다. SHA-256은 변경 검사이며 작성자 인증이 아닙니다.

API/내부 오류와 반복/예산 초과를 구분하고 같은 무진전 호출은 2회 뒤 차단합니다. 기본 4턴·input 32,000자 안에서 완결 턴을 제거하고 최신 조건/과업 맥락을 제공합니다. 기간 변경은 이전 가정 목록을 무효화합니다. 장기 사용자 프로필은 후속 후보입니다.

모델 gpt-6-luna·Responses API, Python 3.13·Streamlit·고정 lock·배포 글꼴을 사용합니다. 조건 카드·로컬 CSV·브리핑·PDF·JSON은 키 없이 직접 실행됩니다. 자연어는 외부 API·계정이 필요합니다.

## 3. 재현 가능한 실행 예시

| 과업 | 조건·관찰값 | 판정 |
| --- | --- | --- |
| 기본 비교 | 3,000kg·3,000원/kg·7일·감모 2%·보관비 20,000원/일 | 남는 물량 2,940kg·보관비 140,000원·최소 3,109원/kg |
| 카드 수정 | 감모 4%만 수정 | 최소 3,174원/kg·물량/현재단가 보존 |
| 가정 비교 | 감모 1/2/4% × 미래단가 3,000/3,300 | 6조합·최소단가 범위 3,078~3,174원/kg |
| 조건 설명 | 미래 3,300원/kg 조합 | 차이 661,000 / 562,000 / 364,000원, 실행 제약 별도 |
| 과거 자료 | 노지온주 2018~2024년 11월 | 실제 과거 관측 7개 연도 |
| 미관측 | 노지온주 2025년 11월 | NO_DATA·부분 검토, 0톤으로 채우지 않음 |
| 저장/복원 | JSON 저장 후 물량 수정·확인·복원 | 확인만으로 무변경, 복원 후 원래 조건 재계산 |

경제성 수치는 실제 농가 사례가 아니라 독립 검산용 가상 조건입니다. #855 조회는 동봉한 실제 과거 CSV입니다. 현재 관측과 사용자 입력·가정을 같은 사실로 취급하지 않습니다.

확장 예시 생성: python -m scripts.prepare_juneok_review_demo. 확장시연자료/의 PDF·MD·JSON·비교복원예시.json을 확인합니다. 실제 사람의 시연 소요시간은 측정하지 않았습니다.

## 4. 검증 방법과 실패·수정 이력

확장 전 140개 회귀가 기준선입니다. 이번 신규 검사는 브리핑 정상/미관측/입력누락/자료오류, 조건 보존, 구버전 결과 차단, 판단 경계·실행 제약, JSON 형식/용량/해시/비정상 입력, 명시적 복원·UI/PDF를 다룹니다. 추가 22개가 통과했습니다.

초기 신규 검사에서 브리핑 모듈 구문 오류를 발견해 수정했습니다. 전체 160개 첫 실행에서는 기존 UI 검사 2개가 다운로드 버튼 수를 2개로 고정해 실패했습니다. JSON 추가가 의도된 변경이므로 PDF·MD·JSON의 실제 항목을 확인하도록 수정한 뒤 전체 160개가 통과했습니다. 이후 자료 오류·업로드 복원 검사를 2개 추가했습니다. 최종 전체 수와 분리 ZIP 판정은 최신 검증 JSON을 기준으로 합니다.

실제 모델 확장 검증은 4개 대화·4회 요청에서 9개 기준이 통과했습니다. 브리핑 도구 선택·7개 연도·6조합·조건 유지·미관측 부분 결과·판단 설명·복원 후 3,109·요청 완료·최종 상태 보존을 확인했습니다. 실제 모델 결과는 소스 해시와 함께 artifacts/extensions-live/latest.json에서 연결합니다.

최신 회귀는 기존188+신규38개 총226개, 신규8종×3회24/24·맥락18/18입니다. 마지막 기존25종은21건 성공·연결 오류4건 재시도 성공으로 existing-functional-verdict.json에 구분했습니다. 역산 가정 저장·버전/확인 플래그와 실제 입력 구분·복수 가정표 선택·포장/중량 혼동·PDF 표/가격 표시를 보완했습니다. 과거 수치와 합산하지 않으며 가상 입력·CSV 검증입니다.

분리 인수 ZIP은 해시·비밀정보 제외·doctor·두 종류의 오프라인 시연·전체 회귀·공개 사양을 확인합니다. artifacts/handoff-package/latest.json이 최종 경로와 판정을 담습니다.

## 5. 데이터·센터 활용과 남은 검증

필수 #855는 2018-01-01~2025-09-17 과거 신고 출하량입니다. 날짜 누락은 제외 기록하고 부분월을 표시합니다. 경매자료는 확보한 가락시장 동일규격 관측이며 실시간 시세·농가 실수취가격이 아닙니다. 두 자료의 기간·분류가 달라 가격 인과관계나 현재 수급을 도출하지 않습니다.

센터 담당자는 설치·키·자료 갱신을 관리하고 이용자는 준비된 CSV와 카드부터 사용할 수 있습니다. API 키가 있는 경우 자연어 대화를 사용합니다. 최초 설치는 패키지 저장소 접근이 필요하고 실제 센터 네트워크·권한·계정은 미확인입니다. 공개 최소사양 기반 로컬 검증을 실제 i7-8700/GTX 1060 장비 실행으로 표현하지 않습니다.

| --- | --- |
| 계산·상태·직접 사용·배포 | 자동 검사·모델·분리 실행으로 확인한 범위 |

Python 고정49개·공지97개와 글꼴 OFL을 동봉합니다. 자료 출처·이용조건과 외부 목록은 데이터활용명세.md·외부라이선스목록.md, 실행은 사용자/운영자 매뉴얼을 확인합니다. 사람 리허설 과업표는 준비했지만 참여 결과는 미실시입니다. 커밋·개발 원격 반영과 팀 통합·외부 제출을 구분합니다.
