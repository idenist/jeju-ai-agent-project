# 제주 감귤 출하 검토 Agent 결과 설명자료

임준억 개인 구현 후보 / 2026-11-09 KST / 팀 최종 합의·외부 제출 전

## 1. 사용자의 질문에서 시작

“지금 출하할까요, 며칠 기다릴까요?”에 답하려면 가격뿐 아니라 수수료·보관비·기간 전체 감모와 실행 조건을 같은 기준으로 확인해야 합니다. 출하일을 조정할 수 있고 자신의 제시가격/비용을 확인할 수 있는 사용자가 대상입니다. 실제 수요·입력 가능성은 농가 검증 전의 가설입니다.

서비스는 아는 조건 확인 → 제주 과거 자료/선택적 시장 관측 → 필요한 가격 조건 비교 → 결과·근거 확인 → 기록/PDF 저장으로 이어집니다. 출하 후에는 별도 실제 기록과 정산 검산을 연결합니다.

| 구현 | 사용자가 확인할 결과 |
| --- | --- |
| 대화·조건 카드 공유 | 정정한 감모/비용으로 같은 상태에서 재계산 |
| 제주 자료·규격 탐색 | 실제 존재하는 품종/기간·규격과 관측 범위 |
| 비교·가정·역산 | 필요한 최소단가, 지정 가정별 금액, 한 변수의 허용 상한 |
| 저장·변경 검토 | 원래 조건을 보존하고 현재 조건과 재계산 차이 확인 |
| 실제 출하·정산 A+B | 매출/공제/지급액·별도 비용·입금 차이와 입력/계산 근거 |

미래가격 예측·최적 출하일·자동 거래·수익 개선 입증을 주장하지 않습니다. 지정 데이터의 실제 분석과 실행 가능한 서비스라는 취지에 맞춰 구성했습니다. [공식 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)

## 2. Agent와 하네스·근거의 역할

모델은 한국어 요청을 해석하고 부족한 조건 확인·허용 도구 선택/인수 구성을 담당합니다. Python 하네스는 원자 상태 갱신·버전·철회·기간 변경 재확인·반복/실행 예산·실패/부분 결과를 통제합니다. 수치와 보고서는 Python 결과를 표시합니다.

| 경계 | 통제 |
| --- | --- |
| 상태 | 최신 조건·과업 맥락을 기준으로 계산, 편집 중 이전 결과/내려받기 숨김 |
| 자료 | 품종/시점 자동 연결·미관측0·임의 가격 대입 방지 |
| 실행 | 모델6회·도구12회·90초 기본 예산, 동일 무진전2회 차단 |
| 맥락 | 최근4개 완결 사용자 턴·직렬화 input32000자, 사용자 장기 프로필 없음 |
| 계산 | Decimal로 비용/단위/감모 확인, 수수료·포함 비용 재차감 방지 |

자료 결과는 원문 URL·관측기간·조회조건을 표시합니다. 새 정산은 입력/계산 근거 ID·버전·식/반올림을 대화·PDF·JSON에 동일하게 연결합니다. 해시는 동일성 확인이며 원문 진위를 보증하지 않습니다. 기존 관측 도구 전체의 공통 근거 레지스트리 정렬은 후속입니다.

정산 카드는 로컬에서 검산하며 대화 검산도 같은 결과를 바로 표시합니다. 카드의 상세 정산값/근거는 모델 이력에 넣지 않고 금액 없는 처리 상태만 전달합니다. 사용자가 직접 입력한 채팅과 기존 출하 비교 조건은 모델 API 입력입니다. [OpenAI 도구 호출 문서](https://developers.openai.com/api/docs/guides/function-calling)

## 3. 확인 가능한 한 사례

경제성/정산 수치는 모두 독립 검산용 가상 조건입니다. #855 수치만 실제 보유 과거 CSV 조회입니다.

| 단계 | 조건 | 확인한 결과 |
| --- | --- | --- |
| 과거 맥락 | 노지온주·2018~2024년11월 | 실제7개 연도, 2024년43781.08톤 |
| 첫 비교 | 3000kg·3000원/kg·7일·총감모2%·보관비14만원 | 판매가능2940kg, 필요한 최소3109원/kg |
| 조건 정정 | 같은 조건에서 총감모4% | 필요한 최소3174원/kg, 현재 가격/물량 유지 |
| 자료 없음 | 노지온주·2025년11월 | 미관측, 0톤이나 가격상승 근거가 아님 |
| 정산 검산 | 매출9702000·공제545100·지급액9156900원 | 정산 항등식 차이0원 |
| 외부 비용 | 별도 보관비140000원 추가 | 입력 비용 반영9016900원, 전체 순이익 아님 |

현재 출하 비교는 ‘수수료만 차감된 현재 단가’와 보관비 외 동일 비용 제외 가정입니다. 정산 예시는 별도 비용 범위를 가진 가상 기록이므로 두 금액을 그대로 빼 보관 효과로 표시하지 않습니다. 당시 가정과 실제 결과 대조 C는 미구현입니다.

발표는 과거 데이터→조건 비교/정정→근거 확인을 주 시연으로 두고 정산·탐색·역산·변경 검토는 시간과 질문에 맞춰 보조로 제시합니다. PDF 예시를 쓰면 미리 생성한 가상 결과임을 밝힙니다.

## 4. 검증은 위험과 경로로 설명

| 확인한 위험 | 검사 방법 |
| --- | --- |
| 금액/단위·비용 이중 차감 | 독립 산술 정답·경계값·포함 비용/정산 밖 비용 구분 |
| 모름을0으로 처리 | 미입력/명시0·부분 결과·미관측 자료 검사 |
| 오래된 조건/잘못된 복원 | 버전 충돌·철회·기간 변경·해시/형식·재계산 검사 |
| 모델이 금액/근거 생성 | Python 결과 직접 표시, 정산의 후속 모델 입력 비전송 검사 |
| 키/네트워크 제약 | 키 없는 카드/CSV·PDF, 분리 패키지·부분 실패 복귀 |

자동 회귀257개는 test_ 함수 수이며 독립 사용자 수가 아닙니다. 분리 패키지에서도 같은 검사를 반복합니다. 정산6종은 변경한 로컬 처리 계약으로 각1회 모델 과업을 확인했으며, 이전18회/기존25종·제품8종 실행은 당시 소스/계약 기록으로 구분합니다. 모든 숫자를 합쳐 검증 규모나 정확도로 표현하지 않습니다.

발견했던 근거 ID 순서·이전 결과 표시·대안 식별 충돌·PDF 캐시 문제는 수정과 관련 검사로 보존했습니다. 현재 자동 결과와 소스 해시는 artifacts/verification.json·settlement-live/latest.json, 분리 실행은 package-shared-latest.json을 봅니다. 사람 사용성·농가 효용은 측정하지 않았습니다.

## 5. 데이터·센터·팀의 경계와 다음 단계

[제주데이터허브 #855](https://www.jejudatahub.net/data/view/data/855)는 2018-01-01~2025-09-17 과거 신고 출하량입니다. [경매원천정보](https://www.data.go.kr/data/15141810/openapi.do)는 확보 CSV의 규격별 관측가격이며 농가 실제 수취가격이 아닙니다. 품종/관측기간이 다르므로 현재 수급·가격 인과관계로 결합하지 않습니다. #855 개별 재배포 조건은 미확인으로 남겼습니다.

센터 담당자는 설치·키·자료 갱신을, 이용자는 배포 CSV와 대화/카드를 사용한다는 운영 가정입니다. 실제 센터 계정·권한·네트워크는 미확인입니다. 공개 최소 하드웨어 사양에 따른 로컬/분리 재현을 실제 센터 장비 실행으로 표시하지 않습니다.

| 구분 | 상태/후속 |
| --- | --- |
| 구현/자동 검사 | 개인 후보의 확인한 소스·실행 범위로 제시 |
| 농가·비전문가 실용성 | 참여0명, 실제 양식·입력 부담·이해도·효용 검증 필요 |
| 사람 발표 리허설 | 대본 준비, 실제 소요시간/참여 결과 미측정 |
| 팀 합의 | 대표 하네스/계산/UI·정산 채택·팀원 도구 연결·역할/통합 대기 |
| 후속 개발 | 당시 가정 대조 C·실제 양식 D·공통 citation 정렬, 범용화/생애주기 후보 |

공동 main CSV·전처리를 보존했고 임준억은 개인 하네스·상태·자료/계산·정산·UI/PDF·검증을 구현했습니다. 다른 팀원 도구를 통합 완료했다고 표시하지 않습니다. ChatGPT/Codex는 설계·구현·문서/검사 보조에 사용했고 최종 사람 검토는 별도입니다. Python49개 공지97개와 글꼴 OFL을 동봉합니다.

구현 기준은 dev/juneok의 dcae708이며 원격 게시 상태는 README를 확인합니다. 개인 후보로서 팀 승인·최종 제출은 아직 아닙니다. 공식 제출은 기획서15페이지 이내와 실행 코드/환경·매뉴얼·데이터 활용 명세·결과 설명자료 ZIP입니다. [공식 제출 기준](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)
