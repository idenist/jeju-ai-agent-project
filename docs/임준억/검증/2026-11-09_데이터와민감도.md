# 데이터 최신화·민감도·센터 CSV 실행 검증

후속 정정: [공개 사양·업무 적합성 판정](2026-11-09_공개사양과업무적합성.md)에서 센터 접근을 개발 필수 조건으로 두지 않고 공개 사양 기준으로 검증했습니다. 이 문서의 당시 결과와 미실시 기록은 이력으로 유지합니다.

2026-11-09 KST. 로컬 `dev/juneok`, 실제 농가·실제 센터 PC 검증은 아직 미실시입니다. 원격 push·PR·제출은 하지 않았습니다.

## CSV 환경과 API의 관계

센터 데이터 시스템 API 직접 접속은 지원하지 않으며, 센터 이용자가 내려받은 CSV를 입력하는 것이 공식 안내입니다. 외부 LLM API는 별도로 사용할 수 있습니다. 공개 데이터의 가공 CSV도 출처·전처리 방식을 적어 제출할 수 있습니다. [센터 CSV 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=3d8a1ba3-d0d8-4667-9e0e-b6d5d671e6d5), [외부 LLM 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=2a5342e0-a297-4d1d-9d6d-c91810382fae), [가공 데이터 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=b2f27892-3e7e-4df7-b055-d50d529f4741).

따라서 **개발 PC의 경매 API 수집 → 원본 CSV·전처리·검증 → CSV 포함 패키지 → 센터의 로컬 CSV 분석**으로 분리했습니다. 자연어 질문 처리만 OpenAI API를 사용합니다. 경매자료 수집키가 없어도 센터의 CSV 조회·직접 계산·민감도 도구는 동작합니다. 지원 CSV는 현재 감귤 출하·경매의 정해진 명세이며, 다른 센터 CSV를 자동 분석하는 범용 업로드 기능은 아직 없습니다.

## API·첨부 명세·CSV 확인

사용자가 추가한 DATA_GO_KR_KEY로 실제 첫 페이지 호출이 성공했습니다. 키·인증 헤더·요청 인증 URL은 결과에 남기지 않았습니다. [인증·컬럼 점검](../../../artifacts/api-probe-20261109.json).

첨부 XLSX의 ‘API 명세’와 ‘컬럼 변경 내역’에서 GET 주소, 시장·거래정산일 필수 조건, 단위물량·총물량·낙찰가·총가격 의미를 대조했습니다. 낙찰가를 곧바로 원/kg으로 해석하지 않고 총금액/검증된 총kg로 가중 가격을 계산합니다. 거래정산일과 실제 출하일도 구분합니다. 응답의 mdfcn_dt는 첨부 응답 필드 표에는 없지만 기존 CSV에도 이미 있으며 원본에 보존했습니다.

| 항목 | 확인 결과 |

| 최신 선택 CSV | 2026-10-01~11-06, 상세 집계 1,743행·17컬럼 |
| 최신 전처리 | 제주산 감귤·경매·수치/단위 검증 후 35,984거래 사용, 1,990거래 제외 |
| 원본 보존 | 공통 data/raw·processed·reports와 공통 전처리 코드는 변경하지 않음 |

[CSV 점검 요약](../../../artifacts/csv-and-api-audit.json). API의 전체 중분류 응답 수와 감귤 CSV 수, 최종 분석 거래 수는 다른 집계입니다. 수집기는 과실류 06·감귤 14만 CSV에 내보내고, 전처리는 제주산·경매·금액/중량 검증을 추가 적용합니다. 7~8일 0건을 가격 0원이나 전국 모든 거래 없음으로 해석하지 않습니다. API 조회를 8일까지 했더라도 관측 마지막일은 **6일**로 표시합니다.

가격 데이터는 여전히 가락시장 경락가격이며 농가 실수취가격·전국 실시간 시세가 아닙니다. #855 출하 통계는 2018-01-01~2025-09-17 자료를 유지합니다. 원출처 페이지에서 방화벽 차단 응답을 받아 더 최신의 #855 원본을 확보했다고 보고하지 않습니다.

공공데이터포털 페이지는 2026-11-09 확인 시 ‘한국농수산식품유통공사_전국 공영도매시장 경매원천정보’, 이용허락범위 제한 없음, 무료, 개발·운영 자동승인으로 안내했습니다. 포털의 실시간 갱신 안내와 로컬 CSV의 실제 관측일은 구분합니다. [공식 서비스](https://www.data.go.kr/data/15141810/openapi.do).

## 구현·검증 결과

- **자료 교체:** 원본 재전처리 재현, 새 버전 검증, 최신 관측이 없는 버전의 선택 거부, 선택 파일 해시 검사, 이전 선택 기록 보존. 새 자료는 artifacts/data-refresh에 보관하며 런타임은 선택 CSV를 읽습니다.
- **민감도:** 사용자 지정 감모율 최대 7개 × 미래 단가 최대 7개, 최대 49조합. 미래 단가가 없으면 손익분기만 계산합니다. 원래 조건·가격을 덮어쓰지 않고 기간·비용을 고정합니다. 목록이 없으면 모델이 값을 만들지 않고 확인합니다. 직접 화면과 Agent 도구·다운로드에 연결했습니다.
- **새 환경:** 기존 .venv와 분리한 artifacts/repro-env에 고정 의존성을 설치하고 pip check와 99개 회귀검사가 통과했습니다. [새 환경 결과](../../../artifacts/clean-env-verification.json).
- **실제 모델:** 기존 22개와 민감도·가정 미정·미래가격 미지정 3개를 합친 25개 모두 통과했습니다. [전체 실행 기록](../../../artifacts/evaluation-runs/20261109T040529628239.json)에 코드·CSV 버전·해시를 기록했습니다.
- **CSV 패키지:** 실제 키·가상환경을 제외하고 선택 CSV·명세·소스·설치 안내를 포함합니다. 새 위치에 풀고 두 키를 비운 상태에서 CSV 도구가 실행됐습니다. HTTP 요청을 강제로 막아도 같은 검사를 통과했습니다. [패키지 점검](../../../artifacts/center-package-smoke.json).

현재 패키지는 센터 실행 준비본이며 최종 제출물 검수 완료를 뜻하지 않습니다. 범용 CSV 매핑 UI와 실제 센터의 파일 입력·권한·운영 절차는 추가 확인이 필요합니다.

## ‘농가 실용성 미검증’의 의미

계산이 맞는지와 농가가 사용할 수 있는지는 별개입니다. 농가가 출하일을 바꿀 수 있는지, 실제 제시가격·비용·기간 감모를 확보할 수 있는지, 저장·납기 조건이 가능한지, 표의 의미를 이해하고 다음 행동에 활용하는지, 전화·메모·엑셀보다 나은지를 아직 사람에게 확인하지 못했습니다.

[실행 가능한 사용자 과제·독립 정답·기록표](../안내/사용자검증계획.md)를 준비했습니다. 팀원/비전문가에게 먼저 입력 부담·시간·이해도를 비교하고, 실제 농가/유통 담당자의 사례에서 선택권·입력 확보·실행 조건을 확인합니다. 사람의 측정 결과는 아직 없으며 가상 시간·만족도를 실측으로 쓰지 않습니다.

## ‘실제 센터 실행 미검증’의 의미

현재 PC의 새 환경과 패키지에서 동작하는 것은 확인했습니다. 실제 센터의 Python·패키지 설치, 쓰기 권한, CSV 배치·인코딩, 브라우저·localhost, 센터 키의 모델 권한·할당량, HTTPS·프록시·운영 절차에서는 실행하지 않았습니다. 공식적으로 허용된다는 답변과 해당 장비에서 작동한다는 실측은 다릅니다.

[센터 설치·CSV 경로·키 구분·현장 점검 안내](../안내/센터실행안내.md)와 `scripts.doctor_juneok.py`를 준비했습니다. 실제 장비 점검 전 center_pc_verified, 농가 검증 전 farmer_usability_verified는 false로 유지합니다.
