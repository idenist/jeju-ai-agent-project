기준일2026-11-09 KST / 개인 dev/juneok / 기준 main28e8af97. 사용자 요청으로 보고서의 실제 업무 문서 구성과 상단/하단 중복 문구를 정리했습니다. 분석·농가 효과를 새로 입증했다는 의미가 아닙니다.

## 참고와 적용

[한국농촌경제연구원 농업관측 과일2025년11월호](https://aglook.krei.re.kr/upload/observeFiles/4b6fdd5ba3b24c87b86312d70e36f5da.pdf)의 감귤 면과 말미 자료 설명을 읽고, 감귤 면을 로컬 렌더링해 확인했습니다. 절 제목·표 단위·표 옆 출처·산출 기준/자료 한계 분리 원칙을 참고했습니다. 기관 로고·발행/감수·공식 인증을 모방하지 않고 원문 수치·전망도 프로젝트에 전용하지 않았습니다. KAMIS 추가 PDF는 열람 시간초과로 근거에 사용하지 않았습니다.

## 실제 변경

- 상단의 `Python 도구의 조회·계산 결과입니다...` 문구를 제거했습니다. 제목과 내용 기반 문서ID·결과 절로 바로 시작합니다.
- 하단 공통 문구는 페이지 footer에만1회 표시합니다. MD/미리보기에서도 문서 마지막에1회 표시합니다.
- 공통 경고·가정·산출 해석·입력 확인·단위를 끝의 `이용 안내 및 확인사항`에 중복 제거해 모았습니다. PDF에는 구분되는 회색 상자를 사용합니다. 실행 제약·누락/실패 상태·자료 부재 등 판단에 직접 필요한 정보는 본문에 유지합니다.
- 절·표 번호, 단위, 자료명/관측기간/자료 버전/원출처, 입력 조건·조건 버전을 유지합니다. 문서ID는 같은 결과에 동일하고 결과가 바뀌면 달라집니다. 공식 발행번호나 인증 번호가 아닙니다.
- 채팅용 render_result는 유지합니다. 보고서는 같은 도구 결과를 읽어 문서 목적에 맞게 순서만 정리합니다. 내용 일치 검사는 채팅 문단의 단순 포함 대신 visible_results의 전체 render_report와 정확히 일치하는지 검사하도록 강화했습니다. 수치 계산·상태/도구 계약은 변경하지 않았습니다.

## 검증과 수정 루프

별도 재현 환경에서139개 전체가 통과했습니다. 신규4개는 상단 문구 제거·하단 중복 제거·본문 수치/버전/가정 보존·문서ID·PDF 페이지별footer를 검사합니다. 기존 PDF 검사에는49행이 첫 페이지부터 시작함을 추가 확인했습니다. 채팅·보고서의 배치가 달라진 두 검사는 같은 수치·버전·제약·다음 행동을 유지하는지 확인하도록 변경했습니다.

4종(기본1p·3대안2p·49행3p·과거자료/자료부재2p) 총8페이지를 Poppler PNG로 렌더해 직접 검수했습니다. 표 번호 캡션 때문에49행 전체가 다음 페이지로 밀리는 문제, 마지막 안내 한 줄만 별도 페이지에 남는 문제, 관련 입력 목록이 끊기는 문제를 보정했습니다. 긴 표 머리글 반복·한글·URL·표/문단 잘림을 확인했습니다. 중간 렌더 명령의 잘못된 path suffix는 임시 명령만 고쳤습니다.
