## 배포와 재현

`python -X utf8 -m scripts.build_juneok_handoff_package`는 현재 CSV 런타임을 만들고 인수 문서·예시 PDF 4종·MD/JSON을 하나의 ZIP에 넣습니다. .env와 가상환경을 제외하고 설정된 키 바이트가 포함됐는지 검사합니다. 파일별 SHA-256을 HANDOFF_MANIFEST.json에 기록합니다.

ZIP을 새 폴더에 풀어 해시·키 제외·예시 PDF 개수·doctor·시연 재생·회귀·공개 사양을 검사합니다. 분리 실행에는 기존의 별도 새 Python 환경을 사용하며 새 PC나 실제 센터 장비에서 설치했다는 뜻은 아닙니다.

원본 회귀 통과와 ZIP 분리 검증을 구분합니다. **ZIP 경로·분리 실행 결과·실제 검사 수·로그 위치의 단일 기준은 artifacts/handoff-package/latest.json**입니다. 실패하면 passed=false이며 배포 성공으로 판정하지 않습니다. 패키지 외부의 검증 결과는 scripts/build_juneok_handoff_package.py로 재현할 수 있습니다.
