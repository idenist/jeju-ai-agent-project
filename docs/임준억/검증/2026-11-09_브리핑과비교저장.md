## 구현 범위

브리핑은 기존 조건 비교와 명시적으로 선택한 #855 출하자료, 선택적 동일규격 시장 참고, 사용자 가정, 판단 조건을 묶습니다. 각 항목의 OK/NO_DATA/NEEDS_INPUT/DATA_ERROR를 남기고 부분 검토를 구분합니다. 품종 자동 매핑·시장가격의 현재단가 대입·과거물량→미래가격 추론은 하지 않습니다.

JSON은 로컬 내려받기/업로드로 조건·입력 구분·최대 100개 이력·자료 환경 버전·당시 결과를 보관합니다. 1MiB·지원 형식/버전·중복/비유한 숫자·조건·SHA-256 검사를 거칩니다. 미리보기는 무변경이고 명시적 복원만 상태를 바꿉니다. 당시 도구/문장은 실행하지 않고 현재 세션에서 다시 계산합니다. 해시는 인증·서명이 아니며 사용자가 가져온 값의 사실 여부는 미검증입니다.

판단 설명은 지정 조합의 최소단가 범위·금액 차이·유리/동일/불리·가격 미입력·실행 제약을 Python이 산출합니다. 보간·확률·최적 추천을 만들지 않고 기존 조건을 바꾸지 않습니다.
