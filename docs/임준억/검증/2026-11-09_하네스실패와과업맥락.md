# 하네스 실패 처리·반복 차단·과업 맥락 검증

2026-11-09 KST / 개인 구현 후보. [재검토](../계획/센터와팀기준의하네스재검토.md)를 사용자 승인 후 구현했습니다. 사용자 장기 프로필·계정·DB·팀 통합은 이번 범위에 없습니다.

## 구현과 완료 기준

| 항목 | 동작·경계 |
| --- | --- |
| 실패 분류 | API 시간초과·연결·인증·권한·호출 제한과 내부 도구 오류를 구분. 요청/도구/시간/입력 예산 초과도 개별 종료 사유로 기록. 화면에는 정제한 복구 안내와 부분 완료 표시 |
| 반복 차단 | 한 실행에서 같은 도구·실질 인수·조건·데이터 상태의 호출은 2회까지 실행, 세 번째는 실행 전에 중단. finish_turn·버전 숫자만 바꾸는 무진전 호출도 차단. 조건·자료·인수 변경 및 다음 사용자 요청은 재시도 가능 |
| 과업 맥락 | 고정된 목적 분류·명시한 조회조건·민감도 가정·미확인 항목. 금액·실행 가능성의 근거는 기존 ScenarioStore와 Python 조회/계산 결과가 담당. 원문 대화를 사용자 프로필로 누적하지 않음 |
| 입력 예산 | 기본 최대 4개 사용자 턴과 직렬화 input 32,000자. 오래된 완결 턴부터 제거하고 현재 상태·과업 맥락을 다시 넣음. 현재 턴의 도구 호출/응답 쌍은 잘라내지 않음. 현재 턴만으로 초과하면 명시적 중단 |
| 실행 예산 | 모델 요청 6회·도구 실행 12회·실행 경과 90초. SDK 요청 timeout은 남은 예산과 30초 중 작은 값, 자동 재시도 0회. 로컬 도구 실행을 강제 종료하는 하드 타임아웃은 아님 |
| 저장·초기화 | JSON v2에 과업 맥락 동봉, v1 읽기 호환. 이전 프로그램은 v2를 읽지 못할 수 있음. 대화만 지우면 조건/맥락 유지, 새 비교는 초기화. 데이터 변경 시 선택 맥락·과거 대화/결과 제거, 사용자 조건 유지. 가상 예시 불러오기도 이전 맥락/복원 기록 제거 |
| 기간 변경 | 감모 미확인 처리와 함께 이전 보관기간에 묶인 가정 목록도 무효화. 새 기간의 가정을 재확인 |

32,000자는 토큰 한도가 아니며 별도 instructions·도구 스키마 길이는 포함하지 않습니다. 비용 전체 상한 또는 어떤 길이의 과업도 계속 수행한다는 보장이 아닙니다. 과업 맥락은 도구가 확인한 선택의 구조화 기록이며 자유 형식 대화 요약/모든 사용자 의도의 추론 기능은 아닙니다.

## 검증 루프와 수정

1. 기존 162개를 먼저 실행했습니다. 기존 반복 호출 상한 기대와 JSON v2 거부 기대 2건을 새 명세에 맞게 바꾸고, 별도 요청 상한 검사·기존 v1 복원을 추가했습니다. 나머지 기존 회귀는 유지했습니다.
2. 신규 24개로 SDK 유형별 오류·부분 계산 보존·반복/무진전 차단·정상 복구·각 예산·30턴 맥락·철회·기간 변경·JSON/UI/PDF를 검사했습니다. PDF 추출 줄바꿈에 의한 한 건은 공백 정규화로 수정했습니다. 표시할 내용 자체를 완화하지 않았습니다.
3. 민감도 목록을 보관기간에 묶어 기간 변경 때 무효화하도록 보강하고 전체 186개가 통과했습니다.
4. 기존 실제 모델 평가의 첫 실행은 23/25였습니다. J21은 브리핑 내부의 실제 계산, J25는 판단 조건 표의 실제 가정을 최상위 도구명 검사기가 인정하지 못한 경우입니다. 평가기는 브리핑 구성 결과와 실제 조건 표 행도 검사하도록 수정했습니다. 금액/가정 오답을 여전히 거부하는 회귀 2개를 추가했습니다. 실패 기록을 삭제하지 않았습니다.

최종 전체 회귀 **188/188**, 기존 실제 모델 **25/25**, 새 한국어 과업 **18/18** 통과입니다. 신규 회귀는 26개입니다. 기간 바인딩 보강 후 실제 모델 18회를 별도로 다시 실행했고, 과거 소스 18회와 합산하지 않았습니다. 자동 테스트·모델 반복 평가는 실제 농가·팀원·심사위원의 사용 검증을 대체하지 않습니다.
