# 공유 상태와 미리보기·PDF 검증

2026-11-09 KST / 개인 dev/juneok / 기준 main28e8af97. 사용자 승인으로 Streamlit을 유지하며 대화·조건 카드의 동일 상태와 PDF 기본 출력을 구현했습니다. 실제 사람 검증과 AI 독립 검토를 구분합니다.

## 구현 범위와 결과

- SharedWorkspace가 AgentSession.store 한 개를 사용합니다. 카드 초안은 기준 버전·대안 ID와 함께 원자 갱신합니다. null 유지와 명시 철회를 구분합니다.
- 카드·대화·후속 계산이 같은 조건을 사용합니다. 미저장 카드 수정은 먼저 적용/취소하게 하고, 그동안 현재 결과·PDF는 숨기며 이전 대화 응답은 접어 표시합니다.
- 저장 후 소모된 감모 확인 표시를 미확인으로 오해하지 않습니다. 기간을 바꾸면 다시 확인하고, 그 새 확인만 저장에 반영합니다.
- 동등 숫자 표현·비용 배열 순서가 기존 사실을 새 입력으로 바꾸지 않게 값·순서·provenance를 보존합니다. 실제 값 변경은 직접 입력으로 기록합니다.
- 작업 시작 자료 토큰과 조건 버전을 고정합니다. 외부 CSV 교체·작업 중 자료 변경은 과거 내보내기를 차단하고 공유 조건은 보존합니다. 조회 출처에 자료 버전을 표시합니다.
- 미리보기·PDF·보조 MD는 같은 동결 entries를 사용합니다. 모델 재작성·수치 재계산은 없습니다. PDF 생성 실패는 미리보기·조건을 보존합니다. API 실패의 검증된 부분 결과에는 미완료 경고를 함께 내보냅니다.
- 한글 Nanum Gothic Regular/Bold와 OFL·출처/해시를 assets/fonts에 동봉했습니다. reportlab5.1.0/pypdf7.0.0을 lock에 반영했습니다. PDF 생성에 OS 글꼴·인터넷·키가 필요하지 않습니다.
