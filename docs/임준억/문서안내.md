# 임준억 개인 개발 문서

최신 발표 정리는 [핵심 대본](인수/발표핵심대본.md)과 [현재 검증](검증/2026-11-09_발표흐름과로컬정산정리.md)을 봅니다. 대화 정산은 카드 상세값을 로컬 처리하고 별도 전송 체크 없이 근거를 표시합니다. 현재 모델 검증6종과 주 여정을 이전18회 기록과 구분합니다. 사람 리허설/팀 채택은 후속입니다.

[검증 규모·모델 전송 재검토](검증/2026-11-09_검증규모와모델전송설계재검토.md):257개는 자동 테스트 메서드 수이며 ZIP에서 같은 검사를 반복했습니다. citation 자체에는 모델 전송 동의가 필요하지 않습니다.

최신 구현은 [실제 출하 기록·정산 검산](검증/2026-11-09_실제출하와정산검산.md)과 [작업기록29](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/%EC%9E%84%EC%A4%80%EC%96%B5/%EC%9E%91%EC%97%85%EA%B8%B0%EB%A1%9D/2026-11-09_29_%EC%B6%9C%ED%95%98%EA%B8%B0%EB%A1%9D%EA%B3%BC%EC%A0%95%EC%82%B0%EA%B2%80%EC%82%B0%EB%B0%8F%EA%B7%BC%EA%B1%B0%EC%B6%94%EC%A0%81%EA%B5%AC%ED%98%84.md)입니다. A+B·해당 근거 추적을 로컬 구현했고 C/D·팀 채택은 후속입니다. 아래 출처 점검은 당시 개발 전 검토입니다.

[공식 자료·팀 방향 정합성](검증/2026-11-09_공식자료와팀방향인용정합성.md)을 대조해 지정 데이터 분석·CSV 실행 유지와 금융정보 공개 경계를 보완했습니다.

최신 추가 검토는 [출처와 계산 근거 인용 점검](검증/2026-11-09_출처와계산근거인용점검.md)입니다. 당시 승인한 실제 기록 A+정산 검산 B에 근거 추적 완료 기준을 추가했고, 이후 구현 판정은 위 최신 검증을 봅니다.

원격 구현 게시 후 다음 범위는 [실제 출하·정산 기록 개발 검토](계획/실제출하와정산기록개발검토.md)와 [작업기록26](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/%EC%9E%84%EC%A4%80%EC%96%B5/%EC%9E%91%EC%97%85%EA%B8%B0%EB%A1%9D/2026-11-09_26_%EC%9B%90%EA%B2%A9%EA%B2%8C%EC%8B%9C%ED%99%95%EC%9D%B8%EA%B3%BC%EC%8B%A4%EC%A0%9C%EC%B6%9C%ED%95%98%EC%A0%95%EC%82%B0%EA%B2%80%ED%86%A0.md)을 확인합니다. 현재 구현과 다음 미구현 제안을 구분합니다.

최신 제품 확장은 [자료 탐색·역산·변경 검토 검증](검증/2026-11-09_자료탐색과역산및변경검토.md)과 [작업기록24](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/%EC%9E%84%EC%A4%80%EC%96%B5/%EC%9E%91%EC%97%85%EA%B8%B0%EB%A1%9D/2026-11-09_24_%EC%9E%90%EB%A3%8C%ED%83%90%EC%83%89%EA%B3%BC%ED%97%88%EC%9A%A9%EC%A1%B0%EA%B1%B4%EC%97%AD%EC%82%B0%EB%B0%8F%EB%B3%80%EA%B2%BD%EA%B2%80%ED%86%A0%EA%B5%AC%ED%98%84.md)를 봅니다.1·2번 통과 후3번을 진행했으며 기존188개와 신규38개 총226개를 구분했습니다.

리허설 준비·이용조건 후속 검수는 [사람 리허설 진행표](인수/사람리허설진행표.md), [데이터와 라이선스 검수](검증/2026-11-09_데이터이용조건과라이선스.md), [작업기록22](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/%EC%9E%84%EC%A4%80%EC%96%B5/%EC%9E%91%EC%97%85%EA%B8%B0%EB%A1%9D/2026-11-09_22_%EB%A6%AC%ED%97%88%EC%84%A4%EC%A4%80%EB%B9%84%EC%99%80%EC%99%B8%EB%B6%80%EB%9D%BC%EC%9D%B4%EC%84%A0%EC%8A%A4%EA%B2%80%EC%88%98.md)를 확인합니다.

최신 하네스 보강은 [실패와 과업 맥락 검증](검증/2026-11-09_하네스실패와과업맥락.md), [작업기록 21](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/%EC%9E%84%EC%A4%80%EC%96%B5/%EC%9E%91%EC%97%85%EA%B8%B0%EB%A1%9D/2026-11-09_21_%EC%8B%A4%ED%8C%A8%EB%B6%84%EB%A5%98%EC%99%80%EA%B3%BC%EC%97%85%EB%A7%A5%EB%9D%BD%EA%B5%AC%ED%98%84.md)을 확인합니다. 전체 회귀188·기존 실모델25/25·한국어 반복18/18을 기존 단계와 구분했습니다.

팀 주제인 감귤 출하 의사결정 Agent 안에서 개인 구현과 검증을 기록합니다. 공통 전처리 안내는 상위 docs에 보존합니다. 구현·설정·검증 산출물은 제품 저장소 안에 둡니다.

## 파일 배치

```text
docs/
├── 감귤_경매가격_전처리_실행안내.md       # 기존 공통 안내 보존
├── 제주_감귤_출하량_전처리_실행안내.md    # 기존 공통 안내 보존
└── 임준억/
    ├── 문서안내.md
    ├── 현황.md
    ├── 계획/
    ├── 안내/
    ├── 검증/
    ├── 인수/                          # 팀 인수·사용자/운영자 매뉴얼·통합·시연
    └── 작업기록/                      # 목차·날짜별 일지·통합 전 기록
```

앞으로 개인 문서는 이 경로와 한글 주제명을 사용합니다. 자동화 원시 결과·환경·데이터 버전은 artifacts에, 코드와 테스트는 기존 제품 폴더에 둡니다. 다른 프로젝트의 코드는 가져오지 않고 작업기록 형식만 참고했습니다.

커밋 메시지는 [작업기록 작성기준](작업기록/목차.md#기록-방법)의 제목·변경 불릿·필요시 맥락 형식을 따릅니다.
