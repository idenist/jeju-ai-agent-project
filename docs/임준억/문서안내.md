```text
docs/
├── 감귤_경매가격_전처리_실행안내.md       # 기존 공통 안내 보존
├── 제주_감귤_출하량_전처리_실행안내.md    # 기존 공통 안내 보존
```

커밋 메시지는 [작업기록 작성기준](작업기록/작성기준.md)의 제목·변경 불릿·필요시 맥락 형식을 따릅니다.
