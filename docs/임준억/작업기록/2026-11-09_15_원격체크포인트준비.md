Git 체크포인트는 공통 data CSV를 포함합니다. artifacts에 선택한 추가 경매 스냅샷과 키·평가 로그는 포함하지 않습니다. 새 clone은 공통 CSV로 실행되며 개발 PC의 최신 스냅샷과 관측범위가 다를 수 있습니다. 현재 선택 자료까지 동결한 인수 ZIP은 별도 로컬 산출물입니다. 자료의 관측범위는 실행 시 표시된 버전을 기준으로 확인합니다.
