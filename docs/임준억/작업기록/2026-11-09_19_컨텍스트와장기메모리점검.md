# 컨텍스트와 사용자 장기 메모리 점검

수행·기록일 2026-11-09 KST / dev/juneok. 이전: [하네스 레퍼런스 검토](2026-11-09_18_하네스외부레퍼런스검토.md).

사용자는 긴 대화뿐 아니라 필요한 사용자 정보를 장기 기억하는 구조의 필요성을 제기하고 현재 상태·나머지 하네스를 추가 확인하도록 요청했습니다. 코드·OpenAI/Anthropic/Streamlit 공식 자료를 대조하고 실제 API 없이 모의 구조 점검을 수행했습니다.

현재는 session_state/AgentSession.messages·ScenarioStore와 비교 JSON 수동 복원이며 사용자별 장기 메모리는 없습니다. 모의 점검 6개 기준으로 대화 초기화/조건 보존·새 workspace의 빈 조건·명시적 JSON 복원·전체 초기화·대화 누적을 확인했습니다. 30턴 요청 JSON 문자 수 372→11,180은 측정했으나 토큰/실제 지연은 아닙니다.

모의 시간 제한이 API_ERROR로 묶이고 동일 잘못된 도구 호출은 6회 후 종료됨을 확인했습니다. 전체 조건 초기화 뒤 restored_archive 객체가 남으나 현재 모델/화면에 자동 사용되지 않는 점도 기록했습니다. 프로필 전환·삭제의 정리 범위에 포함할 후보입니다.
