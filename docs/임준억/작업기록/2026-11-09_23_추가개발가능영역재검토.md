# 갈무리 전 추가 개발 가능 영역 재검토

수행·기록일2026-11-09 KST / dev/juneok / 원격203cbca·제품354b2e93 이후 로컬 후보. 이전: [리허설 준비와 외부 라이선스 검수](2026-11-09_22_리허설준비와외부라이선스검수.md).

사용자는 아직 마무리하기 이르다고 보고 개발 가능한 영역과 계획을 다시 검토하도록 요청했습니다. 현재 계획이 안정화·인수 준비에 치우친 점을 수정하고, 코드·데이터·공식 목적·기존 확장 방향을 대조했습니다. 새 기능 구현을 시작하라는 요청으로 확대하지 않았습니다.

확보 CSV는1743행·규격167개이며 관측범위10/1~11/6입니다. 데이터에서 실제 선택 가능한 거래조건을 탐색하는 도구가 없고, 시장 조회는 조건을 먼저 알아야 한다는 빈틈을 확인했습니다. 현재 계산은 필요한 가격과 지정 조합을 제공하지만 제안가격에서 허용 감모/비용을 역산하지 않습니다. JSON 저장/복원은 있으나 현재 상태를 유지한 과거/현재 비교도 없습니다.

추가 개발은 자료 탐색/선택 → 제안단가의 허용 조건 → 저장 비교의 변경 검토 순서를 권고했습니다. 3300원 가정에서 감모 경계 약7.6767%를 독립식으로 구하고 기존 계산기의7.67%(+670원)/7.68%(-320원)와 대조했습니다. 새 역산 기능이 구현·검증된 것으로 표시하지 않았습니다. 읽기 전용 점검 결과는 artifacts/development-review/feasibility.json입니다.

[추가 개발 재검토](../계획/추가개발가능영역재검토.md)에 기능별 사용자 과업·범위·완료기준·팀 합의를 정리하고 개발계획 상단의 오래된140개 수치를188개로 바로잡았습니다. 이전 단계 기록은 보존했습니다. 실제 출하/정산 기록은 그 다음 인접 업무 후보, 부분 출하·다른 작물·생애주기·장기 프로필은 각 선행 조건을 구분했습니다. 순서는 가용시간만이 아니라 현재 자료·계산 단위·검증 가능성에 근거합니다.

공식 안내와 제주농업기술센터의2018년 영농정보를 재확인했습니다. 후자는 저장/품질/감량과 출하 업무의 연결 참고이며 최신 감모 수치나 농가 효과를 도출하지 않았습니다. 사람/팀/심사위원 실검증은 수행하지 않았습니다. 제품 코드·실모델 추가 호출·데이터 변경·패키지 재생성·commit/push는 하지 않았으며 현재188개·25/25·18/18은 기존 기능의 검증 기록입니다. 새 검토 문서는 이전 인수 ZIP에 포함되지 않습니다.
