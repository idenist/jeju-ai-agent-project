# 실패 분류·반복 차단·과업 맥락 구현

수행·기록일 2026-11-09 KST / dev/juneok. 이전: [센터와 팀 기준 재검토](2026-11-09_20_센터와팀기준하네스재검토.md).

## 요청과 작업 의도

사용자는 재검토 방향을 승인하고 계획 최신화 후 실패 분류·반복 차단·과업 맥락부터 구현하도록 요청했습니다. 기존 기능을 유지하며 검증 루프를 돌리고 사용자 장기 프로필과 팀 합의 항목은 구분합니다. 이전 로컬 확장·기본 모델 변경은 보존하고 공통 데이터/전처리·팀 브랜치는 수정하지 않았습니다.

## 변경

- harness.py에 오류 유형·같은 조건의 반복 감지·실행/입력 예산·완결 턴 단위 입력 정리를 구현했습니다. agent.py는 최신 조건/과업 맥락을 매번 제공하고 종료 사유·단계·자료 버전을 반환합니다. SDK 자동 재시도는 0회로 조정했습니다.
- task_context.py에 현재 비교의 고정 목적 분류·명시 조회조건·사용자 가정·누락 항목을 관리합니다. 긴 대화 원문이나 사용자 프로필을 저장하지 않습니다. 기간 변경 때 해당 가정 목록을 지웁니다.
- SharedWorkspace·Streamlit에 공유 맥락과 복구 안내를 연결했습니다. 대화만 삭제/새 비교/데이터 변경/예시 불러오기 경계를 구분하고 오래된 복원 기록도 초기화합니다.
- JSON v2에 맥락을 포함하면서 v1 읽기는 유지했습니다. 기존 해시·용량·원자 복원과 과거 결과 재계산 원칙을 유지합니다.

## 실패·수정·검증

기존 162개 실행 중 반복 종료 정책과 v2 허용에 관한 예전 기대 2개를 새 계약에 맞게 갱신했습니다. 신규 24개 중 PDF 추출 줄바꿈 검사 한 건을 공백 정규화했습니다. 186개 통과 후 기간 변경 시 과거 민감도 목록도 무효화하도록 보강하고 다시 186개를 확인했습니다.

첫 기존 실모델 평가는 23/25였습니다. J21 브리핑 내부 계산과 J25 판단 조건 표의 가정을 평가기가 최상위 도구명만으로 거부했습니다. 실제 구성 결과/표 행을 검사하게 보완하고 오답 거부 회귀 2개도 추가했습니다. 최종 **188/188**, 기존 실모델 **25/25**, 1턴 정책으로 과거 턴을 제거하는 한국어 6종×3회 **18/18**입니다. 초기/보강 후 실행은 별도 보존했고 합산하지 않습니다.

가짜 SDK/시계로 장애를 주입했으며 실모델 API 장애를 유발한 검사는 아닙니다. 전체 회귀에서 데이터 manifest·공통 전처리 불변과 환경/비밀 파일 ignore를 확인했습니다. 매뉴얼·계획·기획서·결과 설명자료를 반영하고 PDF/분리 인수본을 재생성합니다. 최종 패키지 판정은 artifacts/handoff-package/latest.json을 따릅니다. [상세 검증](../검증/2026-11-09_하네스실패와과업맥락.md).

## 남은 일과 팀 경계

이번 작업은 commit/push·Notion 쓰기·팀 채택을 하지 않았습니다. 대표 하네스·화면·도구 계약·운영 예산과 개인정보 보존/삭제는 팀 합의 항목입니다. 사용자 장기 프로필·다른 작물·생애주기는 후속 후보입니다. 다음은 사람 리허설·데이터 이용조건 검수와 원격 반영 단위 정리이며 실제 농가 효과는 미검증입니다.
