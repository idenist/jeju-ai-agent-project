## 게시 전 재현성 보완

Git의 줄바꿈 자동 변환으로 공지29개의 Git blob 해시가 원문과 달라지는 문제를 발견했습니다. 공통 데이터의 blob을 바꾸지 않고 원래 CRLF가 checkout되게 하고, 글꼴/공지는 원문 바이트를 보존했습니다. lock도 실제 원문이 CRLF여서 처음 LF 설정을 정정했습니다. 게시 전 배포 커밋에 합쳤고 이미 공개된 이력은 재작성하지 않았습니다.

최종 clone의 데이터·공지 해시 불일치0건, lock 해시 일치를 확인했습니다. 첫 clone 검사에서는226개가 통과했지만 없는 .venv 디렉터리의 ignore 검사만 실패했습니다. 최종 clone에 환경 디렉터리 조건을 갖추고 기존 검증 인터프리터를 재사용해226개·manifest·공통 데이터 불변·ignore 검사를 모두 통과했습니다. 새 가상환경에 패키지를 재설치했다고 표시하지 않습니다. 증거는 artifacts/git-release-final-hashes.json, git-release-final-verification.log입니다.

실제 키·artifacts·실제 농가 기록은 커밋하지 않았습니다. 라이선스 원문의 공백을 일괄 수정하지 않고 해시를 유지했습니다. README와 개인 문서68개에서 상대 링크 누락0건을 확인했습니다. 제품 기능 변경이 없어 유료 모델 평가는 반복하지 않았습니다.
