## 시작 배경

오늘 출하와 미래 출하의 비교에 이어, 두 미래 출하일도 비교할 수 있도록 팀이 논의한 P2를 구현했다. 팀 기준은 `553ed30`, 정현님 변환 함수는 `c70bb5d`다.

## 작업과 변경 파일

- 기존 손익 엔진으로 A안·B안을 각각 계산해 B−A 차액과 A 대비 B 손익분기 단가를 표시한다. 과거 가격으로 B 단가를 가정할 때는 **두 출하일의 차이**로 가격쌍을 찾고, 비용과 감모에는 **각 대안의 보관일**을 적용한다. [P2 변경 파일과 커밋](https://github.com/idenist/jeju-ai-agent-project/compare/553ed30...0bdfd12)
- 과거 자료가 부족하면 B 단가를 직접 입력할 수 있다. `comparison_input.py`에서 중복 안내를 한 번으로 줄이고, [화면 회귀 테스트](../../../../tests/test_integration_future_pair.py)에 이를 포함했다. 화면·PDF·JSON은 같은 비교 결과를 사용한다.
- 검토본 `0bdfd12`를 `dev/juneok`에 올리고 이전 원격 검토 브랜치를 정리했다. 팀 통합 반영은 검토 대기다.

## 검증 결과

앱을 실행하고 **두 미래 출하안 비교**를 펼친다. 검산 입력은 물량 3,000kg, A 단가 2,500원/kg, A 3일·감모 1%·수수료 5%, B 10일·감모 4%·수수료 7%다. 하루 보관비 10,000원과 대안별 별도 비용 5,000원을 사용했다. [앱 실행 방법](../../../04_사용자_및_운영_가이드.md)

| 확인 항목 | 결과 |
| --- | --- |
| 3일 뒤 vs 10일 뒤 | 7일 간격 과거 가격쌍 20개. 3,000kg 예시에서 A 비교금액 7,018,750원, B 손익분기 2,660원/kg |
| B만 17일로 수정 | 14일 간격 가격쌍 15개. A 조건과 비교금액 유지 |
| B를 8일로 수정 | 5일 간격 자료 없음 안내. B를 2,750원/kg으로 직접 입력하면 A 대비 +261,850원 |
| 내보내기 | 로컬 브라우저에서 화면·PDF·JSON 결과 일치 확인. 이후 안내 중복 수정은 Streamlit 화면 테스트로 재확인 |
| 기존 기능 | 안내 수정 후 로컬 `unittest discover -s tests -q` 전체 559개 통과 |

기준선 재실행에서는 자동 테스트 548개와 평가기 14개, 가격 자료 재생성·사전검증을 통과했다. 이때 팀 실제 모델 평가 원본이 로컬에 없어 종합 인수는 완료하지 못했다. 위 P2 확인은 로컬 기술 검증 범위다. [개편 전 상세 기록](https://github.com/idenist/jeju-ai-agent-project/blob/0bdfd12/docs/임준억/작업기록/2026-11-12_미래출하안상대비교제안.md)
