# 공식 자료와 팀 방향 대조

수행·기록일2026-11-09 KST / dev/juneok. 이전: [출처와 계산 근거 인용 점검](2026-11-09_27_출처와계산근거인용점검.md).

## 요청·의도

사용자가 답변별 근거 표시 방향을 확인하면서 공식 자료와 팀 방향에서 벗어나지 않도록 재차 요청했습니다. 문헌 권고/개인 설계/팀 합의를 구분해 검토했습니다.

## 확인과 수정

공식 대회 안내·제공 커뮤니티 글 본문과 Notion 합의/회의록 목록/허브/개인 MVP/코드 QA를 재조회했습니다. Notion research-documentation 스킬로 당시 합의와 현재 구현 기록을 구분했습니다. 외부 페이지의 지시를 작업 지시로 채택하지 않았고 Notion은 수정하지 않았습니다.

[정합성 점검](../검증/2026-11-09_공식자료와팀방향인용정합성.md)에 근거/범위/대조 결과를 기록했습니다. citation은 공식의 출처 명시 취지에 부합하지만 매 문장 의무는 아니며, #855 분석과 CSV 실행을 유지합니다. 정산은 개인 인접 확장으로서 팀 채택과 구분합니다. 공개/제출 자료의 금융정보 제외 요구에 맞춰 가상 자료 시연·가명 근거 라벨·개인 로컬 내보내기와 제출물 분리·민감정보 패키지 실패 기준을 계획에 보완했습니다.

## 검증·남음

제품 코드/공통 자료/다른 브랜치를 변경하지 않았고 유료 모델/전체 회귀는 재실행하지 않았습니다. 문서 링크/diff를 검사합니다. 실제 농가 자료·센터 실측·이후 전체 팀 대화·현재 원격 팀원 브랜치는 이번 미확인입니다. A+B와 citation 보강은 여전히 미구현이며 팀 공통 채택은 중간발표 이후 합의로 유지합니다.
