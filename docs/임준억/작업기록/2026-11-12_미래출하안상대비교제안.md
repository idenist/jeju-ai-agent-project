# 두 미래 출하안의 상대 비교 제안

2026-11-12 KST / 통합 기준 `553ed30` / 정현 변환 함수 `c70bb5d`

팀 대화에서 논의한 P2를 별도 로컬 브랜치 `proposal/juneok-future-pair`에 구현했다. 앱에서 **두 미래 출하안 비교**를 펼쳐 물량, 보관 시작일, 각 대안의 보관일·감모·비용, A 단가, B 단가 입력 방식을 선택한다. 계산은 기존 엔진에 A와 B를 나누어 요청하고, 두 미래 대안의 비교금액으로 B−A 차액과 A 대비 B 손익분기 단가를 산출한다. PDF와 결과 JSON은 같은 상대 비교 결과를 사용한다.

과거 변동으로 가정하는 경우에는 A·B의 출하일 차이로 동일 규격의 가격쌍을 조회한다. 3일 대 10일이면 조회 간격 7일, 손익 계산의 보관일은 각각 3일과 10일이다. 가격쌍을 확보하지 못하면 **직접 입력**으로 전환할 수 있다. 보관일을 바꾸면 해당 대안의 기간 전체 감모를 새로 입력하고, 이전 계산과 다운로드는 숨긴다.

- 가상 검산에서 물량 3,000kg, A 단가 2,500원/kg, A 3일·감모 1%·수수료 5%, B 10일·감모 4%·수수료 7%를 사용했다. 하루 보관비 10,000원과 대안별 별도 비용 5,000원을 반영하면 A 비교금액은 7,018,750원이고, A 대비 B 손익분기 최소 단가는 2,660원/kg이다.
- B를 17일로 변경하면 조회 간격이 14일로 바뀌며 A 조건·금액을 유지한다. B가 8일이면 5일 간격 자료가 없어, B 단가 2,750원/kg을 직접 입력한 경우의 A 대비 차액 261,850원을 화면 검사에서 확인했다.
- 연결 후 전체 단위 테스트 559개가 통과했다. 기존 계산 엔진과 공통 계산 서비스 파일은 기준 커밋과 동일하다.
