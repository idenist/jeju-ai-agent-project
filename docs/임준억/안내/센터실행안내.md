# 센터 실행: 데이터는 CSV, 자연어 처리는 별도 모델 API

현재 기준(2026-11-09): [공개 사양 적합성](../검증/2026-11-09_공개사양과업무적합성.md)을 새 환경·단일 CPU·CSV/화면·메모리 검사로 확인했습니다. 실제 센터 장비 접근은 현시점 개발을 멈추는 선행 조건으로 두지 않습니다. 아래 실제 장비 점검 항목은 운영자 인수 때 추가할 확인사항입니다.

## 공식 답변과 적용 범위

2026-11-09 공식 게시판 답변을 브라우저에서 다시 확인했습니다.

- [센터 실행 환경·데이터 접근 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=3d8a1ba3-d0d8-4667-9e0e-b6d5d671e6d5): 센터 시스템에 API로 직접 접속하는 방식은 지원하지 않으며 이용자가 내려받은 CSV를 Agent에 입력해야 합니다. Windows 11, Python·패키지 설치 가능이며 사전 명세가 필요합니다.
- [외부 LLM·키 설정 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=2a5342e0-a297-4d1d-9d6d-c91810382fae): 외부 LLM API 사용 가능, 향후 센터가 비용을 부담할 예정이며 별도 키 설정 안내를 제공해야 합니다.
- [가공 데이터 제출 답변](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board&postId=b2f27892-3e7e-4df7-b055-d50d529f4741): 공개 데이터의 전처리 CSV 등은 출처·처리방식을 명시해 제출할 수 있습니다.

이 프로젝트에서 **경매 API 수집은 개발·자료 준비 작업**, **Agent의 데이터 조회는 로컬 CSV 읽기**입니다. 센터 시스템에 API로 접속하지 않습니다. `.env`의 DATA_GO_KR_KEY는 선택적 수집 도구에만 필요하며 센터 실행에는 없어도 됩니다. 자연어 기능의 OPENAI_API_KEY는 별개입니다.

사이드바의 자료 관리자 영역에서 배포 원본과 같은 36컬럼 CSV를 선택·검사·미리보기·적용할 수 있습니다. 가공본·다른 명세·#855 교체는 지원하지 않습니다.

## 설치와 실행

검증한 Python은 **3.13.12, 64비트**입니다. 센터에는 Python 3.13과 Python launcher, 고정 의존성 목록을 사전에 안내합니다. 검증 모델은 gpt-6-luna입니다. 모델 추론은 외부 API에서 수행하며 로컬 GPU를 사용하지 않습니다.

1. CSV 실행 패키지를 쓰기 가능한 폴더에 풀고 `setup-center.cmd`를 실행합니다. 설치에는 패키지 저장소 접근이 필요합니다.
2. 키가 없어도 `run-juneok.cmd`로 공유 조건 카드·과거 출하통계·가정 범위 비교·PDF를 사용할 수 있습니다.
3. 자연어 모드를 사용할 경우 생성한 `.env`의 OPENAI_API_KEY에 센터의 키를 입력합니다. OPENAI_MODEL은 사용할 수 있는 모델로 설정합니다. 키는 제출 ZIP·보고서·영상에 넣지 않습니다.
4. `run-juneok.cmd`를 실행하고 터미널에 표시된 localhost 주소를 엽니다. 화면의 자료 관측일과 실행 상태를 확인합니다.

```powershell
.\.venv\Scripts\python.exe -m scripts.doctor_juneok
.\.venv\Scripts\python.exe -m scripts.doctor_juneok --network
```

기본 점검은 현재 PC의 파일 쓰기·localhost 바인딩·CSV 도구를 확인합니다. `--network`는 인증키 없이 OpenAI HTTPS 응답 도달 여부만 확인하며 계정 인증·모델 이용권한·할당량을 검증하지 않습니다. 실제 모델 검증은 별도 평가 명령으로 수행합니다.

## 공개 경매 CSV 갱신: 개발 PC에서 수행

필요한 서비스는 [한국농수산식품유통공사_전국 공영도매시장 경매원천정보](https://www.data.go.kr/data/15141810/openapi.do)입니다. API 명세의 GET 주소는 `https://apis.data.go.kr/B552845/katOrigin/trades`입니다. 발급한 키를 제품 `.env`의 DATA_GO_KR_KEY에 넣습니다. 인코딩/디코딩 키는 수집기에서 처리합니다.

```powershell
# 네트워크 호출 없이 현재 관측기간·CSV 버전 확인
.\.venv\Scripts\python.exe -m scripts.refresh_juneok_market
# 기존 원본 CSV를 별도 버전으로 검증. 기존 공통 파일은 수정하지 않음
.\.venv\Scripts\python.exe -m scripts.refresh_juneok_market --input data/raw/auction_trades.csv --name imported-source
# 수집은 현재 관측일 다음 날부터, 한 번에 최대 7일. 예시 날짜는 실행 시 조정
.\.venv\Scripts\python.exe -m scripts.refresh_juneok_market --collect --start 2026-11-09 --end 2026-11-09 --name market-new
# 유효하며 기존보다 최신 관측이 있는 버전만 선택
.\.venv\Scripts\python.exe -m scripts.refresh_juneok_market --activate market-new
# 선택한 CSV와 해시·코드를 포함하고 실제 키·가상환경을 제외한 패키지 생성
.\.venv\Scripts\python.exe -m scripts.build_juneok_center_package
```

`artifacts/data-refresh/`는 검증 버전 보관 위치입니다. `artifacts/market-active.json`이 선택한 버전을 가리킵니다. 패키지 빌더는 이 두 위치 중 선택한 버전에 필요한 파일만 명시적으로 포함합니다. 평소 Git에서 artifacts 전체를 제외하더라도 패키지에 선택 CSV가 누락되지 않게 했습니다. 공통 data/raw·processed·reports는 보존합니다.

수집 실패·자료 0건을 유효한 가격 0원으로 처리하지 않습니다. 최신 관측이 추가되지 않으면 기존 버전을 유지합니다. 선택한 파일의 해시가 다르거나 누락되면 조회 오류를 표시하며 조용히 다른 가격으로 대체하지 않습니다. 폴더를 옮길 때는 전체 패키지를 함께 옮기세요.

## 실제 센터에서 남은 확인

로컬 새 가상환경 검증은 실제 센터 검증이 아닙니다. 실제 PC에서 다음을 확인해 결과를 남깁니다.

- 사전 명시한 Python·패키지 설치, 파일 쓰기 권한, 브라우저·localhost 실행.
- 준비한 CSV 위치·인코딩·컬럼·단위·관측기간과 필수 데이터 사용 여부.
- 센터 키의 모델 접근권한·할당량, HTTPS·프록시·보안 프로그램과 API 응답.
- 키 없는 직접 도구 사용, 잘못된 CSV·API 실패 때 복구 안내, 일반 사용자의 작업 완료.
- 결과 다운로드·데이터 이용/반출 절차와 담당자의 운영·갱신 방법.

`readiness.json`의 scope는 CURRENT_MACHINE_ONLY이며 실제 센터 점검 전 center_pc_verified는 false로 유지합니다.

## 공유 화면과 PDF 배포

대화와 조건 카드는 같은 Python 상태를 사용합니다. PDF 기본 다운로드와 MD 보조 출력을 제공합니다. `assets/fonts`의 TTF 2종·OFL.txt·SOURCE.json을 빠뜨리지 마세요. 설치 lock에는 reportlab/pypdf가 포함됩니다. 모델 키 없이 CSV·조건 카드·PDF를 실행할 수 있고, 초기 패키지 설치에는 별도 패키지 저장소 접근이 필요합니다. 최신 상세 판정은 [공유 상태·PDF 검증](../검증/2026-11-09_공유상태와PDF.md)을 확인하세요.
