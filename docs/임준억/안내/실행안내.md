# 개인 MVP 설치와 실행

모든 명령은 제품 폴더 `C:/Proj/26_jeju_agent/jeju-ai-agent-project`에서 실행합니다. 다른 프로젝트의 환경 파일이나 전역 Python 환경은 사용하지 않습니다.

## 준비된 환경

Python 3.13.12 전용 가상환경 `.venv`와 설치한 패키지의 정확한 버전 목록 `requirements-juneok.lock`을 준비했습니다. 원본 CSV는 공통 main 스냅샷이며 `data/metadata/juneok_manifest.json`에 출처·관측기간·SHA-256이 기록되어 있습니다.

새 PC에서 설치할 때:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-juneok.lock
Copy-Item .env.example .env
```

이미 `.env`가 있는 환경에서는 덮어쓰지 마세요. 센터 설치 시 Python·패키지와 외부 API 주소를 사전에 명시합니다.

## 키 설정

제품 루트 `.env`의 `OPENAI_API_KEY=` 뒤에 본인의 키를 입력합니다. `OPENAI_MODEL`은 계정에서 사용 가능한 모델 ID로 지정합니다. 현재 `.env.example`의 모델은 검증에 사용한 `gpt-6-luna`입니다. `OPENAI_MODEL`이 없거나 비어 있으면 코드 기본값 `gpt-6-luna`를 사용합니다. 키와 모델은 OS 환경변수가 `.env`보다 우선합니다.

프로그램은 이 제품 루트 `.env`만 명시적으로 읽습니다. 다른 프로젝트·상위 디렉터리에서 `.env`를 탐색하지 않습니다. 같은 이름의 OS 환경변수가 있으면 OS 값이 우선합니다. 키는 화면·로그·보고서에 표시하지 않습니다.

설정 확인은 키 값 없이 실행됩니다.

```powershell
.\.venv\Scripts\python.exe -m agents.juneok.cli --check
```

화면에서 설정 상태 새로 확인을 누르거나 CLI를 다시 실행하면 새 설정을 읽습니다. 모델 설정이 바뀌면 화면의 API 클라이언트를 갱신하고 기존 비교 조건은 유지합니다.

결과는 `artifacts/offline-demo.md`에 저장합니다. 이는 실제 모델 성능 검증이 아닌 Python 도구 시연입니다.


- 자연어 대화: 키 설정 후 질문·추가 조건·조건 변경을 처리합니다. 조건 카드와 같은 ScenarioStore·버전을 사용합니다.
- 현재 조건 카드: 키 없이 같은 조건을 확인·수정·계산합니다. 빈칸과 0을 구분하며 저장 전 초안과 확정 조건은 구분합니다. 미저장 수정은 먼저 적용하거나 취소한 뒤 대화를 이어갑니다.
- 과거 출하통계: 펼침 영역에서 키 없이 실제 #855 과거자료를 조회합니다.
- 결과와 보고서 미리보기: 현재 확정 조건의 결과를 읽고 PDF로 저장합니다. MD는 보조 펼침 영역에 있습니다. 사용 안내에서 가격·비용·감모·자료 범위를 확인합니다.

미래 단가가 없으면 필요한 단가를 제시하고 실제 유리한 대안 순위는 만들지 않습니다. 실행 가능성은 사용자 확인 여부와 별도로 표시합니다.

## 선택 기능: 자료 관리자의 경매 CSV 추가

일반 사용자는 배포 CSV로 바로 시작할 수 있습니다. 자료를 갱신할 때만 사이드바의 `자료 관리자 · 경매 CSV 추가`를 엽니다.

1. 배포 `data/raw/auction_trades.csv`와 같은 36개 컬럼의 원본 CSV를 선택합니다. UTF-8 또는 CP949, 최대 20MiB를 지원합니다. 가공 가격표·#855 출하통계·다른 명세는 이 업로드에서 지원하지 않습니다.
2. `CSV 검사 · 변경 내용 미리보기`로 유효·제외 건수, 사유, 품종, 적용 후 관측기간과 버전을 확인합니다. 검사만으로 현재 자료가 바뀌지 않습니다.
3. 확인 후 `확인한 자료 적용 · 대화 초기화`를 누릅니다. 기존 경매 이력에 추가하며 완전히 동일한 원본 거래는 중복 제외합니다. 같은 날짜 수정 거래를 대체하는 기능은 아닙니다. 최신 유효 관측이 없으면 적용하지 않습니다.
4. 대화는 이전 가격 근거와 혼동하지 않도록 초기화합니다. 공유 비교 조건은 유지합니다. 변경한 자료는 이 설치본의 모든 사용자가 공유합니다.

오류·변조·검사 이후 다른 자료 적용은 기존 선택 자료를 유지하며 재검사를 요구합니다. 키와 인터넷 없이 작동하고 원본·가공본은 공통 data 폴더에 덮어쓰지 않습니다. 검사 후보는 artifacts/data-refresh에 보존합니다. 별도 사용자 인증·여러 관리자 동시 갱신은 현재 범위가 아닙니다.

## 조건 확인·수정과 보고서

조건 카드는 현재 판매·비용·보관·실행 조건의 네 구역으로 입력합니다. `이번 비교의 입력 구분`은 사용자의 표시이며 사실 검증이 아닙니다. 가상 예시 버튼은 가정으로 표시합니다. 현재 조건 카드에서 값·0·모름·실행 제약을 구분할 수 있습니다.

값을 수정하고 Enter 또는 다른 항목으로 이동해 반영하면 이전 결과·보고서·민감도 표를 숨깁니다. 다시 `입력 조건 비교`를 눌러야 갱신됩니다. 보관기간 변경은 감모 확인을 즉시 해제하므로 새 기간 전체 감모를 확인한 뒤 체크하세요. 조건 버전과 직전 제출 이후 바뀐 항목은 결과와 보고서에 같이 표시합니다.

결과의 `다음 확인과 행동`으로 실제 제시가격·비용·저장시설·출하 변경/계약/납기 조건을 확인하세요. 필요한 단가는 예측가격이나 자동 출하 권고가 아닙니다. 대화와 카드는 같은 확정 조건을 사용합니다. 대화 후 카드를 다시 입력할 필요가 없고 카드 변경도 다음 대화에 반영됩니다. 카드 초안은 적용 전까지 공유 상태가 아니며 오래된 기준 버전으로 저장하면 거부합니다.

## 공유 조건·PDF의 추가 확인

`대화만 비우기 · 조건 유지`는 공유 조건을 보존하고 이전 대화·보고서를 비웁니다. `새 비교 시작 · 조건도 초기화`는 조건까지 초기화합니다. CSV 적용이나 다른 실행 세션의 자료 교체도 조건은 보존하고 구자료 대화·내보내기는 무효화합니다.

결과·PDF는 같은 동결 결과 객체에서 생성합니다. 카드 편집 중에는 현재 결과·PDF를 숨기고 과거 대화 응답을 접어 표시합니다. 감모·비용·수수료·미래 단가를 바꿔도 바꾸지 않은 수치·대안 ID·출처 이력은 보존합니다. 실제 관측 조회는 가상 예시 조건과 별도로 표시합니다.

PDF는 `assets/fonts/`의 Nanum Gothic과 OFL 라이선스를 포함해야 하며 OS 글꼴·PDF 생성용 인터넷·모델 키를 요구하지 않습니다. PDF 생성에 실패하면 미리보기와 조건을 보존하므로 설치/글꼴을 복구한 뒤 다시 시도하세요.

새 공유 경로의 실제 모델 검증은 비용이 발생하는 다음 명령입니다. 기본 회귀는 모델을 호출하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_juneok
.\.venv\Scripts\python.exe -m scripts.verify_juneok_shared_live
```
