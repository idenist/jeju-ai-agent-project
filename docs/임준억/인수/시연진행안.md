# 시연 진행안

발표의 기본 순서는 [발표 핵심 대본](발표핵심대본.md)을 우선합니다. 아래는 기능별 상세/질의응답용이며 모든 확장 기능을 한 발표에서 순회하지 않습니다. 정산은 카드 상세값을 로컬 처리하며 별도 전송 동의 체크가 없습니다.

## 탐색·역산·변경 검토 추가 시연

1. 가상 예시 조건에서 자료 탐색을 열어 경매/조생귤/5kg 등 직접 선택하고 실제 후보를 조회합니다. 관측일·품질·입력 가격 불변을 확인합니다.
2.3300원 가정으로 감모 상한7.67%를 계산합니다. 감모2%를 고정한 별도 계산에서 일 보관비100285원을 확인합니다. 두 상한 동시 적용이 아님을 설명합니다.
3. 감모2% 조건을 JSON으로 저장하고 카드에서4%로 수정합니다. 파일 확인 후 변경 검토를 누르면3109→3174원/kg·차이65원/kg이며 현재4%가 유지됩니다. 복원은 누르지 않습니다.

`python -m scripts.prepare_juneok_product_demo`가 기능확장시연자료/의 PDF4종·MD/JSON·비교기준예시.json을 키/HTTP 없이 생성합니다. 사용자·농가가 실제 수행한 결과로 표시하지 않습니다.

처음 사용하는 사람의 과업·관찰·시간/도움/이해도 기록은 [사람 리허설 진행표](사람리허설진행표.md)를 사용합니다. 이 대본의 자동 재생 통과를 사람 리허설 완료로 표시하지 않습니다.

기준일 2026-11-09 KST. **3분은 대본의 목표 길이**이며 실제 완료시간 측정값이 아닙니다. 녹화·팀원 리허설은 미실시입니다. 가상 경제성 조건과 실제 CSV 관측을 구분합니다.

## 사전 준비

- [운영자 매뉴얼](운영자인수매뉴얼.md)대로 설치하고 run-juneok.cmd를 실행합니다. 자연어 확장에는 별도 모델 키와 접근권한이 필요합니다.
- `새 비교 시작 · 조건도 초기화`로 시작합니다. 화면 공유에서 .env·오류 전문·개인정보가 보이지 않도록 준비합니다.
- 동봉 PDF는 당시 조건·버전의 예시입니다. 화면 실패 시 예시임을 밝히고 사용합니다.
- 다음 명령은 HTTP를 차단한 자동 재생입니다. 실제 모델·데이터 API 호출은 0회이며, 장애는 명시적으로 주입한 모의 실패입니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.prepare_juneok_handoff_demo
```

## 자연어 확장: 키 설정 후 선택 시연

실제 응답시간과 추가 질문에 따라 길이가 달라집니다. 아래는 **입력 대본**이며 이번 자료 준비에서 새로 실행한 실제 모델 결과가 아닙니다.

첫 질문:

> 가상 조건을 비교합니다. 물량은 3000kg이고 지금 제시가격은 수수료만 뺀 3000원/kg입니다. 단가에 이미 반영한 비용은 수수료만입니다. 보관비 외 선별·포장·운송 등 기타 고정비는 양쪽 동일해서 제외합니다. 7일 보관기간 전체 감모는 2%로 가정 확인하고, 전체 물량의 하루 추가 보관비는 20000원입니다. 미래단가는 없고 저장·출하일 변경 가능성은 미확인입니다. 필요한 최소단가를 비교해주세요.

카드에서 감모를 4%로 바꾼 뒤 질문:

> 지금 저장된 조건으로 필요한 최소 단가를 다시 알려주세요. 다른 조건은 바꾸지 마세요.

첫 결과 3,109 → 카드 감모 4% → 다음 대화 3,174를 확인합니다. 두 번째 질문에 감모 수치를 반복하지 않아 공유 상태를 사용하는지 보여줍니다. 누락 질문에는 정해둔 가정만 답합니다. 실시간 모델 실행은 별도 실행 기록으로 남깁니다.

## 확장 시연: 3분 기본 대본 이후 선택

1. 기존 가상 예시 상태에서 브리핑 출하 품종 노지온주·11월·2018~2024년을 선택합니다. 가정 범위 감모 1,2,4 / 미래단가 3000,3300을 입력하고 범위 포함을 체크합니다.
2. `출하 검토 브리핑 만들기`로 #855 과거 자료·계산·6조합·판단 조건을 같은 보고서에서 확인합니다. 경매 참고는 기본 생략합니다.
3. 조회 연도를 2025~2025로 바꿔 미관측은 부분 검토이고 0톤이 아님을 보여줍니다.
4. `비교 JSON 내려받기`로 저장하고 물량을 수정합니다. 저장 파일을 확인한 뒤 명시적으로 복원하면 원래 물량과 3,109원/kg가 재계산되는지 확인합니다.
5. `판단이 바뀌는 조건 설명`에서 3,078~3,174원/kg·조합별 차이·실행 제약을 설명합니다. 유리한 조합이 실행 권고는 아닙니다.

자동 준비: `python -m scripts.prepare_juneok_review_demo`. 확장시연자료/에 PDF 4종·MD/JSON과 비교복원예시.json을 넣습니다. 실제 모델 검증은 별도 scripts.verify_juneok_extensions_live이며 과업 4개·9개 기준입니다. 사람 리허설 시간은 아직 측정하지 않았습니다.

## 과업 맥락 보강 확인

결과 옆 `이번 검토의 선택과 미확인 사항`을 펼쳐 조회 품종·기간·남은 항목을 확인합니다. 노지온주 2018~2024년 11월 조회 후 “방금 선택한 품종과 기간으로 다시 확인해줘”라고 요청해 같은 선택을 이어갑니다. 7일을 3일로 바꿀 때 이전 감모/가정 목록이 지워지고 새 기간 가정을 확인하는지도 보여줍니다. 대화만 삭제는 선택 유지, 새 비교 시작은 초기화입니다.

반복 차단·오류별 안내는 전체 회귀에서 결정적 모의 응답으로 검사합니다. 현장 시연에서 의도적으로 실제 API 장애/반복을 유발하지 않습니다. 실제 모델 한국어 6종×3회 결과는 task-harness-live/latest.json에 있고 사람 실용성 검증과 구분합니다.
