# 발표 핵심 대본 · 개인 구현 후보

2026-11-09 KST / 목표5분, 실제 사람 리허설 시간은 아직 미측정입니다. 팀의 발표 시간·대표 기반·역할은 확정하지 않습니다. 기존 [기능별 상세 시연안](시연진행안.md)은 질의응답용이고 본문은 발표의 우선 순서입니다.

## 한 문장과 메시지

“출하 담당자가 아는 조건을 말하면, 비교 가능한 자료를 확인하고 기다리려면 필요한 가격 조건을 계산해 근거까지 확인하는 감귤 출하 검토 Agent입니다.”

발표 첫 화면에는 문제·사용자·실행 결과를 먼저 보여줍니다. ‘257개’·API/함수명·기술 목록을 첫 메시지로 쓰지 않습니다. 실제 농가가 출하일을 바꿀 수 있고 감모/비용을 입력할 수 있다는 점은 사용자 조건이며 현재 인터뷰로 확인한 수요가 아닙니다.

## 시연 준비와 대체 경로

- 발표 전 앱과 가상 예시를 준비하고 #855 조회조건·현재 카드 상태를 확인합니다. 실제 정산서/계좌·.env·오류 전문은 화면 공유하지 않습니다.
- 정산은 `python -m scripts.prepare_juneok_settlement_demo`의 normal.pdf를 ‘미리 생성한 가상 예시’로 소개합니다. 실제 농가 사례나 현장 즉석 실행으로 표시하지 않습니다. 자료 탐색/역산은 기존 product-demo 예시를 보조로 사용합니다.
- 자연어는 인터넷·키가 준비된 경우 한 과업만 실행합니다. 느리거나 실패하면 같은 카드 계산으로 전환하며, 미리 저장한 PDF를 쓰면 그 사실을 말합니다. 실패 화면을 오래 붙잡고 숨기지 않습니다.
- 주 시연에서 과거 자료 조회는 결과 영역을 바꿉니다. 경제성 PDF를 보여주기 전 다시 조건 비교를 눌러 원하는 보고서를 만듭니다. 정산은 별도 기록/영역이며 현재 가정과 실제 결과 대조 C는 미구현입니다.

## 주장과 근거

공식 취지·지정 자료·외부 의존성/출처·제출 한계는 [공식 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge), 팀 방향은 [11/03 합의 기록](https://app.notion.com/p/40d34713f16781f2a368c4b4746ea08b)에 근거합니다. #855 수치는 현재 CSV의 도구 조회값이며 출처/관측범위는 화면 보고서에서 확인합니다. 계산 정답은 비교 도구/독립 검산, 정산 근거는 [A+B 검증](../검증/2026-11-09_실제출하와정산검산.md), 발표 정리 후 판정은 [발표 정리 검증](../검증/2026-11-09_발표흐름과로컬정산정리.md)에 연결합니다. 농가 효용은 이 자료로 입증하지 않습니다.
