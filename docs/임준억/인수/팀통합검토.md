## 권고 통합 순서

1. 팀이 기준 브랜치·담당·대표 진입점을 정합니다. 인수본은 검토 가능한 후보입니다.
2. 공통 CSV·전처리를 고정하고 각 기능의 출처와 기여를 보존합니다.
3. 상태·계산·하네스를 선택한 뒤 같은 역할을 중복 호출하지 않도록 정리합니다.
4. 정현 과거가격 도구를 포함한다면 어댑터·도구 schema·상태/경고 렌더링·CSV 버전을 연결합니다. 현재 후보에 연결된 기능은 아닙니다.
5. 개인 후보의 최신 188개 기준 중 적용되는 계약, 각 팀원의 기존 검사, 동일 입력의 결과를 대조합니다. 바뀐 경로의 실제 모델·패키지를 재검증합니다.
6. 팀 최종 설명자료·기여표·시연·ZIP을 같은 버전으로 고정합니다.
