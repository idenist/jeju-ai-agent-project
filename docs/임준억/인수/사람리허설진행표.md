# 팀 시연·사용성 리허설 진행표

2026-11-09 준비 / 실제 참여자·실행 결과 미기록. [시연 대본](시연진행안.md)은 발표자용이고 이 표는 처음 사용하는 사람이 과업을 수행할 수 있는지 보는 용도입니다. 농가 참여가 없으면 농가 실증으로 표시하지 않습니다.

## 진행 방법

팀원 1명이 처음 사용하는 참여자, 다른 1명이 관찰자를 맡습니다. 목표 15~20분이며 실제 시간은 측정해 기록합니다. 역할을 나눌 사람이 없으면 사용자가 혼자 수행한 자체 점검으로 표시합니다. 관찰자는 먼저 조작법/정답을 알려주지 않고 참여자가 무엇을 찾는지 말하게 합니다. 막히면 도움 요청 시점과 제공한 도움을 기록합니다. 화면 녹화는 필수가 아니며 녹화할 경우 참여자의 동의와 키/개인정보 비노출을 확인합니다.

설치·앱 시작은 운영자 매뉴얼로 먼저 준비합니다. 기본 6개 과업은 키 없이 수행하고 자연어 과업은 키/네트워크가 준비됐을 때 별도 실행합니다. 새 비교로 시작하고 가상 입력만 사용합니다.
