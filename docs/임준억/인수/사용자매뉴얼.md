# 사용자 매뉴얼

## 실제 출하 기록·정산 검산 추가 (개인 후보)

1. 기존 조건 비교를 완료한 뒤 아래 **실제 출하 기록·정산 검산**을 엽니다. 실제로 선택한 즉시/보관 대안을 고르고 **현재 비교와 출하 기록 연결**을 누릅니다. 연결 당시 조건은 정산 수정으로 바뀌지 않습니다.
2. 기록 구분(실제라고 입력/가상/미확인), 실행일·출하/판매중량·매출·정산서 지급액·입금액 중 아는 값만 입력합니다. 판매 행 합계로 매출을 검산할 수도 있습니다. 미확인은 빈칸이며 실제 무료로 확인한 경우만0입니다.
3. 정산서 공제와 정산 밖 비용을 분리합니다. 항목 수0만으로 무료 확인이 되지 않습니다. 전체 확인 체크와 모르는 항목의 빈칸을 구분합니다. 양쪽 같은 비용범주가 있다면 서로 다른 비용인지 확인하세요. 이름만 같다고 자동 삭제하지 않습니다.
4. **정산 입력 확인·저장** 후 지급액 항등식·별도 비용 반영·입금 차이를 읽습니다. ‘입력 비용 반영금액’은 전체 순이익이 아닙니다. 출하/판매중량 차이를 자동 감모로 표시하지 않습니다. 카드 수정 중 이전 검산/다운로드·대화 금액은 숨깁니다.
5. 수치 옆 [입력-…]/[계산-…]를 **정산 근거 보기**에서 확인합니다. 개인 JSON에는 입력·이력·같은 계산 근거가 포함되며 가져올 때 다시 검산합니다. 해시는 작성자·원문 진위를 증명하지 않습니다. **정산 PDF 준비** 후 개인 PDF를 저장합니다.
6. 대화에서 ‘확인한 정산 기록을 검산해줘’라고 요청하면 같은 로컬 계산 결과를 표시합니다. 별도 전송 동의 체크는 없습니다. 카드에 저장한 상세 정산값·근거는 모델 이력에 넣지 않습니다. 사용자가 직접 입력한 채팅과 기존 출하 비교 조건은 일반 모델 입력이므로 구분하세요. 새로운 실제 금액은 카드에서 확인·정정합니다.
7. 브라우저 세션 종료 전 필요한 개인 JSON을 내려받으세요. 서버 자동 저장은 하지 않습니다. 복원은 현재 기록을 대체하므로 확인 체크가 필요합니다. ‘새 비교 시작’은 출하 기록도 초기화합니다. 대화만 비우기는 기록을 유지합니다.

원문 정산서·이름·계좌·연락처를 입력하지 마세요. 개인 JSON/PDF의 금액은 공유 전 검토해야 하며 공식 제출·공개 시연은 가상 자료로만 합니다. 반품·음수 보정·추가 정산·복수 날짜 출하·은행 확인·기존 가정과 실제 결과 대조는 첫 버전 범위 밖입니다. 기존 비교 JSON v1/v2와 개인 출하·정산 JSON v1은 다른 파일입니다.

## 자료 탐색·역산·변경 검토 추가

- **확보 자료 탐색·선택 · 키 없이 사용:** 경매/출하 자료를 고르고 실제 후보에서 조건을 좁힙니다.20개씩 페이지를 넘길 수 있습니다. 상위 조건을 바꾸면 하위 선택을 다시 확인합니다. 후보를 직접 선택한 뒤 관측자료 조회를 누르세요. 날짜·품질·코드 모호성을 확인하며 현재 제시가격은 자동 변경되지 않습니다.
- **제안가격에서 허용 감모·보관비 확인:** 보관 대안·제안단가/가정을 입력하고 풀 항목 하나를 선택합니다. 다른 조건이 부족하면 질문합니다. 가상3300원에서 감모7.67%와 일 보관비100285원은 서로 다른 고정 조건의 상한이며 동시에 적용하는 조합이 아닙니다. 실제 감모·비용은 자동 저장되지 않습니다.
- **비교 건 저장·불러오기 → 비교 파일 확인 → 현재 조건과 변경 사항 검토 · 복원하지 않음:** 저장 파일과 현재 조건을 나란히 검토합니다. 과거 보관 숫자를 재사용하지 않고 두 조건을 현재 계산 규칙으로 다시 계산합니다. 가격/비용 기준이 다르면 단가 차이를 생략합니다. 조건 복원 버튼은 별도입니다.

대화에서도 “어떤 실제 규격이 있나?”, “3300원 가정이면 감모 몇%까지 가능한가?”, “선택한 파일과 지금의 변경을 검토해줘”라고 요청할 수 있습니다. 기준 파일이 없으면 앱에서 선택해야 합니다. 이번 역산 단가는 매 요청에서 확인하며 장기 사용자 프로필로 자동 저장하지 않습니다. 예시 PDF4종은 인수본의 기능확장시연자료/에 있습니다.

준비된 CSV로 감귤 출하 조건을 비교하고 결과를 저장하는 안내입니다. 설치와 키·자료 교체는 [운영자 매뉴얼](운영자인수매뉴얼.md)을 봅니다. 아래 수치는 모두 가상 시연 조건입니다.

## 1. 시작하기

run-juneok.cmd를 실행하고 표시된 주소를 브라우저로 엽니다. 처음에는 `가상 예시 조건 불러오기`로 동작을 볼 수 있습니다. 자연어 대화는 모델 키가 필요하지만 조건 카드·과거자료·PDF는 키 없이 사용할 수 있습니다.

배포 자료의 관측일을 확인하세요. 현재 경매 CSV의 마지막 관측은 2026-11-06이고 #855 출하통계는 2018-01-01~2025-09-17입니다. 실시간 시세·현재 공급량이 아닙니다.

## 2. 아는 조건 입력하기

대화에 물량·실제 제시가격 또는 직접 정한 가정·비용·보관기간을 말하거나 `조건 직접 입력·수정`을 엽니다. 대화와 조건 카드는 같은 확정 조건을 사용합니다.

- 가격은 수수료 차감 전/후와 이미 반영된 비용을 구분합니다.
- 감모율은 하루 비율이 아니라 해당 보관기간 전체 비율입니다.
- 하루 보관비는 전체 물량의 비용입니다.
- 모르는 값은 빈칸·미확인으로 둡니다. 실제 무료라고 확인한 경우에만 0입니다.
- 저장 가능 여부와 출하일 변경 가능 여부를 별도로 확인합니다.

가상 예시 버튼은 물량 3,000kg·현재 3,000원/kg·7일·감모 2%·하루 보관비 20,000원·수수료만 반영·기타 고정비 양쪽 동일 제외를 불러옵니다. 이때 필요한 원 단위 최소 단가는 3,109원/kg입니다. 이는 미래에 받을 가격이나 농가 전체 순이익이 아닙니다.

## 3. 조건 수정하기

감모 2를 4로 바꾸고 Enter 또는 다른 항목으로 이동하면 미저장 수정으로 표시됩니다. `입력 조건 비교`를 눌러 적용하면 최소 단가는 3,174원/kg으로 바뀌고 물량·현재 단가는 유지됩니다.

적용 전에는 현재 결과·다운로드가 숨겨지고 대화를 보낼 수 없습니다. 적용하거나 `편집 취소 · 현재 조건 불러오기`로 취소하세요. 편집 중 다른 조건 버전이 생기면 현재 조건을 다시 불러와야 합니다.

기간을 바꾸면 감모 확인이 해제됩니다. 새 기간 전체의 감모를 확인하고 체크한 뒤 저장하세요. 같은 감모 값이라도 기간이 다르면 자동 승계하지 않습니다.

## 4. 모르는 미래를 가정으로 비교하기

`내 가정 범위로 비교하기`에서 감모 가정 1,2,4와 미래 단가 가정 3000,3300을 입력하고 `가정 범위 비교`를 누릅니다.6조합이 나옵니다. 미래 3300원/kg 가정에서 지금 대비 차이는 감모1/2/4% 순서로 661,000 / 562,000 / 364,000원입니다. 원래 저장한 감모 4%가 이 표 때문에 변경되지는 않습니다.

미래 단가를 입력하지 않으면 필요한 최소 단가만 비교합니다. 사용자가 지정한 범위일 뿐 예측·확률·자동 권고가 아닙니다.

## 5. 과거 출하자료 확인하기

`과거 출하통계 직접 조회 · 키 없이 사용`에서 출하 품종·월·연도를 정하고 조회합니다. 노지온주·11월·2018~2024년은 실제 과거 관측을 보여줍니다.2025~2025년은 관측자료 없음이며 0톤이라는 뜻이 아닙니다. 경매의 조생귤을 출하의 노지온주로 자동 대응시키지 않습니다.

이 조회는 공유 입력 조건을 바꾸지 않으며 결과 영역은 방금 조회한 결과로 바뀝니다. 비교 보고서가 필요하면 조건 카드를 다시 비교하세요.

## 6. 보고서 읽고 저장하기

`결과와 보고서 미리보기`에서 조건·버전·수치·출처를 확인한 뒤 `PDF 보고서 내려받기`를 누릅니다. 기본 예시는 1페이지입니다. 긴 표는 여러 페이지가 됩니다. 하단의 `이용 안내 및 확인사항`에서 비용·가정·산출 기준을 함께 읽으세요. 문서ID는 내용 식별자이며 기관 인증이 아닙니다. MD는 보조 형식입니다.

PDF 생성에 실패해도 조건과 미리보기는 남습니다. 운영자에게 글꼴과 설치 상태 확인을 요청하세요. 입력·자료가 바뀐 뒤에는 다시 계산/조회한 결과를 저장합니다.

## 8. 자료와 조건을 한 번에 검토하기

`자료와 조건을 함께 검토하기`에서 출하통계 품종·월·연도를 명시하고 `출하 검토 브리핑 만들기`를 누릅니다. 선택한 품종·기간만 조회하고 경매 품종에서 출하 품종을 자동 추정하지 않습니다. 품종 미선택·미관측·조회 오류는 부분 검토에 남으며 계산 가능한 결과는 함께 제공합니다.

경매 참고는 선택 항목입니다. 체크한 경우 시장코드·경매 품종·등급·크기·포장·포장중량을 입력합니다. 조회가격이 현재 농가 제시가격으로 자동 저장되지는 않습니다. 가정 범위를 포함하려면 기존 범위 입력란에 직접 정한 목록을 입력한 뒤 체크합니다.

## 9. 판단이 바뀌는 조건 설명

`내 가정 범위로 비교하기`에서 대안·감모·미래단가 목록을 정하고 `판단이 바뀌는 조건 설명`을 누릅니다. 1,2,4%와 3000,3300원/kg 예시는 최소단가 3,078~3,174원/kg와 각 조합의 금액 차이를 보여줍니다. 목록을 비우면 저장된 조건만 설명합니다. 유리한 조합도 저장·계약 제약이 해결됐다는 뜻은 아닙니다.

## 10. 비교 건 저장·복원

사이드바 `비교 건 저장·불러오기`에서 이름을 붙이고 `비교 JSON 내려받기`로 로컬에 보관합니다. 조건·입력 구분·최대 100개 이력·자료 버전·당시 결과를 담습니다. 대화·API 키는 담지 않습니다. 파일은 암호화하지 않으므로 개인·계약 정보를 이름에 쓰지 마세요.

`저장한 비교 JSON` 선택 → `비교 파일 확인` → 이름·시각·자료 환경 변경 확인 → `확인한 조건 복원 · 현재 기준 재계산` 순서입니다. 확인만으로 조건이 바뀌지 않습니다. 복원은 현재 조건을 대체하고 대화를 비웁니다. 당시 결과는 보관 기록이며 현재 결과로 실행하지 않습니다. 복원된 조건은 현재 세션 버전으로 다시 계산합니다. 부분 입력은 추가 입력 필요로 남습니다.

1MiB 이하 지정 JSON만 지원합니다. 형식·버전·중복 필드·유한하지 않은 숫자·조건 오류·해시 불일치는 거부합니다. 해시는 내용 일치 검사이며 작성자 인증이 아니고 가져온 입력의 진실성을 보장하지 않습니다. 편집 중에는 저장·복원을 막습니다. 실제 결과 정산·자동 학습·농가 계정 저장은 이번 범위에 없습니다.

## 이번 검토의 맥락과 복구 · 2026-11-09

대화와 조건 카드는 같은 조건과 과업 맥락을 사용합니다. 결과 옆 **이번 검토의 선택과 미확인 사항**을 펼치면 조회 품종/기간·가정 목록·남은 확인항목을 확인할 수 있습니다. 과거 조회조건은 최신 시세나 농가의 장기 프로필을 뜻하지 않습니다. 보관기간을 바꾸면 새 기간의 감모와 가정을 다시 확인합니다.

동일 호출 반복·요청 한도·시간/입력 초과는 연결 장애와 구분해 안내합니다. 완료된 부분 결과는 확인할 수 있지만 요청 전체가 완료됐다는 뜻은 아닙니다. 조건을 확인해 질문을 나누거나 새 요청으로 다시 실행하세요. 인증/연결 장애는 운영자에게 설정 확인을 요청합니다.

비교 저장은 JSON v2로 조건과 이번 검토의 선택을 함께 저장합니다. 기존 v1도 불러올 수 있고 과거 결과는 현재 자료로 다시 계산합니다. **대화만 지우기**는 조건·맥락을 유지하고 **새 비교 시작 · 조건도 초기화**는 모두 새로 시작합니다. 가상 예시 불러오기도 이전 맥락을 초기화합니다. 이전 프로그램은 새 v2 파일을 읽지 못할 수 있으므로 최신 인수본을 사용하세요.
