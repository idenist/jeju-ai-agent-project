# 사용자 매뉴얼

준비된 CSV로 감귤 출하 조건을 비교하고 결과를 저장하는 안내입니다. 설치와 키·자료 교체는 [운영자 매뉴얼](운영자인수매뉴얼.md)을 봅니다. 아래 수치는 모두 가상 시연 조건입니다.

## 1. 시작하기

run-juneok.cmd를 실행하고 표시된 주소를 브라우저로 엽니다. 처음에는 `가상 예시 조건 불러오기`로 동작을 볼 수 있습니다. 자연어 대화는 모델 키가 필요하지만 조건 카드·과거자료·PDF는 키 없이 사용할 수 있습니다.

배포 자료의 관측일을 확인하세요. 현재 경매 CSV의 마지막 관측은 2026-11-06이고 #855 출하통계는 2018-01-01~2025-09-17입니다. 실시간 시세·현재 공급량이 아닙니다.

## 2. 아는 조건 입력하기

대화에 물량·실제 제시가격 또는 직접 정한 가정·비용·보관기간을 말하거나 `조건 직접 입력·수정`을 엽니다. 대화와 조건 카드는 같은 확정 조건을 사용합니다.

- 가격은 수수료 차감 전/후와 이미 반영된 비용을 구분합니다.
- 감모율은 하루 비율이 아니라 해당 보관기간 전체 비율입니다.
- 하루 보관비는 전체 물량의 비용입니다.
- 모르는 값은 빈칸·미확인으로 둡니다. 실제 무료라고 확인한 경우에만 0입니다.
- 저장 가능 여부와 출하일 변경 가능 여부를 별도로 확인합니다.

가상 예시 버튼은 물량 3,000kg·현재 3,000원/kg·7일·감모 2%·하루 보관비 20,000원·수수료만 반영·기타 고정비 양쪽 동일 제외를 불러옵니다. 이때 필요한 원 단위 최소 단가는 3,109원/kg입니다. 이는 미래에 받을 가격이나 농가 전체 순이익이 아닙니다.

## 3. 조건 수정하기

감모 2를 4로 바꾸고 Enter 또는 다른 항목으로 이동하면 미저장 수정으로 표시됩니다. `입력 조건 비교`를 눌러 적용하면 최소 단가는 3,174원/kg으로 바뀌고 물량·현재 단가는 유지됩니다.

적용 전에는 현재 결과·다운로드가 숨겨지고 대화를 보낼 수 없습니다. 적용하거나 `편집 취소 · 현재 조건 불러오기`로 취소하세요. 편집 중 다른 조건 버전이 생기면 현재 조건을 다시 불러와야 합니다.

기간을 바꾸면 감모 확인이 해제됩니다. 새 기간 전체의 감모를 확인하고 체크한 뒤 저장하세요. 같은 감모 값이라도 기간이 다르면 자동 승계하지 않습니다.

## 4. 모르는 미래를 가정으로 비교하기

`내 가정 범위로 비교하기`에서 감모 가정 1,2,4와 미래 단가 가정 3000,3300을 입력하고 `가정 범위 비교`를 누릅니다.6조합이 나옵니다. 미래 3300원/kg 가정에서 지금 대비 차이는 감모1/2/4% 순서로 661,000 / 562,000 / 364,000원입니다. 원래 저장한 감모 4%가 이 표 때문에 변경되지는 않습니다.

미래 단가를 입력하지 않으면 필요한 최소 단가만 비교합니다. 사용자가 지정한 범위일 뿐 예측·확률·자동 권고가 아닙니다.

## 5. 과거 출하자료 확인하기

`과거 출하통계 직접 조회 · 키 없이 사용`에서 출하 품종·월·연도를 정하고 조회합니다. 노지온주·11월·2018~2024년은 실제 과거 관측을 보여줍니다.2025~2025년은 관측자료 없음이며 0톤이라는 뜻이 아닙니다. 경매의 조생귤을 출하의 노지온주로 자동 대응시키지 않습니다.

이 조회는 공유 입력 조건을 바꾸지 않으며 결과 영역은 방금 조회한 결과로 바뀝니다. 비교 보고서가 필요하면 조건 카드를 다시 비교하세요.

## 6. 보고서 읽고 저장하기

`결과와 보고서 미리보기`에서 조건·버전·수치·출처를 확인한 뒤 `PDF 보고서 내려받기`를 누릅니다. 기본 예시는 1페이지입니다. 긴 표는 여러 페이지가 됩니다. 하단의 `이용 안내 및 확인사항`에서 비용·가정·산출 기준을 함께 읽으세요. 문서ID는 내용 식별자이며 기관 인증이 아닙니다. MD는 보조 형식입니다.

PDF 생성에 실패해도 조건과 미리보기는 남습니다. 운영자에게 글꼴과 설치 상태 확인을 요청하세요. 입력·자료가 바뀐 뒤에는 다시 계산/조회한 결과를 저장합니다.

## 7. 초기화·문제 해결

| 상황 | 할 일 |
| --- | --- |
| 아는 값이 반복 질문됨 | 카드의 현재 값·누락·가격 기준·비용 확인 여부 확인 |
| 숫자를 바꿨는데 보고서가 없음 | 미저장 수정 적용 또는 취소 |
| 입력 오류 | 표시한 필드 수정. 수수료를 이중 차감하지 않기 |
| 자료 없음 | 품종/기간/규격과 관측범위 확인.0으로 채우지 않기 |
| 모델 연결 실패 | 운영자가 키·모델 접근·HTTPS 확인. 키 없이 카드 계산은 계속 사용 |
| 대화만 새로 시작 | `대화만 비우기 · 조건 유지` |
| 조건도 새로 시작 | `새 비교 시작 · 조건도 초기화` |

실제 출하 실행 전에는 제시가격·보관비·감모·저장시설·계약·납기·출하일 변경 가능성을 관계자에게 확인하세요. 이 매뉴얼은 실제 농가 사용성 검증 완료를 뜻하지 않습니다.
