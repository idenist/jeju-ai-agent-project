기준일: 2026-11-09 KST / 임준억 개인 구현 / 로컬 dev/juneok / 공통 main 28e8af97 기반. 팀에 실제 전달·승인·통합한 상태가 아니라 검토용 로컬 인수 후보입니다.

## 먼저 확인할 것

이 후보는 감귤 출하 시점을 조정할 수 있는 사용자가 지금 출하와 보관 후 출하의 필요한 가격 조건을 비교하는 Agent입니다. 대화와 조건 카드는 한 Python 상태를 사용하고, 실제 CSV 조회와 계산 도구의 결과를 미리보기/PDF로 제공합니다. 미래가격 예측·최적 출하일·농가 수익 개선을 입증한 자동 권고는 아닙니다.

일반 사용자는 배포 자료로 바로 시작합니다. 키 없는 조건 카드·통계·PDF와 키가 필요한 자연어 대화를 구분하세요. DATA_GO_KR_KEY는 개발/운영자의 사전 수집에만 사용합니다.

## 최소 실행

ZIP을 쓰기 가능한 폴더에 풀고 그 안에서 setup-center.cmd를 실행한 다음 run-juneok.cmd를 실행합니다. Python 3.13과 Python launcher가 필요하며 최초 설치는 패키지 저장소에 접근해야 합니다. 키를 넣기 전에도 비교·CSV 조회·PDF는 사용할 수 있습니다. 자세한 명령과 환경 차이는 운영자 매뉴얼에 있습니다.

공유 인수 ZIP에 `시연자료/`가 있으면 검증한 가상 예시의 PDF·MD·JSON이 들어 있습니다. 없으면 다음 명령으로 생성할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.prepare_juneok_handoff_demo
```

이 명령은 외부 HTTP를 차단하고 실제 모델/데이터 API를 호출하지 않습니다. 모델 장애 사례는 명시적인 모의 전송 실패이며 실제 서비스 실패나 실제 모델 성능으로 소개하지 않습니다. 결과는 artifacts/handoff-demo/latest.json과 실행별 폴더에 저장됩니다.
