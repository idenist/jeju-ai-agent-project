# UI 잔존 문제 수정 기록

기준: 2026-11-17, UI/UX 개편 계획 v1.1과 실제 빈 화면 제보.

## 이번 수정

| 문제 | 원인과 조치 | 관련 계획 번호 |
|---|---|---|
| 첫 화면 입력창·예시 버튼이 사라짐 | 상태를 추적하지 않는 안쪽 탭의 `open=None`을 닫힘으로 판정했다. 안쪽 탭도 선택 상태를 추적하고, 바깥 탭까지 함께 판단하도록 수정했다. | 04, 07 |
| 첫 화면에서 시작할 위치가 불명확함 | 설명·질문 예시·입력창을 제목 아래에 배치했다. 대화가 시작된 뒤에는 입력창을 하단에 고정한다. | 07 |
| 미래가격 미입력 경로가 잘 드러나지 않음 | 직접 입력을 기본으로 두고, 나중 가격을 비워 두면 최소 필요가격을 계산할 수 있다고 안내한다. | 12 |
| 시장 변경 후 이전 규격이 다시 채워짐 | 의도적으로 지운 값과 초기값을 구별한다. 사용자가 바꾼 선택은 이전 제출값으로 덮어쓰지 않는다. | 09, 10 |
| 같은 포장중량의 표기가 달라 선택 해제됨 | 5와 5.0을 동일한 중량으로 처리한다. 선택지 표시 함수가 마지막 항목의 단위를 잘못 붙이던 문제도 수정했다. | 10 |
| 다른 화면에서 선택한 규격과 현재 입력 불일치 | 명시적으로 전달된 거래규격을 동기화하고, 새 비교 시작 시 이전 시장 근거를 초기화한다. | 10, 17 |
| 자료 변경 뒤 이전 시즌 가격이 남음 | 시즌 파일 변경을 감지해 이전 조회 결과를 숨기고 재조회를 안내한다. | 17, 23 |
| 자료 오류 때 결과표 렌더링이 실패할 수 있음 | 조회 실패 상태에서는 오류 안내를 표시하고 표 렌더링을 중단한다. | 23 |
| 한글 관리자 비밀번호 오류 | 비밀번호를 UTF-8 바이트로 비교한다. 비밀번호 변경 시 기존 세션 권한도 해제한다. | 03 |

## 확인 범위

- 실제 브라우저: 첫 화면, 탭 이동, 입력 초안 유지, 실제 메시지 전송 후 하단 입력창, 390px 모바일 화면.
- 화면 캡처: `artifacts/ui-welcome-fixed.jpg`, `artifacts/ui-mobile-fixed.jpg`.
- 자동 검증: `test_ui_revision.py`의 선택 상태·관리자 접근·자료 변경·오류 표시와 기존 대화/계산/보고서 통합 테스트.
- 실행 로그: `artifacts/ui-final-checks.log`.
- 검증 결과: 관련 75개 검사 중 74개 통과. 남은 1개는 실제 자료에 없는 등급을 선택하던 테스트를 ‘등급 선택 해제 후 이전 보고서 숨김’으로 갱신해 개별 재실행 통과했다 (`artifacts/ui-final-recheck.log`).

이 기록은 UI 수정과 관련 검증 범위다. 계획서의 27개 항목 및 모든 실제 모델 대화 시나리오가 완전히 해결됐다는 판정은 아니다. 과거 답변을 펼쳐야 하는 문제는 앞서 수정된 내용을 유지했다.
