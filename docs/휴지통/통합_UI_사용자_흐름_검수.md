## 실제 검수 범위

- 신규 테스트 파일: `tests/test_integration_ui_journey.py` (12개 테스트)
- 외부 OpenAI API를 호출하지 않습니다. 대화는 모의 도구 호출로 검증합니다.
- 기존 원본 CSV·가격 비교 보고서·계산 엔진 및 Streamlit 화면 구조를 변경하지 않습니다.
- 결과는 한 번에 현재 활성 조회 또는 현재 활성 계산만 보여 줍니다. 화면이 과거 가격과 손익 계산을 동시에 자동 결합하거나 과거 변동률로 미래 단가를 채우지 않습니다.
- Streamlit 자동 테스트에서 통과해도 실제 농가·비전문가 대상의 사용성 실증을 의미하지 않습니다.
