# 통합 Streamlit 직접 가격 조회 화면 — STEP 6-1

**기준:** `integration/agents`, 커밋 `5fc869d` 이후 추가 작업

## 목적

STEP 5에서 연결한 과거 경락가격 비교 도구를 OpenAI API 키 없이 사용할 수 있게 합니다. 기존 출하 손익 계산 카드나 자연어 Agent를 대체하지 않습니다.

## 사용자 경로

1. 화면 상단의 **과거 경락가격** 바로가기를 선택하거나 **과거 경락가격 비교 · 직접 조회(키 없이 사용)**을 펼칩니다.
2. 품종·등급·크기·포장 종류·포장중량·비교 간격을 사용자 입력 그대로 작성합니다. 시장코드·거래방식·과거 기준일은 필요 시 지정합니다. 빠진 조건은 Python 조회 도구에서 다시 확인합니다.
3. **과거 경락가격 직접 조회**를 누르면 기존 원천 전체 검증을 통과한 가격쌍을 조회합니다. 실패하면 가격을 공개하지 않습니다.
4. 결과와 Markdown·PDF 보고서는 같은 확인된 Python 결과를 사용합니다. 과거 경락가격은 농가 실수취가격·현재 제시가격·보관 후 기대수익이 아닙니다.
5. 직접 조회에 사용한 조건은 이후의 *명시적인* 자연어 후속 가격 조회에만 사용될 수 있습니다. 입력란을 바꾸기만 해서는 대화 조건이 변경되지 않으며, 조회를 다시 요청해야 반영됩니다.

## 변경 경계

- 손익 카드 `ScenarioStore`, 현재 제시가격, 미래 단가 가정, 저장 가능 여부는 직접 조회로 바뀌지 않습니다.
- 직접 조회는 과거 가격의 새 조회로 처리합니다. 과거 저장 조건이 자동으로 혼합되지 않습니다.
- 검증 실패나 잘못된 입력은 기존 가격 조회 조건을 다시 사용하지 않습니다.
- 입력란을 수정하면 해당 직접 조회의 이전 결과·다운로드가 현재 조건의 결과인 것처럼 남지 않도록 숨깁니다.
- 자료 버전 변경 또는 대화 초기화 시 기존의 Python 후속 조회 맥락도 폐기합니다.
- 정현님 B안 과거 변동 가정 단가는 이 UI에서 생성하거나 손익 비교 입력에 자동 반영하지 않습니다. 해당 기능은 별도 검증 대상으로 유지합니다.
- 모델이 없는 직접 조회에서는 새로운 OpenAI API 요청·과금이 없습니다.
