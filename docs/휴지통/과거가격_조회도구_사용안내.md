# 과거 가격 조회 도구 (정현)

## 구현 범위

사용자가 지정한 동일 조건의 과거 3·7·14일 가격 비교와 비교 가능성 검사를 구현했다.
추가 패키지·네트워크·API 키 없이 실행한다. 자연어 대화, LLM 연결, 손익 계산,
허브 출하량 분석은 이 도구에 아직 연결하지 않았다.

`seunghyuk` 브랜치의 기존 가격 조회·손익 계산은 수정하지 않았다.
그 브랜치의 `compare_shipping`에도 최근 관측일 대비 N일 전 비교가 있다.
이 도구는 지정 조건의 과거 날짜쌍 전체와 경고·누락 건수를 함께 조회한다.

## 실행

저장소 최상위 폴더에서 Python으로 호출한다.

```python
from agents.jeonghyeon.price_history import execute_tool

result = execute_tool("get_price_history", {
    "market_code": "110001",
    "variety": "조생귤",
    "grade": "특",
    "size": "소",
    "package": "상자",
    "package_kg": 5,
    "trade_type": "경매",
    "interval_days": 7,
    "limit": 5,
})
print(result)
```

`base_date: "2026-10-19"`를 추가하면 기준일 하나만 조회한다.
입력 데이터 기본값은 `data/processed/price_comparison_availability.csv`다.
가격 자료가 갱신되면 `python scripts/build_price_comparisons.py`를 먼저 실행한다.

## 반환 결과와 에이전트 연결

| 상태 | 에이전트의 처리 |
|---|---|
| `NEEDS_CLARIFICATION` | `missing_fields`와 `choices`를 보고 빠진 조건 질문 |
| `OK` | 경고 없는 사례와 가격 변동 범위 설명 |
| `NO_CLEAN_COMPARISON` | 경고 있는 쌍과 비교 불가 사유 설명. 미래 수치 생성 금지 |
| `NO_DATA` | 지정 조건 또는 기준일의 기록 없음 안내 |
| `INTERVAL_NOT_AVAILABLE` | 파일에 확보된 비교 간격 안내 |
| `AMBIGUOUS_CODES` | 같은 표시명의 코드 대응 확인. 서로 다른 코드를 합산하지 않음 |
| `ERROR` | 입력 또는 파일 오류 해결 후 재시도 |

`clean_pairs`는 지정 조건에 해당하는 전체 경고 없는 날짜쌍 수다.
`examples`는 그중 기준일 최신순 최대 `limit`개(기본 5, 최대 20)다.
표시 제한을 바꿔도 전체 건수와 변동 범위는 바뀌지 않는다.
경고 있는 쌍은 기본 사례와 변동 범위에서 제외하고 경고 건수는 별도로 반환한다.
`unavailable_reasons`는 비교 불가 사유별 건수다. 자료 없음과 0% 변동을 구분한다.
가격은 원/kg, `clean_change_range_pct`는 % 단위 문자열이다.

기존 에이전트에 연결하려면 도구 스키마 등록, 실행 분기,
최종 결과 표시 분기를 함께 추가해야 한다. 이 함수 추가만으로 LLM이 자동 호출하지 않는다.

## 해석 기준

- 조생귤 전체의 사례 수를 특정 등급·크기·포장 조건의 사례 수로 표시하지 않는다.
- 시장·거래방식은 자료 전체의 값이 하나일 때만 자동 적용하고 `applied_defaults`와 안내 문구로 표시한다. 사용자가 지정한 값은 바꾸지 않는다.
- 품종·등급·크기·포장·중량은 후보가 하나여도 되묻는다.
- 간격은 1~366 사이 정수를 받는다. 파일에 없는 간격(예: 10일)은 `INTERVAL_NOT_AVAILABLE`, 잘못된 값은 `ERROR`다.
- `source`는 저장소 내부 파일은 상대 경로, 외부 파일은 파일명으로 표시한다.
- 과거 관측값이며 미래 가격, 보관 효과, 성공 확률을 뜻하지 않는다.
- 겹치는 날짜쌍이 있어 독립 표본 수로 해석하지 않는다.
- 허브 출하량을 아직 사용하지 않으므로 이 도구만으로 대회 필수 데이터 활용을 충족했다고 주장하지 않는다.

## 검증

`python -m unittest discover -s tests -v`

조건별 필터링, 경고 제외, 누락일 처리, 입력 확인, 코드 모호성,
표시 제한, 중복 자료 거부, 실제 CSV 조건별 건수를 검증한다.
