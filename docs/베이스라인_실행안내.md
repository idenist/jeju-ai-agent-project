# 감귤 출하 시점 비교 베이스라인 실행 안내

## 1. 목표

가격 CSV 조회 → 동일 조건의 최근 경락가격 확인 → 보관비·감량률 반영 → **지연 출하 손익분기 가격** 계산까지 실행한다.

현재 버전은 **LLM을 연결하기 전의 분석 엔진**이다. 아직 자연어 질문을 처리하는 AI Agent나 미래 가격 예측 모델이 아니다. 먼저 결정적인 숫자 계산이 정확한지 검증한다.

## 2. 파일 배치

ZIP에 포함된 파일을 프로젝트 루트에 배치한다. `data/processed/daily_prices.csv`는 기존 저장소에 있는 파일을 그대로 사용한다.

```text
jeju/
├── agents/
│   └── baseline.py
├── data/
│   └── processed/
│       └── daily_prices.csv   # 기존 전처리 산출물
├── docs/
│   └── 베이스라인_실행안내.md
└── tests/
    └── test_baseline.py
```

Python 3.10 이상이 필요하며 이 베이스라인 자체에는 별도 라이브러리 설치가 필요 없다.

## 3. 바로 실행하기

프로젝트 루트에서 다음 명령어를 실행한다.

```powershell
python agents/baseline.py --variety 조생귤 --grade 특 --size 소 --package-kg 5 --quantity-kg 3000 --days 7 --storage-cost-per-day 20000 --loss-pct 2
```

현재 CSV에서는 동일한 조건의 가장 최근 가격(2026-11-03, 서울가락)을 조회한다. 출력되는 가격은 **현재 실시간 시세가 아닌 가장 최근 확보된 관측값**이다.

미래 가격이 2,500원/kg이라는 **가정**을 비교하고 싶다면 끝에 다음 옵션을 덧붙인다.

```powershell
--future-price-kg 2500
```

사용자가 실제 출하 견적을 알고 있다면 다음 옵션으로 기준 가격을 직접 입력할 수 있다.

```powershell
--current-price-kg 3000
```

다른 날짜까지의 정보만 사용하려면 다음 옵션을 활용한다.

```powershell
--as-of 2026-10-23
```

## 4. 계산 기준

- 지금 출하 판매금액 = 현재 기준가격 × 전체 출하 물량
- 지연 후 판매 가능 물량 = 전체 물량 × (1 − 전체 보관기간 감량률)
- 추가 보관비 = 하루 보관비 × 지연 일수
- **손익분기 가격 = (지금 출하 판매금액 + 추가 보관비) ÷ 지연 후 판매 가능 물량**
- 원/kg 가격을 정수로만 표시할 경우 **손익분기 가격을 올림**해 필요한 최소 단가를 안내한다. 계산 내부에서는 가격을 반올림하지 않는다.
- 가격 변동은 정확히 지정된 일수만큼 떨어진 **과거 동일 조건 관측일**이 존재할 때만 보여준다.

운송비, 수수료 등 **두 출하 방식에서 동일한 비용은 비교에서 제외**한다. 보관 후 재선별·추가 운송 등이 발생한다면 그 비용도 추가로 입력하도록 후속 확장해야 한다.

## 5. 계산 검증

```powershell
python -m unittest discover -s tests -v
```

실제 경매가격을 활용한 실행 시험과, 3톤·3,000원/kg·7일·하루 2만 원·2% 손실 조건의 계산 시험을 수행했다.

## 6. 해석상 주의

1. **미래 가격을 예측하지 않으므로 무조건 '기다리라/지금 출하하라'고 권고하지 않는다.**
2. 경락가격은 생산자가 실제 받는 순수취액이 아니다.
3. 품종·시장·등급·크기·포장 종류·포장중량이 같은 거래만 조회한다. 결측치는 임의로 채우지 않는다.
4. 보관비·감량률은 사용자 입력값이며, 실제 보관 환경과 맞는지는 별도 확인이 필요하다.
5. 기존 경매자료는 2026년 10월~11월 서울가락시장 한 곳의 자료이므로 계절 전체 예측에 사용하지 않는다.

다음 개발 단계는 이 함수들을 **최소한의 LLM Tool Calling**에 연결해 사용자의 자연어 질문을 처리하도록 하는 것이다. 그 단계에서도 경락가격 조회와 금액 계산은 Python 함수가 담당한다.
