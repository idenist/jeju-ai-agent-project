# 2차 리팩토링 — 운영 기준

- 기준 브랜치: `refactor/lean-mvp` (1차 기준 `e381f768`의 후속 패치)
- `app.py`는 Streamlit 진입점만 담당합니다.
- `ui/application.py`는 전체 화면 배치만 담당하고, 세션 동작은 `ui/context.py`로 분리했습니다.
- `ui/chat.py` 및 `ui/panels.py`는 `ui/application.py`를 import하지 않습니다.
- `agents/`는 AI 입력 해석·도구 호출·대화 상태를 담당합니다.
- `services/`는 경제성 계산·원천자료 조회·무결성 검증을 담당하며 `agents/`와 `ui/`를 import하지 않습니다.
- `presenters/`는 Streamlit과 무관한 텍스트·표·보고서 표현 규칙입니다.
- `core/`는 공통 설정과 입력 provenance 등 낮은 수준의 공통 정의입니다.
- `evals/`는 모델 평가셋과 평가용 품질 점검을 담당합니다.

## 검증

```cmd
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
.venv\Scripts\python.exe -m scripts.evaluate_integrated_agent --validate
.venv\Scripts\python.exe -m scripts.verify_integration_handoff --offline-only
```

- `--offline-only` 성공은 실제 모델 호출을 의미하지 않습니다.
- 실제 모델 E2E 증빙은 별도 실행·채점·해시 검증이 필요합니다.
- 기존 평가 기록은 코드 해시가 변경됐으므로 현행 코드의 통과 증빙으로 재사용할 수 없습니다.
- 기능 삭제·가격 예측·출하 실행 추천은 이번 구조 정리 범위에 포함하지 않습니다.
