# 제주 감귤 출하 Agent 제품방향 재정렬 계획

작성 기준일: 2026-11-16  
기준 브랜치/커밋: `refactor/lean-mvp` / `47b10c3113df96c0a9eaeff294bbba90cb93c6d9`

## 목표

사용자가 보유 물량과 출하 후보를 자연어로 말하면, 허용된 시장 가격자료에서 후보일 가격을 전망하고 보관비·감모·수수료를 반영해 **어떤 조건에서 어느 출하안이 유리한지** 설명한다. 전망이 검증되지 않았거나 자료가 맞지 않으면 최적 날짜를 단정하지 않고, 손익분기 가격과 조건별 비교로 이어간다.

LLM은 사용자의 의도와 조건을 이해하고 필요한 자료·도구를 선택하며 결과를 설명한다. 가격 전망은 검증된 통계/모델 도구가, 금액 계산은 Python 계산 경로가 맡는다. LLM이 가격이나 금액을 창작하지 않는다.

## 사용자에게 보일 두 경로

사용자가 과거 가격 조회를 제한하지 않은 출하 판단 질문에서는 가격자료 사용을 기본 경로로 삼는다. 거래규격이 맞는지 확인하고, 데이터가 맞지 않으면 자동으로 다른 규격을 골라 쓰지 않는다.

### 가격자료 사용이 허용된 비교

1. 사용자가 말한 물량·후보일·품종/규격을 추출한다.
2. 같은 거래규격의 가격자료를 자동 탐색한다. 자료를 임의 매핑할 수 없을 때만 핵심 규격을 확인한다.
3. 해당 예측기간·규격의 시간순 검증을 통과한 전망만 사용한다.
4. 후보별 예상가격/불확실성, 판매 가능 물량, 비용 차감 후 비교금액, A/B 우위가 뒤집히는 조건을 제시한다.
5. 출처·관측일·검증 상태와 경락가격/농가 실수취액의 차이를 함께 밝힌다.

### 과거 가격자료를 사용하지 말라는 요청

가격자료를 조회하거나 전망값으로 대체하지 않는다. 사용자가 준 가격 가정으로 계산하고, B안 단가를 모르면 가능한 손익분기 가격부터 제시한다. 비용·감모가 미확인인 경우 0으로 처리하지 않고, 조건부 결과·범위 또는 한 가지 핵심 확인 질문으로 이어간다.

## 현재 확인된 상태

- 수정 전 기본 미래 A/B 대화는 사용자가 과거 가격 근거를 요청한 경우에만 가격 이력 경로를 선택했다. 제품 의도와 반대여서 이번 변경에서 기본 경로를 뒤집는다. B안 단가를 사용자가 직접 정했거나 과거 가격을 명시적으로 제외한 경우에만 과거 가격 경로를 생략한다.
- 실험용 가격 예측은 CLI에서만 연결되고 일반 채팅 UI에는 기본 제공되지 않는다. 이 저장소의 학습 모델 산출물 디렉터리는 없으며 데이터 계약은 `LABELED_DATA_NOT_TRAINED_MODEL` 상태다.
- 기존 예측 데이터 계약은 3·7·14일만 포함한다. 10일은 현재 예측 API가 지원하지 않는다.
- 3일 후와 10일 후를 비교하는 과거 가격쌍의 간격은 두 날짜 사이인 7일이다. 과거 7일 변동 사례를 손익 가정으로 보여주는 현재 A/B 경로와, 오늘에서 10일 뒤 가격을 직접 예측하는 모델 API는 다른 기능이다. 전자는 가능해도 미래 전망으로 부르면 안 된다.
- 데이터 계약의 28개 학습 후보 규격만 사용해 원본 시즌 가격에서 동일 규격·정확한 달력 날짜 쌍을 계산했다. 10일 가격쌍은 학습 시즌 743건/88 기준일, 검증 시즌 618건/87 기준일이었다. 현재가 유지 기준 MAE는 각각 584.93원/kg, 491.36원/kg이었다.
- 이번에 데이터 계약의 학습·검증 CSV를 검증하고 3·7·14일 후행 기준선을 재현 가능하게 비교했다. 인접 날짜의 상관을 고려해 날짜별 오차를 묶고 14일 이동블록으로 재표집했다. 검증 시즌에서 최근 7일 평균은 7일 간격에서만 현재가 유지보다 낮은 MAE(498.59 대 542.03원/kg)를 보였고, 날짜별 paired 차이는 -42.12원/kg(95% CI -77.54~-7.43)이었다. 3일은 +10.09원/kg(95% CI -33.20~+66.32), 14일은 -23.34원/kg(95% CI -59.72~+13.87)으로 우위가 확인되지 않았다.
- 2026-2027 부분 시즌에서 7일 최근 평균의 paired 차이는 -117.23원/kg이었다. 다만 해당 구간은 한 달뿐이라 14일 블록 4개 기준을 충족하지 못해 신뢰구간을 산출하지 않았다. 이 분할은 탐색 이력이 있어 선택 근거로도 사용하지 않는다. 7일 기준은 추가 연구 신호일 뿐, 서로 독립인 검증 시즌이 하나이고 최신 자료도 2026-11-03 관측치 기준으로 13일 늦었으므로 운영 예측을 켜지 않는다. 전체 기준선 수치와 CSV 해시는 [평가 기록](11_가격전망_기준선_평가.md)에 남겼다.
- 공통 처리 가격표의 마지막 관측일은 2026-11-03이다. 2026-11-16 기준 13일 지난 자료이므로, 이를 오늘 기준의 실시간 전망 근거처럼 표시하면 안 된다.
- 기존 모델 학습 스크립트는 실행 환경에 `scikit-learn`이 없어 시작하지 못했다. `requirements.txt`와 배포용 잠금 파일에도 해당 연구용 의존성이 없다. 의존성을 임의로 설치하거나 모델을 활성화하지 않았다.
- 사용자가 보낸 “과거 가격은 조회하지 말라” 사례에서는 이력 조회를 하지 않는 것이 맞았다. 실패는 그 뒤에 손익분기/조건부 비교 대신 누락값을 연속 질문한 점이다.

이 결과는 자료 적합성 조사이며 모델 학습·운영 승인이나 전체 사용자 평가 결과가 아니다.

## 실행 단계와 완료 기준

### 1. 제품 답변 계약 고정 — 진행 중

- [x] 가격자료 허용/금지 두 경로 구분
- [x] 기본 경로에서 가격전망이 빠지는 현재 원인 확인
- [x] 10일 자료 표본 및 단순 기준 오차 확인
- [x] 미지원 기간·오래된 자료·검증 미통과 시 예측을 가장하지 않는 fallback 정의
- [ ] 예측 오차 범위를 표시할 데이터와 보정 방식 확정

**완료 기준:** 대표 입력 하나에 대해 자료조회 여부, A/B 가격의 성격, 비교금액, 손익분기 조건, 질문이 필요한 경우를 한 장면으로 합의한다.

**구체화한 무과거자료 장면:** 3,000kg, 3일/10일, A안 3,450원/kg(차감 전), 감모 5%/7%, 수수료 10%/30%이고 B안 단가와 보관비를 모르는 경우, 실제 우열을 단정하지 않고 미확인 비용 차이 0원 기준의 참고 손익분기 가격 4,532원/kg을 낸다. B안 미확인 비용이 A안보다 10,000원 많을 때 기준 가격이 약 5.12원/kg 올라가는 민감도도 함께 보인다. 이 사례에서는 과거 가격·시장 자료를 조회하지 않는다.

### 2. 가격전망 적합성 평가

- 기존 학습 스크립트/시즌 데이터를 재사용해 3·7·14일 후보를 현재가 유지 기준과 시간순 검증한다.
- 10일은 동일 원천에서 학습/검증 표본을 만들 수 있는지 확인하고 같은 방식으로 기준선과 비교한다. 날짜가 다르거나 품질 경고가 있는 값은 채우지 않는다.
- 가격 오차뿐 아니라 방향성, 예측 오차 범위, 거래 규격별 표본 수를 본다. 동일 날짜의 여러 규격 거래는 독립 표본처럼 세지 않는다.
- 모델이 기준선보다 안정적으로 낫지 않거나 표본이 부족하면 예측 추천을 켜지 않는다. 그 경우에도 가격 가정별 손익분기 비교는 제공한다.

**현재 상태:** 3·7·14일 후행 기준선을 분할별로 계산했다. 검증 시즌에서 최근 7일 평균은 7일 기준에만 14일 이동블록 paired CI가 0 아래인 개선 신호를 보였지만, 소수 기준선을 같은 한 시즌에서 탐색한 결과라 확정적인 우위로 해석하지 않는다. 모델은 학습하지 않았고 독립 시즌이 하나뿐이며 최신 관측 자료도 오래되어 운영 추천에는 연결하지 않는다. 10일 단독 전망은 여전히 지원하지 않는다. 3일/10일 A/B의 7일 간격 과거 가격쌍 비교는 별도 참고 시나리오이며 미래 가격 전망으로 표시하지 않는다. `scikit-learn` 후보 모델은 환경에 의존성이 없어 미실행이다. 프로젝트 의존성을 변경하지 않으려고 임시 가상환경에서 설치를 시도했지만 패키지 배포본을 얻지 못했다. 다음으로 할 일은 설치 가능한 분리 실행 환경 및 최신 자료 갱신 경로를 마련하는 것이다.

**진행:** 재현 가능한 기준선 평가표를 만들었다. 현 근거로는 7일 단순 기준만 추가 연구 대상이며, 3·14일은 개선 근거가 부족하고 10일 API 전망은 지원되지 않는다. 따라서 지금의 Agent는 예측 추천을 하지 않고, 검증된 출처의 과거 가격 비교와 조건부 손익분기 비교만 제공한다.

**완료 기준:** 기간·규격별 후보 모델이 현재가 유지 기준을 검증 시즌에서 이기고, 별도 시즌 자료에서 큰 성능 붕괴가 없으며, 예측 범위가 보정된 뒤에만 제한된 운영 전망을 승인한다. 자료가 오래됐거나 규격이 다르면 전망 대신 비교 불가 이유와 손익분기를 제공한다.

### 3. Agent의 기본 비교 흐름 연결

- 과거 가격자료를 명시적으로 제외하지 않은 기본 질문에서 실제 가격자료를 먼저 확인하도록 연결했다. B안 단가를 사용자가 직접 지정한 경우는 그 가격으로 계산한다.
- 세부 규격이 없으면 실제 데이터 후보를 사용해 필요한 규격을 한 번의 메시지에 묶어 묻도록 했다. 사용자 상품과 후보를 자동 연결하지 않는다.
- 10일 전망은 평가를 통과하기 전까지 7일/14일에서 임의 보간하지 않는다.
- 미확인 비용·감모는 값으로 꾸미지 않는다. 사용자가 값을 모르면 결론을 제한하는 이유와 손익분기 경계를 먼저 보여준다.

**진행:** 자연어 비교의 가격자료 기본 정책과 필수 거래규격 확인 흐름을 코드에 반영했다. 거래규격 누락은 자료 후보를 포함해 한 번에 묻는다. 규격이 맞고 A안 가격·감모·수수료가 확인되면 과거 B−A 가격쌍을 세 가지 가정으로 계산하고, 미확인 보관비·별도비용은 추가 질문 없이 손익분기 기준과 비용 민감도로 남긴다. 이 값은 미래가격 예측 확률이나 출하 추천이 아니다. 아직 모델 가격전망은 연결하지 않는다.

**완료 기준:** 사용자가 B안 예상가격을 직접 알아내 입력하지 않아도, 데이터가 허용하는 범위에서 비교 또는 유보 이유를 받는다.

### 4. 질문 부담과 채팅 표시 개선

- 여러 입력을 이미 말한 경우 한 번에 저장하고 재질문하지 않는다.
- 결론에 영향이 큰 누락값만 질문하고, 모른다고 답하면 같은 질문을 반복하지 않는다.
- 대화 답변은 채팅 본문에 계속 보이게 한다. 이전 조건의 원시 자료/JSON만 접을 수 있다.

**진행:** 오래된 비교 답변을 접는 대신 본문에 표시하고, 이전 조건의 응답임을 짧게 표시하도록 `ui/chat.py`를 수정했다. 과거자료 기본 경로에서는 과거 가격쌍 가정과 손익분기/비용 민감도를 함께 보여준다. 사용자가 자료를 명시적으로 제외한 수동 경로에서는 미확인 B안 단가·보관비 때문에 질문을 이어가지 않고 조건부 손익분기 참고값과 비용 민감도를 보여준다. 이 경로의 화면·보고서에는 추가 다년도 시장 근거 조회도 붙이지 않는다. 어느 경로든 B안 실제 가격이 없으면 실제 우열은 판단 보류로 표시한다.

**완료 기준:** 3일/10일 대표 대화에서 반복되는 필드별 질문이 없고, 사용자가 이전 응답을 펼치지 않아도 대화 맥락을 읽을 수 있다.

### 5. 변경 검토와 사용자 시연

- 이번 목표와 직접 관련된 파일만 수정한다. 기존 미커밋 변경 4개 파일은 보존하고 별도 검토한다.
- 테스트 수를 늘리는 정리 작업, 전체 구조 재작성, 관련 없는 UI 개편은 하지 않는다.
- 이번 변경에서는 테스트를 실행하지 않았다. 구현 답변을 정적으로 검토하고 `git diff --check`만 확인한다.
- 검증되지 않은 모델 예측과 오늘 기준 실시간 가격 추천은 2단계 평가와 자료 갱신 전까지 켜지 않는다. 기본 A/B 대화에서는 과거 비교자료를 먼저 살펴보고 관측 범위·자료일·가정의 한계를 밝힌다. 과거 가격을 명시적으로 제외한 요청은 어떤 과거 가격/시장자료 조회도 하지 않는다.
- 구현 후에는 두 사용자 경로(가격자료 허용, 가격자료 금지)를 대상으로 실제 화면 답변과 자료 사용/미사용 근거를 검토한다. 일반 테스트 통과만으로 사용성 개선을 주장하지 않는다.

**완료 기준:** 같은 질문에서 사용자 입력 부담이 줄고, 데이터 기반 전망/조건부 손익 비교 중 무엇을 제공했는지 사용자가 확인할 수 있다.

## 대표 사용자 수용 시나리오

### 가격자료 조회를 허용한 경우

> “감귤 3톤이 있어요. 3일 후와 10일 후 중 언제 출하하는 게 나을까요?”

Agent는 확인 가능한 동일 규격 가격자료를 찾아 전망 가능 여부를 판단한다. 지원되는 경우 A/B 가격 전망과 불확실성, 예상 비교금액, 손익분기 조건을 한 답변에 보여준다. 10일 전망이 검증되지 않았다면 기간을 임의 대체하지 않고, 왜 추천할 수 없는지와 가능한 손익분기 비교를 알려준다. B안 가격을 농가에게 먼저 만들어 오라고 요구하지 않는다.

### 가격자료 조회를 금지한 경우

> “감귤 3톤, 3일 후와 10일 후를 비교하되 과거 가격은 보지 말아 주세요.”

Agent는 경매 가격을 조회하지 않는다. 알려진 조건으로 가능한 손익분기 가격·비용 경계를 먼저 제시하고, 결론이 크게 달라지는 미확인 조건만 묻는다. 모르는 값은 0이나 확정값으로 저장하지 않는다.

## 변경 전제

- 기존 작업 트리의 `agents/agent.py`, `agents/future_pair_state.py`, `tests/test_integration_future_pair.py`, `ui/chat.py` 변경은 이번 작업 전에 존재했다. 덮어쓰거나 되돌리지 않는다.
- 이번 작업에서 `ui/chat.py`의 과거 답변 렌더링만 추가 변경했다. 기존 변경분은 보존했다.
- 첨부된 사용성 작업지시서는 과거 가격전망 모델 추가를 범위에서 제외하지만, 사용자가 이번 대화에서 직접 밝힌 제품 목표에는 가격 흐름 기반 전망이 포함된다. 우선 기존 자료와 통계 기준선을 검증하고, 새 모델의 필요성은 평가 결과를 본 뒤 별도 판단한다.
- 예측값은 경락가격 전망이며 농가 실수취액 보장이 아니다. 검증 실패는 `추천 불가 + 손익분기 조건`으로 표시한다.
