# 04. 제주 출하량 데이터 명세서

> **기준:** 2026-11-07 · [README](../README.md) · [01 기능 명세](01_요구사항_및_기능명세서.md) · [02 시스템 설계](02_시스템_설계서.md)

## 1. 목적과 입력 데이터

- **목적:** 제주데이터허브 **#855 「신고소별 감귤류 및 만감류 출하량 통계」**를 팀 공통 분석용 CSV로 정리합니다.
- **원본 파일:** `data/raw/jeju_shipments.csv` (원본 파일명을 변경하여 저장)
- **원본 컬럼:** `출하일자`, `품종대분류`, `품종소분류`, `신고소`, `출하량`
- **원본 인코딩:** CP949. **출하량 단위: 톤(t)**.
- **환경:** Python 3.10 이상 권장, 전처리 자체에는 별도 pip 패키지가 필요하지 않습니다.

## 2. 입출력 파일과 실행 (Windows CMD)

```text
jeju/
├── data/
│   ├── raw/
│   │   └── jeju_shipments.csv
│   ├── processed/
│   │   ├── daily_shipments.csv
│   │   └── monthly_shipments.csv
│   └── reports/
│       ├── shipment_unassigned_rows.csv
│       └── shipment_quality_report.json
└── scripts/
    └── preprocess_shipments.py
```

프로젝트 최상위 폴더에서 실행합니다.

```bat
python scripts\preprocess_shipments.py
```

원본이 기존 한국어 파일명으로 저장되어 있다면 명시적으로 입력을 지정할 수 있습니다.

```bat
python scripts\preprocess_shipments.py --input "data/raw/신고소별감귤류및만감류출하량통계.csv"
```

출력 디렉터리를 지정하는 경우:

```bat
python scripts\preprocess_shipments.py --input data/raw/jeju_shipments.csv --output-dir data/processed --report-dir data/reports
```

이미 가공 CSV가 저장소에 포함되어 있으므로, **원본이나 전처리 규칙이 바뀌었을 때만 재실행**하면 됩니다.

## 3. 결과 데이터와 활용

| 파일 | 주요 컬럼 | 용도 |
|---|---|---|
| `data/processed/daily_shipments.csv` | `date`, `category`, `variety`, `shipment_tons`, `reporting_offices`, `positive_offices`, `source_rows`, `data_warning` | 품종별 **일일 출하량** 추이 |
| `data/processed/monthly_shipments.csv` | `year_month`, `category`, `variety`, `shipment_tons`, `observed_days`, `source_rows`, `data_warning` | 과거 계절별 **월간 출하 집중도** |
| `data/reports/shipment_unassigned_rows.csv` | `exclusion_reason` 및 원본 컬럼 | 날짜 누락 등 미배정 기록 보관 |
| `data/reports/shipment_quality_report.json` | 기간·전체/제외 건수·합계 검증·누락 통계 | 품질 확인 및 해석 제한 확인 |

- **집계:** 신고소별 물량을 `날짜 × 대분류 × 소분류`별로 합산합니다. 월별 집계는 날짜가 존재하는 기록만 포함합니다.
- **단위:** 모두 톤(t). kg으로 환산하려면 `shipment_tons × 1,000`입니다.
- **품종:** `노지온주`, `하우스온주`, `월동온주`, `한라봉`, `천혜향`, `레드향`을 원본대로 사용합니다. 경매 API의 `조생귤`, `극조생감귤`과 **임의 일대일 매핑하지 않습니다**.
- **미관측 날짜:** 행이 없는 날짜를 0톤으로 채우지 않습니다. 원본에서 명시된 0톤은 유지합니다.
- **중복:** `날짜 × 대분류 × 소분류 × 신고소`가 중복되면 이중 합산을 막기 위해 전처리 스크립트가 오류를 내고 중단합니다.

## 4. 결과 CSV 컬럼 명세

### `daily_shipments.csv` — 품종별 일별 출하량

| 컬럼 | 의미 |
|---|---|
| `date` | 출하일(YYYY-MM-DD) |
| `category`, `variety` | 원본 대분류·소분류 명칭 |
| `shipment_tons` | 해당 일자·품종의 신고소별 물량 합계(톤) |
| `reporting_offices` | 해당 그룹에 기록된 신고소 수(0톤 신고 포함) |
| `positive_offices` | 양의 출하량이 기록된 신고소 수 |
| `source_rows` | 집계에 반영한 원본 행 수 |
| `data_warning` | 날짜 누락 또는 부분월에 관한 주의 코드(기본 `ok`) |

### `monthly_shipments.csv` — 품종별 월별 출하량

| 컬럼 | 의미 |
|---|---|
| `year_month` | 출하 월(YYYY-MM) |
| `category`, `variety` | 원본 대분류·소분류 명칭 |
| `shipment_tons` | 해당 월의 **날짜가 있는** 원본 출하량 합계(톤) |
| `observed_days` | 원본에 기록이 존재하는 서로 다른 일자 수 |
| `source_rows` | 월간 합산에 포함된 원본 행 수 |
| `data_warning` | `unknown_date_rows_excluded_for_variety`, `source_ends_mid_month` 등 |

### 품질 보고서·날짜 미배정 기록

- `shipment_unassigned_rows.csv`: 날짜 누락·형식 오류 등 제외된 원본 행과 `exclusion_reason` 보관.
- `shipment_quality_report.json`: 원본 개수, 유효 날짜/제외 건수, 결측 물량, 일·월별 합계 일치 여부를 기록.
- 월간 `observed_days`는 **그 달 전체의 정상 출하일 수**가 아니라, 원자료에 존재한 관측일 수입니다.
- `source_ends_mid_month`는 데이터 종료 월이 부분월이라는 표시이지 해당 월의 나머지 출하량을 0으로 추정했다는 의미가 아닙니다.

## 5. 원본 검증 결과

| 항목 | 결과 |
|---|---:|
| 전체 기록 | **46,836건** |
| 유효 날짜 기록 | **44,886건** |
| 날짜 누락 기록 | **1,950건** (모두 한라봉) |
| 누락 기록 중 물량이 양수인 행 | **816건** |
| 날짜를 배정할 수 없는 물량 | **21,617.86톤** |
| 처리 후 일별 집계 | **7,481행** |
| 처리 후 월별 집계 | **304행** |
| 유효 날짜 출하량 총합 | **2,209,217.71톤** |
| 원자료 날짜 범위 | **2018-01-01 ~ 2025-09-17** |

한라봉의 날짜 누락 1,950건은 날짜를 알 수 없어 연월을 추정해 채우지 않았습니다. 한라봉 월별 출하량을 완전한 통계로 해석하면 안 됩니다. 날짜 누락 기록은 원본에서 동일한 내용이 반복되더라도 각각 다른 날의 기록일 수 있어 임의로 중복 제거하지 않았습니다.

**2025년 9월은 17일까지의 부분 집계**입니다. `data_warning`에 `source_ends_mid_month`가 표시되며, 한라봉은 `unknown_date_rows_excluded_for_variety`가 표시됩니다.

## 6. Agent 활용 시 주의

- 이 데이터는 **2025년 9월까지만** 있으므로 2026년 실시간 출하량으로 사용해서는 안 됩니다.
- 제주 신고소 출하량과 서울가락시장 경매 반입량은 **서로 다른 지표**이므로 단순히 같은 날 합쳐 해석하면 안 됩니다.
- 현재 개인 Agent는 이 출하량 파일을 **사용하지 않습니다**. 후속 분석에서는 `monthly_shipments.csv`의 과거 출하 집중시기 참고 등을 고려할 수 있습니다.
