# 다중 시즌 가격예측 모델 학습 및 사용

작성 기준일: 2026-11-17

## 생성된 모델

다음 로컬 모델 묶음을 실제 학습하고 저장했다.

```text
artifacts/seunghyuk/price_forecast_multiseason/20261116_163408_661649_utc/
```

각 모델은 `HistGradientBoostingRegressor`이며, 같은 규격의 기준일 대비 미래 경락가 변화량을 예측한다. 가격 자료에서 `quality_flag == OK`인 동일 규격 관측쌍만 사용했고, 여러 시즌을 합쳐 79개 학습 규격을 선정했다.

| 예측 간격 | 학습 행 | 규격 수 | 저장 파일 |
|---:|---:|---:|---|
| 3일 | 3,760 | 78 | `candidate_3d.joblib` |
| 7일 | 4,141 | 77 | `candidate_7d.joblib` |
| 10일 | 3,195 | 78 | `candidate_10d.joblib` |
| 14일 | 3,489 | 77 | `candidate_14d.joblib` |

학습에 포함한 가격표는 `data/seasons/2023-2024`, `2024-2025`, `2025-2026`, `2026-2027`이다. 마지막 가격표는 2026-11-13까지다. 학습 데이터의 SHA-256, 피처 순서, 행 수와 모델 버전은 해당 묶음의 `metrics.json`에 기록했다.

## 피처와 데이터허브

입력은 현재 동일 규격 경락가·거래량·거래 건수, 3일·7일 시차 가격, 최근 7일 평균과 물량, 요일·월·시즌 경과일 및 거래 규격 코드다. 제주데이터허브 #855 출하량은 2025-09-17 이후 가격 시즌과 날짜가 겹치지 않아 학습 피처에서 제외했다. 해당 자료는 과거 수급 참고로만 취급한다.

## 추론 실행

프로젝트 루트에서 최신 로컬 모델을 이용해 기준일별 가격 전망을 실행한다.

```powershell
.\.venv\Scripts\python.exe -m experiments.predict_multiseason_forecast `
  --as-of 2026-11-13 `
  --horizons 3 7 10 14
```

기본 예시는 서울가락·온주·특·소·상자 5kg·경매 규격이다. 다른 규격은 `--market-code`, `--variety-code`, `--grade-code`, `--size-code`, `--package`, `--package-kg`, `--trade-type`으로 지정한다. 학습 데이터에서 정상 관측이 충분하지 않은 규격은 추론을 거부한다. 다른 날짜 자료를 쓸 때는 해당 시즌의 `daily_prices.csv`를 `--price-file`로 지정한다.

추론 경로 확인을 위해 2026-11-13 가격표의 온주·특·소 5kg 규격으로 실행했다. 기준가는 2,997.81원/kg이었고, 모델은 네 간격 모두 숫자 예측을 반환했다. 이 입력은 기준일 현재 4일 지난 자료이므로 결과는 역사 재현에 불과하며 현재 출하 판단에 쓰면 안 된다.

| 기준일 | 간격 | 대상일 | 연구용 추정가 |
|---|---:|---|---:|
| 2026-11-13 | 3일 | 2026-11-16 | 3,108.13원/kg |
| 2026-11-13 | 7일 | 2026-11-20 | 3,249.64원/kg |
| 2026-11-13 | 10일 | 2026-11-23 | 3,351.77원/kg |
| 2026-11-13 | 14일 | 2026-11-27 | 3,406.28원/kg |

이 표는 학습된 모델이 실제 규격 입력을 받아 추론한 결과 예시다. 예측 대상일 가격으로 사후 검증한 결과가 아니며, 현재 가격 흐름을 나타내지 않는다.

## 사용 범위

- 모델은 **학습·저장되고 추론까지 실행된다.** 일반 Agent와 UI에는 연결하지 않았다.
- 다중 시즌 검증에서 3일은 개선 신호가 있었지만 신뢰구간이 0을 포함했다. 7·10·14일은 시즌별 성능이 일관되지 않았다. 특히 예측 보고서의 짝비교를 운영 추천 근거로 해석하지 않는다.
- 보정된 예측 구간은 없으며, 경락가 전망은 농가 실수취액이나 최적 출하일과 다르다.
- 모델 파일은 Git에서 제외되는 `artifacts/` 아래에 있다. 다른 작업공간에서 재현하려면 같은 원천 데이터와 Python 의존성을 준비한 뒤 학습 명령을 다시 실행한다.

학습 명령:

```powershell
.\.venv\Scripts\python.exe -m experiments.train_multiseason_forecast
```
