# 제주 감귤 출하 시점 분석 Agent — 베이스라인 기술 설명서

**작성 기준:** 2026년 11월 7일 · **구현 브랜치:** [`seunghyuk`](https://github.com/idenist/jeju-ai-agent-project/tree/seunghyuk) · **발표:** 11월 9일

## 1. 개발 목적

제주 감귤 출하 담당자가 **지금 판매할지, 일정 기간 보관한 뒤 판매할지** 비교할 수 있도록 돕는 의사결정 지원 Agent다. 과거 경락가격과 사용자가 입력한 물량·보관비·감량률로 **지연 출하의 손익분기 단가**를 계산한다. **미래 가격을 예측하거나 출하 시점을 확정적으로 추천하는 시스템은 아니다.**

## 2. 데이터 및 시스템 구조

- **가격 데이터:** 전국 공영도매시장 경매원천정보 API를 전처리한 `data/processed/daily_prices.csv`. 현 단계에서는 **서울가락시장**의 2026년 10월~11월 3일 거래를 사용한다.
- **가격 산출:** 같은 시장·품종·등급·크기·포장중량·거래유형(경매)끼리 비교하며, 단가는 **총낙찰금액 ÷ 총거래중량(kg)**으로 구한다.
- **출하량 데이터:** `daily_shipments.csv`, `monthly_shipments.csv`도 확보했으나 **현재 Agent 계산에는 연결하지 않았다.**

```text
사용자 자연어 질문
    ↓
OpenAI Responses API · LLM (입력 해석 / 도구 선택 / 누락 조건 질문)
    ↓
get_market_price() 또는 compare_shipping()  [Tool Calling]
    ↓
Python 분석 엔진: agents/baseline.py ↔ data/processed/daily_prices.csv
    ↓
Python이 계산값을 직접 표시하는 검증된 결과 보고서
```

| 도구 | 역할 |
|---|---|
| `get_market_price` | 동일 거래 조건의 최근 관측 경락가격·관측일·거래 건수 조회 |
| `compare_shipping` | 가격 조회를 포함해 즉시 출하 매출, 지연 후 물량·보관비, 손익분기 단가 및 사용자 지정 미래 가격 시나리오 계산 |

**기술 구성:** Python, OpenAI SDK(Responses API Function Calling), `python-dotenv`, CSV. `agents/agent.py`가 대화와 도구 호출을, `agents/baseline.py`가 데이터 조회와 수치 계산을 담당한다. LLM이 계산값을 다시 만들어 발생할 수 있는 오차를 막기 위해 **최종 숫자는 Python 도구 결과를 그대로 출력**한다.

## 3. 핵심 계산 및 실제 시연

- **손익분기 단가:** `(물량 × 기준단가 + 보관일수 × 하루 보관비) ÷ [물량 × (1 − 감량률/100)]`
- **지연 출하 차액(미래 가격을 사용자가 지정한 경우):** `지연 후 물량 × 가정가격 − 추가 보관비 − 즉시 출하 가정 매출`

**시연 조건:** 조생귤·특·소·5kg 상자, 물량 3,000kg, 7일 보관, 하루 보관비 20,000원, 전체 감량률 2%.

| 항목 | 실제 출력 |
|---|---:|
| 최근 관측 경락가격 | **2,446.81원/kg** (2026-11-03, 277건) |
| 즉시 출하 가정 매출 | **7,340,424원** |
| 보관 후 물량 / 추가 보관비 | **2,940kg / 140,000원** |
| 손익분기 단가 / 최소 정수 단가 | **2,544.36원/kg / 2,545원/kg** |
| 필요한 가격 상승률 | **3.99%** |
| 7일 후 가격이 2,700원/kg이라는 *사용자 가정*일 때 | **즉시 출하 대비 +457,576원** |

## 4. 검증 결과와 한계

- **검증:** `unittest` 자동 테스트 16개 통과. 실제 OpenAI API에서 자연어 질문 → `compare_shipping` 호출 → 계산 결과 출력 확인. 조건이 부족한 질문에는 등급·규격·보관비·감량률 등을 추가로 요청함.
- **한계:** 경락가격은 농가 실수취가격이 아니며, 관측 범위가 서울가락시장·약 한 달로 제한됨. 미래 가격은 미예측, 보관비·감량률은 사용자 가정이며 공통 비용과 추가 품질 변화는 상세 반영하지 않음.
- **다음 단계:** 11월 9일 세 가지 시연(정상 비교·조건 누락·미래 가격 가정)을 준비하고, 팀 Agent 통합 시 입력·출력 인터페이스를 협의한다.

**한 줄 요약:** *미래 가격을 맞히는 Agent가 아니라, 가격이 얼마나 올라야 기다릴 가치가 있는지를 실제 거래자료와 비용 조건으로 계산하는 Agent.*
