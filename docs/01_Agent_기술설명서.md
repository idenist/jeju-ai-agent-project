# 제주 감귤 출하 시점 분석 Agent — 기술 설명서

**정리 기준:** 2026년 11월 7일 · **구현 브랜치:** `seunghyuk` · **시연 예정:** 11월 9일

> [문서 길잡이](../README.md#문서-읽는-순서) · [02 실행 및 검증](02_Agent_실행_및_검증.md)

## 1. 개발 목적

제주 감귤 출하 담당자가 **지금 판매할지, 일정 기간 보관한 뒤 판매할지** 비교할 수 있도록 돕는 의사결정 지원 Agent입니다. 과거 경락가격과 사용자가 입력한 물량·보관비·감량률로 **지연 출하 손익분기 단가**를 계산합니다.

**미래 가격을 예측하거나 출하 시점을 확정적으로 추천하는 시스템은 아닙니다.**

## 2. 데이터 및 시스템 구조

- **가격 데이터:** 전국 공영도매시장 경매원천정보 API를 전처리한 `data/processed/daily_prices.csv`. 현재 서울가락시장 2026년 10월~11월 3일의 경매거래를 사용합니다.
- **비교 기준:** 같은 시장·품종·등급·크기·포장중량·거래유형(경매)끼리 비교하며, 단가는 **총낙찰금액 ÷ 총거래중량(kg)**으로 산출합니다.
- **출하량 데이터:** `daily_shipments.csv`, `monthly_shipments.csv`도 확보했으나 **현재 이 Agent의 계산에는 연결하지 않았습니다.**

```text
사용자 자연어 질문
    ↓
OpenAI Responses API · LLM (질문 이해 / 도구 선택 / 누락 조건 확인)
    ↓
get_market_price() 또는 compare_shipping() [Function Calling]
    ↓
Python 분석 엔진: agents/baseline.py ↔ data/processed/daily_prices.csv
    ↓
Python이 수치를 직접 표시하는 검증된 결과 보고서
```

| 도구 | 역할 |
|---|---|
| `get_market_price` | 동일 거래 조건의 최근 관측 경락가격·관측일·거래건수 조회 |
| `compare_shipping` | 가격 조회를 포함한 즉시 출하 금액, 지연 후 물량·보관비, 손익분기 단가 및 사용자 지정 미래 가격 시나리오 계산 |

**구현 스택:** Python, OpenAI SDK(Responses API Function Calling), `python-dotenv`, CSV. `agents/agent.py`가 대화 및 도구 호출을, `agents/baseline.py`가 데이터 조회 및 수치 계산을 담당합니다.

**수치 일관성:** LLM이 표시용 반올림 단가로 금액을 다시 계산해 틀리는 것을 방지하기 위해, 도구 호출이 성공하면 **최종 수치를 Python 도구 결과에서 직접 출력**합니다. 추가 정보가 필요한 경우에는 LLM이 질문합니다.

## 3. 핵심 계산 및 시연 결과

**손익분기 단가**

```text
(출하 물량 × 현재 기준가격 + 보관일수 × 하루 추가 보관비)
──────────────────────────────────────────────────
     출하 물량 × (1 − 전체 감량률 / 100)
```

사용자가 미래 가격을 지정한 경우에만 **지연 후 판매 가능 물량 × 가정가격 − 보관비 − 즉시 출하 금액**으로 차액을 계산합니다.

**시연 입력:** 조생귤·특·소·5kg 상자, 3,000kg, 7일 보관, 하루 보관비 20,000원, 누적 감량률 2%.

| 항목 | 실제 출력 |
|---|---:|
| 최근 관측 경락가격 | **2,446.81원/kg** (2026-11-03, 거래 277건) |
| 즉시 출하 가정 매출 | **7,340,424원** |
| 지연 후 물량 / 추가 보관비 | **2,940kg / 140,000원** |
| 지연 출하 손익분기 단가 | **2,544.36원/kg** |
| 원 단위 최소 필요 가격 / 상승률 | **2,545원/kg 이상 / 3.99%** |
| *7일 뒤 가격이 2,700원/kg*이라는 사용자 가정 | **즉시 출하 대비 +457,576원** |

가정가격이 2,700원/kg이라면 계산상 지연 출하가 유리하지만, **이는 예측이 아니라 조건부 시나리오 비교**입니다.

## 4. 검증 및 한계

**확인한 결과**

- `unittest` 자동 테스트 **16개 통과**.
- 실제 OpenAI API를 통한 자연어 입력 → `compare_shipping` 호출 → Python 결과 출력 확인.
- 정보가 부족한 신규 질문에서 필수 조건을 요청하는 흐름 확인.
- 사용자 지정 미래 가격 시나리오와 수치 일관성 검증(표시용 단가 재계산 오류 방지).

**현재 한계**

- 서울가락시장 약 한 달간의 경매자료만 사용하며, 실시간 가격과 농가 실수취가격이 아닙니다.
- 미래 가격을 예측하지 않아 현재/지연 출하의 실제 우열을 확정할 수 없습니다.
- 보관비와 감량률은 사용자의 가정값이며 추가 품질 변화·재선별·추가 운송비 등은 상세히 반영하지 않습니다.
- 현재 보고서는 숫자 정확성을 위해 일부 문장이 고정되어 있으며, 모든 대화 경로의 잘못된 숫자 생성을 보증 차단하는 것은 아닙니다.
- 경매가격 이외의 제주 출하량 전처리 데이터는 현재 이 Agent에 연결하지 않았습니다.

**향후 단계:** 11월 9일 발표 시 정상 분석·입력 누락·미래 가격 가정의 세 가지 흐름을 시연하고, 팀 Agent 통합을 위한 입력·출력 규격을 협의합니다.

**요약:** *미래 가격을 맞히는 Agent가 아니라, 가격이 얼마나 올라야 기다릴 가치가 있는지를 거래 자료와 비용 조건으로 계산하는 Agent입니다.*
