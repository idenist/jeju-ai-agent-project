# 05. 실행 및 테스트 가이드

> **기준:** 2026-11-07 · Windows **CMD** 기준 · [README](../README.md) · [01 기능 명세](01_요구사항_및_기능명세서.md) · [02 설계서](02_시스템_설계서.md)
>
> **이 문서의 역할:** 기존의 베이스라인 실행 안내, Tool Calling 실행 안내, 수치 일관성 수정 설명을 한 곳에 통합했습니다. 과거 ZIP 덮어쓰기 안내는 삭제했습니다.

## 1. 실행 환경

- **Python 3.10 이상** 권장. 프로젝트 루트 `C:\SKN projects\jeju`에서 실행합니다.
- 기존 `test_env`를 쓰는 경우 CMD에서 다음을 실행합니다. Conda가 정상 초기화되지 않았다면 `call` 명령을 사용합니다.

```bat
cd /d "C:\SKN projects\jeju"
call C:\miniconda\Scripts\activate.bat test_env
where python
python -m pip install -r requirements.txt
```

`where python`의 첫 경로가 `C:\miniconda\envs\test_env\python.exe`이면 의도한 환경에서 실행 중입니다.

## 2. `.env`와 인증키

프로젝트 루트에 `.env`를 생성합니다. `agents/` 폴더 아래에 두면 안 됩니다.

```bat
if not exist .env copy .env.example .env
notepad .env
```

내용 예시:

```dotenv
OPENAI_API_KEY=본인이_발급받은_실제_OpenAI_API_키
OPENAI_MODEL=gpt-6-luna
```

- `OPENAI_MODEL`은 계정에서 접근 가능한 실제 모델 ID로 선택합니다. 저장소 예시값이 계정에서 지원되지 않으면 수정합니다.
- `.env`는 **커밋 금지**, `.env.example`만 공유합니다. `.gitignore`에 `.env` 제외 규칙이 있습니다.
- 이미 설정된 **운영체제 환경변수**는 `.env`의 같은 항목보다 우선합니다.
- `DATA_GO_KR_KEY`는 **신규 경매 원본 수집 시에만** 필요합니다. Agent 실행용 `OPENAI_API_KEY`와 다릅니다.
- ChatGPT 구독과 OpenAI API 사용량·요금은 별도입니다.

## 3. 자동 테스트

```bat
python -m unittest discover -s tests -v
```

기존 구현에서 총 **16개 테스트**가 통과했습니다(2026-11-06). 다음 항목을 확인합니다.

| 테스트 파일 | 확인 내용 |
|---|---|
| `tests/test_baseline.py` | 손익분기 계산, 동일 규격 필터, 감량률 예외 |
| `tests/test_agent.py` | 도구 호출 왕복, 실제 가격 CSV 조회, 정보 누락, 오류 결과 |
| `tests/test_env_loading.py` | `.env` 읽기, 기존 환경변수 우선순위 |
| `tests/test_numeric_consistency.py` | 최종 매출·단가·가정가격의 Python 결과 일치, LLM 재계산 오류 방지 |

이 테스트는 **실제 LLM이 모든 표현에서 정확히 행동한다는 보장**이 아니라, Python 계산 및 모의 API 응답 흐름에 대한 검사입니다. 온라인 호출은 별도로 시연 확인합니다.

## 4. Tool Calling Agent 실행

```bat
python agents\agent.py --show-tools
```

`질문>` 프롬프트에 다음을 각각 입력합니다.

**사례 A — 정상 출하 비교**

> 조생귤 특등급 소 크기 5kg 상자 3톤을 가지고 있어. 7일간 보관할 경우 하루 보관비가 2만 원이고 전체 감량률은 2%야. 지금 출하하는 것과 비교해 줘.

**사례 B — 정보 부족** (**새 프로세스를 시작한 뒤** 첫 질문으로 입력)

> 조생귤 3톤을 가지고 있는데, 7일 뒤에 출하하는 게 좋을까?

**사례 C — 사용자 미래 가격 가정**

> 조생귤 특등급 소 크기 5kg 상자 3톤을 7일 보관하고, 하루 보관비는 2만 원, 감량률은 2%야. 7일 뒤 가격이 2,700원/kg이라면 지금 출하하는 것보다 얼마나 이득일까?

**기대 동작:** A는 `compare_shipping`을 호출해 실제 가격과 손익분기 결과 표시. B는 누락된 규격·보관비·감량률을 확인. C는 2,700원을 **사용자 가정가격**으로 취급하고 조건부 차액 표시. B는 LLM 판단에 따라 먼저 조회 도구를 호출할 수 있으며, 임의의 시장 가격이나 입력 조건을 만들어내면 안 됩니다.

단일 질문만 처리하려면 `--question` 옵션을 사용합니다. `exit`, `quit`, `종료`로 대화 종료 가능합니다.

## 5. LLM 없이 계산 엔진만 실행

OpenAI API 키 없이 `agents/baseline.py`를 직접 실행할 수 있습니다.

```bat
python agents\baseline.py --variety 조생귤 --grade 특 --size 소 --package-kg 5 --quantity-kg 3000 --days 7 --storage-cost-per-day 20000 --loss-pct 2
```

옵션: `--future-price-kg 2700`(미래 **가정** 단가), `--current-price-kg 3000`(기준단가 직접 지정), `--as-of 2026-10-23`(관측 기준일 제한). **단가가 미래에 실제로 오를지는 계산하지 않습니다.**

## 6. 시연 기준값 및 수치 일관성

서울가락시장, 2026-11-03 조생귤·특·소·5kg 상자, 물량 3,000kg, 7일 보관, 하루 20,000원, 전체 감량률 2%를 가정합니다.

| 항목 | 예상 결과 |
|---|---:|
| 최근 관측 경락가격 | 2,446.81원/kg (277건) |
| 즉시 출하 가정 매출 | **7,340,424원** |
| 보관 후 물량 | 2,940kg |
| 추가 보관비 | 140,000원 |
| 손익분기 단가 | 2,544.36원/kg |
| 원 단위 최소 필요 단가 | **2,545원/kg 이상** |
| 필요 상승률 | 3.99% |
| 미래 가격 2,700원/kg 가정 시 차액 | **+457,576원** |

**왜 `7,340,430원`이 아닌가?** 표시용 단가 `2,446.81원/kg × 3,000kg`으로 계산하면 7,340,430원이지만, 실제 집계의 `117,667,000원 ÷ 48,090kg`에서 얻은 **반올림 전 단가**를 적용하면 7,340,424원입니다. 최종 출력은 Python 계산 결과를 사용하며 LLM이 단가를 다시 곱해 수정하지 않습니다.

## 7. 오류가 났을 때

| 증상 | 확인 방법 |
|---|---|
| `ModuleNotFoundError` | 활성화된 Python 환경을 `where python`으로 확인하고 `python -m pip install -r requirements.txt` 재실행 |
| `AuthenticationError` / HTTP 401 | `.env`의 OpenAI API 키 확인. 이미 설정된 CMD 환경변수가 우선함 |
| `PermissionDeniedError` / HTTP 403 | API 프로젝트·모델 접근 권한 확인 |
| `RateLimitError` / HTTP 429 | 사용량·요금·호출 제한 확인 |
| CSV 파일 없음 | 프로젝트 최상위 폴더 실행 여부와 `data/processed/daily_prices.csv` 확인 |
| 규격 조회 없음 | 품종·등급·크기·포장중량이 데이터와 일치하는지 확인. 임의로 다른 규격 평균 사용 금지 |

CMD에서 **현재 터미널의 잘못된 API 키**만 지우려면 다음을 사용합니다. 실제 키 값은 대화·이슈·오류 로그에 올리지 마세요.

```bat
set "OPENAI_API_KEY="
python agents\agent.py --show-tools
```

## 8. 신규 데이터 전처리와 검증

기존 `data/processed/` 결과는 저장소에 있으므로 **일반적인 Agent 실행 전에 전처리를 매번 수행할 필요는 없습니다.** 원본을 새로 수집하거나 변경했을 때만 재실행합니다.

```bat
python scripts\preprocess_auction.py
python scripts\preprocess_shipments.py
```

원자료·결측치·품질검증 규칙은 [03 경매가격 데이터 명세서](03_경매가격_데이터_명세서.md), [04 출하량 데이터 명세서](04_제주출하량_데이터_명세서.md)를 참고합니다. 변경 후 테스트를 다시 실행하고 필요하면 품질 보고서도 확인합니다.
