# 감귤 출하 Agent 수치 일관성 수정 안내

## 수정 이유

기존 Tool Calling은 Python이 계산한 결과를 LLM에 전달한 뒤 LLM이 숫자를 포함한 답변을 다시 생성했습니다. 이 과정에서 **표시용 반올림 단가**를 곱해 실제 총금액과 다른 수치가 나올 수 있습니다.

실제 `2026-11-03` 조생귤·특·소·5kg 상자 예시:

- 경매 자료의 총금액: 117,667,000원, 총중량: 48,090kg
- 표시용 가격: 2,446.81원/kg
- 3,000kg의 정확한 가정 매출을 원 단위 반올림: **7,340,424원**
- 표시된 단가만 다시 곱하면 **7,340,430원**이 되어 6원 차이가 발생

## 변경 내용

- `agents/agent.py`만 수정: **LLM은 자연어 질문 해석 및 도구 호출**, **Python은 숫자와 계산 결과를 최종 보고서로 출력**합니다.
- `get_market_price`와 `compare_shipping` 도구가 성공하면 LLM이 생성한 수치 설명 대신, 도구 결과의 필드를 변경하지 않고 최종 보고서에 표시합니다.
- 사용자 질문에 필수 조건이 부족해서 도구를 호출하지 않았다면, 기존처럼 LLM이 추가 질문을 합니다.
- 오류가 발생한 도구 호출의 경우에도 기존 LLM 오류 안내 흐름을 유지합니다.
- 기존 `agents/baseline.py`, `.env`, API 설정, 데이터 CSV는 변경하지 않습니다.

**현재 제한:** 이번 수정은 성공적으로 호출된 두 도구의 숫자 출력만 보호합니다. LLM이 도구 자체를 호출하지 않고 임의의 가격을 주장하는 경우까지 완전히 막는 보증은 아닙니다. 또한 보고서 문장은 고정된 형식이므로 LLM의 자유로운 서술보다 유연성이 낮습니다. 이는 11월 9일 발표용 베이스라인에서 숫자 정확성을 우선한 선택입니다.

## CMD에서 적용 및 테스트

프로젝트 경로: `C:\SKN projects\jeju`

1. 압축 파일의 `agents/agent.py`, `tests/test_numeric_consistency.py`, `docs/수치_일관성_수정_안내.md`를 같은 상대 경로로 복사합니다.
2. **CMD**에서 아래 명령어를 실행합니다.

```bat
cd /d "C:\SKN projects\jeju"

python -m unittest discover -s tests -v
python agents\agent.py --show-tools
```

예시 질문:

> 조생귤 특등급 소 크기 5kg 상자 3톤을 가지고 있어. 7일간 보관할 경우 하루 보관비가 2만 원이고 전체 감량률은 2%야. 지금 출하하는 것과 비교해 줘.

기대 결과는 **즉시 출하 가정 매출 7,340,424원**, **손익분기 가격 2,544.36원/kg**, **원 단위 최소 필요 단가 2,545원/kg 이상**입니다.
