# 제주 감귤 Agent 통합 응답 계약 — 1차

**대상:** `integration/agents` · **적용 단계:** STEP 3-2

## 목적과 범위

승혁님·정현님·준억님 도구의 결과를 공통 구조로 변환합니다. **기존 Agent, 계산기, CSV, 화면은 이번 단계에서 수정하지 않습니다.**

추가 파일: `agents/common/result_contract.py`, `tests/test_integration_result_contract.py`, 이 문서.

## 공통 결과 구조

`normalize_tool_result(tool_name, result)`는 아래 필드가 있는 새 객체를 반환합니다.

| 필드 | 의미 |
|---|---|
| `contract_version` | 응답 형식 버전(현재 1) |
| `tool` | 호출한 Python 도구명 |
| `status` | 공통 처리 상태 |
| `source_status` | 기존 도구에서 사용하던 원래 상태. 상태 필드가 없는 승혁님 도구는 `LEGACY_*`로 구분 |
| `reason` | 원래 세부 오류 사유 또는 명시적인 변환 사유 |
| `message` | 원래 안내 문구 또는 공통 기본 안내 |
| `missing_fields` | 추가 확인할 입력 항목 |
| `warnings` | 원래 경고 및 품질 경고 요약 |
| `cautions` | 원본의 해석 주의사항 |
| `source` | 원래 조회 결과에서 확인된 출처만 사용. 없으면 `null` |
| `data` | **원본 반환값 전체를 복사한 값**. 숫자·근거·선택지·관측일·경고 개수 보존 |

공통 `status`는 `OK`, `NEEDS_INPUT`, `NO_DATA`, `INVALID_INPUT`, `DATA_ERROR`, `PARTIAL`, `CHECK_REQUIRED`입니다. 정산의 `PARTIAL`과 `CHECK_REQUIRED`를 `OK`로 합치면 누락이나 검산 차이를 숨길 수 있으므로 별도 상태로 유지합니다.

## 상태 변환 규칙

| 기존 구현 | 원래 결과 | 공통 상태 |
|---|---|---|
| 준억님 | `OK`, `NEEDS_INPUT`, `NO_DATA`, `INVALID_INPUT`, `DATA_ERROR`, `PARTIAL`, `CHECK_REQUIRED` | 그대로 유지 |
| 준억님 | `NEEDS_CLARIFICATION` | `NEEDS_INPUT` |
| 정현님 | `OK` | `OK` |
| 정현님 | `NEEDS_CLARIFICATION` | `NEEDS_INPUT` |
| 정현님 | `NO_CLEAN_COMPARISON` | `NO_DATA` (경고 있는 비교쌍 개수 보존) |
| 정현님 | `INTERVAL_NOT_AVAILABLE`, `NO_DATA` | `NO_DATA` |
| 정현님 | `AMBIGUOUS_CODES` | `DATA_ERROR` (원천 코드 충돌이며 입력을 임의 수정하지 않음) |
| 정현님 | `ERROR` | `error_kind`가 `INVALID_INPUT`이면 `INVALID_INPUT`, 그 밖에는 `DATA_ERROR` |
| 승혁님 | 가격 조회 성공 / `has_price=False` | `OK` / `NO_DATA` |
| 승혁님 | 정상 손익 결과 | `OK` |
| 승혁님 | 원래 `error`만 있는 반환값 | `DATA_ERROR` (원인이 구조화되지 않았으므로 사용자 오류라고 단정하지 않음) |

알 수 없는 도구명은 거부하고, 알 수 없는 상태나 필수 성공 필드가 빠진 V0 결과는 `DATA_ERROR`로 처리합니다. `source_status`와 `data`를 보존하여 원인을 역추적합니다.

## 해석상 주의

- `NO_CLEAN_COMPARISON`은 *아무 거래도 없다는 뜻이 아니라* **경고 없는 과거 가격쌍이 없다는 뜻**입니다. `data`의 `warning_pairs`, `unavailable_pairs`를 함께 설명해야 합니다.
- `INTERVAL_NOT_AVAILABLE`은 가격이 0% 변했다는 뜻이 아니며, 지원되는 간격은 `data.available_intervals`에서 확인합니다.
- 경매가격은 농가 실수취 단가가 아닙니다. 가격·수수료·감모 숫자를 어댑터가 생성하거나 변경하지 않습니다.
- 어댑터는 입력 객체를 수정하지 않습니다. `data` 필드는 원본 결과를 복사한 것으로, 아직 **모델에 전송할 필드 목록을 제한하는 공개 API가 아닙니다.** 실제 Agent 연결 단계에서는 필요 항목만 공개해야 합니다.
- STEP 3-1의 `verify_price_pair_sources()`는 이번 어댑터에서 **자동 실행되지 않습니다.** STEP 5에서 정현님 가격 조회 도구를 등록하기 전에 먼저 이 버전 검사를 통과하도록 연결해야 합니다.
