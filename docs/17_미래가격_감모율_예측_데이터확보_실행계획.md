# 미래가격·감모율 예측 데이터 확보 및 실행 계획

작성일: 2026-11-17

## 목표

농가에게 미래가격이나 감모율을 추측해서 입력하라고 하지 않는다. 사용자가 알려줄 값은 보유량, 실제 받은 현재 견적, 출하 가능 기간처럼 현장에서 확인할 수 있는 조건이다. 미래가격과 판매 가능한 물량은 확보 자료로 추정하고, 결과에는 근거·불확실성·예측 불가 사유를 함께 표시한다.

## 저장소에서 확인한 현재 상태

### 가격

- `data/seasons/`에 2023-2024, 2024-2025, 2025-2026 전체 시즌 및 2026-2027 일부 시즌의 규격별 일 경락가격 자료가 있다. 2026-2027 자료는 2026-11-13까지다.
- `experiments/train_multiseason_forecast.py`와 `experiments/predict_multiseason_forecast.py`가 있고, `artifacts/seunghyuk/price_forecast_multiseason/`에 3·7·10·14일 모델 파일 2개 묶음이 있다. 둘 다 `FITTED_RESEARCH_ONLY_NOT_DEPLOYED` 상태이며 정상 관측이 확보된 정확 규격 79개를 대상으로 한다.
- 일반 Agent와 UI는 모델을 호출하지 않는다. 추정 구간도 보정되어 있지 않다.
- `docs/14_가격예측_다중시즌_및_출하량_평가.md`의 시간순 평가에서 3일 모델은 최근 7일 평균과 비슷했지만 개선을 확정하지 못했다. 7·10·14일은 여러 시즌에서 기준선을 일관되게 이기지 못했다. 따라서 현재 가격모델을 출하일 추천에 바로 연결하지 않는다.
- 제주데이터허브 #855 CSV의 관측 기간은 2018-01-01~2025-09-17이다. 2023-2024 시즌 124/124일, 2024-2025 시즌 123/124일에 가격 관측과 겹쳐 가격 예측 변수로 시험했지만 안정적인 개선은 확인하지 못했다. 현재 앱은 이 파일을 과거 같은 시기의 신고 출하량을 조회하는 데 사용한다.

### 보관 감량

- 저장소에는 농가별·저장고별 보관 전후 중량, 온도·습도, 부패·등급 하락 기록이 없다. 현재 계산기는 사용자가 준 감모율만 계산에 반영한다.
- 공개 저장시험 논문과 기술자료는 확인했지만, 서로 다른 품종·처리·저장 조건의 제한된 실험값이다. 농가 로트 단위의 반복 관측과 현재 현장 조건을 담은 통합 데이터셋은 아직 확인하지 못했다. 문헌 기록만으로 보편적인 7일·14일 감모 예측 모델을 학습·검증하기는 어렵다.

## 가격 자료 확보

### 우선 원천

1. **기존 시즌별 경매자료**: 현재 모델의 기준 자료다. 원본 행, 자료 해시, 품질 표지를 보존하고 동일 시장·품종·등급·크기·포장·중량·거래방식만 연결한다.
2. **aT 전국 공영도매시장 경매원천 API**: 정산일, 도매시장·법인, 품목 코드, 거래량·가격과 포장·등급·크기 관련 코드를 제공하는 무료 실시간 REST API다. 정확한 일자 단위로 조회하는 형태다. 실제 과거 날짜를 어디까지 받을 수 있는지는 문서만으로 확정되지 않아 승인 후 직접 호출해야 한다. [공공데이터포털 자료 15141810](https://www.data.go.kr/data/15141810/openapi.do)
3. **제주농산물수급관리센터 웹 자료 — 실제 화면과 파일까지 확인**: [온주밀감 일일정보](https://jasdc.or.kr/tangerine/day/day.htm)는 매일 14시 이후 갱신한다고 안내하며, 제주 감귤 출하량의 당일·누계·전년 비교와 9대 도매시장 가격·거래량을 보여준다. [9대 도매시장 가격](https://jasdc.or.kr/tangerine/price/market/market2.htm)은 날짜·품종별 조회와 엑셀 다운로드를 제공하고, [기간별 출하정보](https://jasdc.or.kr/tangerine/shipment/day.htm)는 품종과 날짜 범위를 골라 출하량을 내려받는 화면이다. 2026-11-17 노지온주 페이지는 9개 시장 합계 거래량 788.1톤, 5kg 환산 평균가 11,200원을 표시했다. 이 값은 해당일 시장 요약이지 농가 견적이나 미래 가격이 아니다. 같은 화면에서 엑셀도 내려받아 구조를 확인했다. 파일은 한 시트 `A1:AK45`이며 시장·법인별 거래량, 최고·최저·평균가를 총계와 0.8·3·4·5·6·7.5·9·10kg 상자 규격별로 담는다. 다만 시트에 조회 날짜 열이 없고, 숫자처럼 보이는 값도 문자열로 들어 있으며 `-`가 결측 표기로 쓰인다. 자동 수집 시 조회 날짜를 파일명·메타데이터로 따로 저장하고, 숫자·단위·결측 기호를 정규화해야 한다. 공개 API 주소, 과거 조회 한도, 자동수집·재사용 허용 조건은 아직 확인하지 못했다.
4. **KREI 농업관측 과일 월보**: [공식 과일 관측 목록](https://aglook.krei.re.kr/main/uObserveMonth/OVR0000000013)에서 감귤 관련 월보를 내려받을 수 있다. 공식 안내는 표본 농가 조사와 수급 분석모형, 현장·전문가 자문에 따른 전망이며, 기상·수급 변화에 따라 결과가 달라질 수 있다고 밝힌다. 일별 3~14일 가격 예측의 정답으로 쓰지 않고, 월 단위 시장 전망의 비교 기준 및 가격·출하·작황 배경으로 사용한다.
5. **제주농산물수급관리센터 유통처리 분석 자료집**: [2023년산](https://jasdc.or.kr/community/publish.htm?act=download&no=2&seq=887), [2024년산](https://jasdc.or.kr/community/publish.htm?act=download&no=2&seq=15990) 보고서는 생산·유통·도매시장·품종별 흐름을 연 단위로 정리한다. 긴 계절 맥락과 변수 정의를 보충하는 데 유용하지만, 매일의 가격 경로를 학습하는 자료는 아니다.
6. **KAMIS 등 집계가격**: 규격·조사방법이 경락 원천과 다를 수 있으므로 같은 규격의 학습 표본에 섞지 않는다. 필요하면 시장 전체 흐름을 보여주는 보조 지표로 따로 쓴다.

### #855를 실제로 어떻게 쓸 수 있는가

- 프로젝트의 실제 시간순 평가표에서 #855가 가격과 겹치는 날짜는 2023-2024 124일 전부, 2024-2025 124일 중 123일이다. 2025-2026과 2026-2027에는 겹치는 날짜가 없다. 따라서 “겹치는 과거 자료가 없다”는 설명은 부정확하다.
- 과거 2023-2024로 학습하고 2024-2025를 시험한 결과, 3일 예측에서 #855만 추가한 모델은 날짜 평균 MAE가 최근 7일 평균보다 7.39원/kg 낮았지만, 날짜 단위 95% 신뢰구간이 -47.47~+32.61원/kg으로 0을 포함했다. 7·10·14일에서도 #855가 예측을 확실히 개선했다는 근거는 나오지 않았다. 즉 **데이터를 모델에 넣어 효과를 시험했으며, 현재까지는 유의미한 개선을 입증하지 못했다.**
- 이유 후보는 #855가 제주 출하 신고량이고 가격 자료는 서울 가락시장 경매량이라는 차이, 신고소·품종 분류의 대응 불확실성, 전국 시장의 반입량과 판매가격을 직접 설명하지 않는 점, 학습 시즌이 적다는 점이다. 이것들은 원인으로 확정된 사실이 아니라 다음에 검증할 가설이다.
- #855 갱신은 멈춘 상태이므로 현재 확보한 파일로 과거 출하량을 제공한다. 제주농산물수급관리센터에서 찾은 자료는 별도 원천으로 기록한다. 센터 엑셀을 나중에 활용한다면 조회일·원천 URL을 기록하고 품종·포장 규격·시장·단위를 표준화한다.
- 데이터 이용조건은 따로 확인한다. 제3자 교육데이터 카탈로그에는 #855 라이선스가 `CC-ZERO`라고 표시되지만, 이번 확인은 원 게시자인 제주데이터허브의 공식 페이지에서 해당 표기를 재검증하지 못했다. 저장소의 매니페스트도 개별 원천 조건을 확인해야 한다고 기록한다. 그러므로 카탈로그 표기만으로 제품 배포·CSV 재배포 허용을 확정하지 않고 원 제공처에 확인한다. [제3자 카탈로그 기록](https://data.edmgr.kr/dataView.do?id=jejudatahub-net-855)

### 수집할 필드

정산일, 시장·법인, 품종, 등급, 크기, 포장 및 포장중량, 거래방식, 거래중량, 거래금액 또는 kg당 단가, 거래건수, 원천 품질정보, 수집시각, 원천 파일/API 식별자.

기존 시즌 CSV로 가격 모델을 학습하고 검증했다. aT API 키는 이후 경락 자료의 자동 갱신이나 원본 조회 범위 확장이 필요할 때 발급받는다. 과거 조회 범위는 그때 실제 응답으로 확인한다.

## 감모 데이터 확보

### 확인된 공개 자료와 한계

- 제주특별자치도농업기술원 `2021 노지감귤 재배기술`에는 1994-1995년 흥진조생·상온 저장 기록의 품질 및 감량 자료가 인용되어 있다. 이 표는 저장 시작일·온도·습도·반복 수를 밝히지 않는다. 따라서 **현재 농가의 감모율을 추정하는 모델·기준값·사전확률·백테스트 정답으로 사용하지 않는다.** [`data/research/citrus_storage_reference.csv`](../data/research/citrus_storage_reference.csv)에 남긴 이유는 출처와 옛 관측을 보존하고, 원자료를 기관에 문의할 때 단서를 제공하기 위해서다. [제주농업기술원 자료](https://agri.jeju.go.kr/ebook/technology.htm?act=download&no=1&page=3&seq=50091)
- 추가 검색에서 제주산 저장시험 논문도 확인됐다. 1998년 논문은 제주시 애월 농가의 홍진조생(논문 표기), 55~65mm 과실을 수확해 20일간 약 4% 예조한 뒤 2·4·6℃ 및 상온에서 저장했다. 저온 저장은 상대습도 85±2%였고, 처리당 20과를 15일 간격으로 쟀다. 논문은 90일 무포장 감량을 2℃ 11.8%, 4℃ 7.2%, 6℃ 13.8%, 상온 17.7%로 보고한다. 지역·품종·저장조건이 구체적이라 과거 참고 연구로는 유용하지만, 예조를 포함한 특정 실험이고 7·14일 관측 및 농가 로트별 원자료는 제공하지 않는다. 현재 농가의 예측값으로 직접 쓰지는 않는다. [논문 원문 PDF](https://www.foodengprog.org/download/download_pdf?pid=fep-2-1-42)
- 2020년 연구는 중국 후난성에서 2018년 수확한 Satsuma를 25℃·상대습도 85~90%에서 40일간 보관하고 10일 간격으로 조사했다. 감량은 10·20·30·40일에 2.3·6.3·9.8·11.4%였고, 부패율도 따로 측정했다. 단기 시간대별 관측이 있다는 점은 유용하지만, 제주 농가의 저온·간이 저장과는 품종 세부·지역·저장 조건이 달라 해당 조건의 공개 실험 결과로만 취급한다. [논문 원문](https://www.mdpi.com/1420-3049/25/2/412)
- 기상청 통계에서 제주도 2010년대의 10년 평균기온은 1980년대보다 0.9℃ 높고, 1991-2020년 기후평년값은 1981-2010년보다 0.3℃ 높다. 이는 기후가 달라졌다는 배경 근거이지, 1994-1995 저장시험의 실제 환경을 보여주거나 그 감량율을 현재 값으로 보정해주는 자료는 아니다. 상온 저장과 저온 저장고는 외기 영향도 다르다. [제주지방기상청 기후평년값 비교](https://www.kma.go.kr/kma/servlet/NeoboardProcess?bid=press2&callback=https%3A%2F%2Fwww.kma.go.kr%2Fkma%2Fnews%2Fpress2.jsp&fno=2&k=ATC202103251456472_b253a836-4003-4193-8ddf-854cba60c21f.pdf&mode=download&num=11568&ses=USERSESSION)
- 1999년 제주산 궁천조생 온주밀감 연구 초록에는 3℃·상대습도 90%에서 98일 감량 3.40% 및 부패 3.87%, 같은 온도·습도 85%에서 감량 6.92%, 상온에서 감량 11.87%, 3℃·90%에서 126일 부패 48.75%가 보고되어 있다. 7~14일 중간 관측값과 반복 수가 공개 초록에 없어 [`data/research/citrus_storage_reference.csv`](../data/research/citrus_storage_reference.csv)에서는 문헌 참고값으로만 보존한다. [원 논문 초록](https://koreascience.or.kr/article/JAKO199903043021570.page)
- 제주농업기술원은 2002년의 `눈 맞아 수확한 과실` 저장시험을 최근 관리요령에 다시 싣고 있다. 5~30일 구간의 부패율과 맛·냄새·당도·산함량은 있지만 **중량감소율은 없다.** 눈을 맞은 특수 과실의 품질자료이므로 일반 농가의 감모 예측으로 전용할 수 없다. [`data/research/citrus_quality_storage_reference.csv`](../data/research/citrus_quality_storage_reference.csv)는 이 표를 감모 데이터와 분리해 보존하며 모든 행을 학습 제외로 표시한다. [제주농업기술원 농작물 관리요령](https://agri.jeju.go.kr/files/board/d285a815-dbfa-458e-83cf-4c36373b1199.pdf)
- 제주농업기술원 `농작물 관리요령`은 온주밀감의 예조, 저장조건, 부패율·감모율을 안내한다. 이 자료의 예조 감량은 저장 전 처리에 관한 것으로, 저장 중 순수 중량 손실과 분리해야 한다. [제주농업기술원 자료 PDF](https://agri.jeju.go.kr/files/board/5e332d33-5b04-4c69-bf2c-c282ca1eb545.pdf)

- 2026년 공개된 Owari 연구는 1·3℃ 저장과 온수 처리 조건에서 8주 저장 후 중량감량을 비교한다. 감량이 온도와 전처리에 따라 달랐다는 점은 조건별 관측의 필요성을 보여주지만, 제주 농가의 일반 저장 감모율이나 7·14일 예측치로 옮길 수는 없다. [논문 원문](https://www.mdpi.com/2311-7524/12/3/300)
- 농촌진흥청의 만감류 안내는 특정 품종과 온·습도 관리에 따른 예조·저장 방법이다. 해당 수치를 노지 온주밀감이나 모든 저장고에 그대로 적용하지 않는다. [농촌진흥청 안내](https://www.rda.go.kr/middlePopOpenPopNongsaroDBView.do?no=2177)

### 원자료 요청 및 자체 시험 항목

제주농업기술원 감귤연구센터와 국립원예특작과학원 감귤연구센터에 아래 자료가 있는지 요청한다.

- 원자료 파일(일자별 중량, 부패, 품질 또는 등급 기록)과 자료 이용 조건
- 품종·수확시기·성숙도, 예조 처리, 저장 온도·습도·환기, 포장 형태, 반복 수
- 총 중량감소와 부패·폐기·등급 하락을 구분할 수 있는 기록

사용자가 기관에 바로 보낼 문의 초안:

> 안녕하세요. 제주산 감귤의 출하 시기 의사결정을 돕는 데이터 기반 서비스를 개발하고 있습니다. 공개된 `노지감귤 재배기술`의 저장시험 표와 관련해, 온주밀감의 저장시험 원자료(품종·수확일·예조·저장 시작일·온도·습도·측정일별 중량·부패/폐기·품질/등급)를 제공받거나 열람할 수 있는지 문의드립니다. 연구·서비스 개발에 사용할 수 있는 범위, 출처 표시 방식, 재배포 제한도 함께 알려주시면 감사하겠습니다. 원자료 제공이 어렵다면 관련 보고서·연구자·후속 시험자료를 안내 부탁드립니다.

제주농산물수급관리센터 자료를 별도로 수집할 때는 아래 내용을 문의한다.

> 안녕하세요. 제주 감귤 출하 시점 의사결정 서비스를 위해 센터의 품종별 일일 출하량과 도매시장별 거래량·평균가격 자료를 검토하고 있습니다. 홈페이지의 일일정보 및 엑셀 다운로드 자료에 대해 ① 과거 조회 가능 기간, ② 엑셀 자료의 항목 정의와 기준(가격 단위·수수료 전후·거래량 기준), ③ 공식 API 또는 정기 파일 제공 여부, ④ 자동수집·서비스 화면 표시·원자료 보관 및 재배포 조건, ⑤ #855에 제공된 신고 출하량과 현재 화면 자료의 정의·품종코드가 같은지 확인 부탁드립니다.

원자료를 받을 수 없거나 현재 저장 조건과 맞지 않으면 지역 농가·저장고와 소규모 계측 시험을 시작한다. 상자 또는 로트별 시작 중량을 재고, 저장 중 온도·습도를 자동 기록하며, 정해진 간격으로 총 중량·부패/폐기 중량·판매 가능 등급을 다시 잰다. **수분 증발에 따른 중량 감소**, **부패·폐기**, **품질 하락에 따른 가격 차이**는 서로 다른 결과값으로 저장한다. 농가가 감모율을 추측해 입력하는 대신, 계측한 로트 자료로 추정 모델을 학습한다.

## 모델·서비스 적용 순서

1. **기존 시즌 자료로 가격 모델 평가**. 오늘 가격 유지와 최근 7일 평균, 전년도 같은 시기·규격의 경락가를 비교 기준으로 삼는다. 3·7·10·14일 각각 이후 시즌으로 검증하고 kg당 오차와 예측구간 포함률, 출하 선택에 따른 손익 차이를 확인한다. KREI 전망은 월간 시장 흐름의 참고로 쓴다. 날짜와 규격을 맞출 수 있는 새 자료를 실제로 확보하면 기존 가격 모델과 같은 조건에서 비교한다.
2. **#855를 과거 출하량 조회에 사용**. 앱의 기존 조회로 후보일 주변의 신고 출하량 또는 월별 기록을 보여준다. 출처와 마지막 관측일을 함께 표시한다.
3. **감모 데이터는 별도 실험**: 문헌은 방향·실험 설계의 참고로만 쓴다. 제주 저장고와 농가에서 같은 수확 로트를 저장방식별로 나눠 저장 전, 3일, 7일, 14일의 중량·부패·상품 등급을 잰다. 온도·습도는 센서로 기록하고, 품종·수확일·예조·포장·저장고·통풍 정보를 함께 저장한다. 파일럿으로 변동 폭을 먼저 보고 필요한 표본 수를 정한다. 물리적 수분감량, 부패·폐기, 품질 저하에 따른 등급 하락을 서로 다른 예측 대상으로 둔다.
4. **손익과 추천 연결**: 가격 전망과 실제 상품화 가능 중량을 각각 범위로 계산해 순수익 범위로 결합한다. 보관비 등은 사용자가 알 수 있는 항목만 최소한으로 묻고, 가격·감모를 직접 예측하라고 요구하지 않는다. 범위가 겹쳐 A/B 순위가 안정적이지 않으면 날짜를 찍지 않고, “어느 가격 이상이면 기다릴 만한가” 같은 손익분기 조건과 판단 근거를 보여준다.
5. **Agent 연결**: 사용자는 물량·출하 가능 기간·실제 받은 현재 견적처럼 아는 정보만 말한다. Agent가 먼저 해당 조건에 맞는 가격·공급 자료를 찾고 예측한 뒤, 한 번에 한 가지의 결론을 준다. 가격 예측과 농가 실수취액은 구분하고, 자료 출처·기준일·규격 차이·예측 범위를 표시한다.

## 역할과 필요한 외부 작업

### 내가 저장소에서 이어서 할 일

- 현행 가격 모델이 어떤 규격·날짜에서 실패하는지 평가결과를 제품용 기준으로 요약한다.
- 경락 API 수집기와 원천 보존·중복 제거·품질 검증 구조를 설계하고, 승인된 API 키가 준비되면 연결한다.
- 감모 원자료를 받을 수 있도록 기관에 보낼 자료 요청서와 파일 스키마를 준비한다.
- 수집된 저장시험 자료로 기준선·예측모델·검증을 만들고, 성능이 확인된 경로만 Agent에 연결한다.

### 사용자가 직접 해줘야 하는 일

1. 제주농업기술원 또는 감귤연구센터에서 저장시험 원자료를 받을 수 있는지 문의한다.
2. 자체 시험을 할 경우 협력 농가·저장고를 정하고, 측정 담당자가 로트 중량과 온습도를 기록할 수 있도록 협의한다.
3. 경락 자료 자동 갱신을 시작할 때 공공데이터포털의 aT API 이용을 신청하고, 키를 로컬 `.env` 또는 배포 환경 비밀변수에 등록한다.

## 조사 결과와 다음 액션

### 가격 예측: 연구는 진행 가능하지만, 지금 추천 기능으로 쓰기는 이르다

기존 네 시즌의 경락 자료로 연구용 모델을 이미 학습했다. 기준선 대비 성능 개선이 시즌마다 달라 출하일 추천에는 보류한다. #855는 확보한 기간의 출하 흐름을 보여주는 데 쓴다. 센터에서 확인한 일별 가격 엑셀은 확보한 한 날짜의 시장 요약이며, 과거 날짜 범위와 상품 규격이 확인되면 별도 자료로 검토한다.

### 감모 예측: 지금 공개 문헌만으로 일반 농가 수치를 내는 건 현실적으로 어렵다

1998년 제주 저장시험과 2020년 해외 상온시험처럼 기간별 감량을 기록한 자료는 존재한다. 그러나 품종·수확 시기·온습도·예조·포장과 표본이 다르고, 최근 제주 농가의 실제 로트와 연결된 반복 자료가 없다. 따라서 문헌으로 연구 방향은 세울 수 있지만, 그 수치로 “농가 감귤은 7일 뒤 몇 % 줄어든다”고 서비스에서 예측하는 것은 근거가 부족하다. 감모·부패·상품 등급 자료를 현장에서 같이 재는 파일럿이 필요하다.

### 실제 진행 순서

1. 기존 시즌 경락 자료와 연구용 모델을 바탕으로 가격 전망을 평가한다. 새 데이터가 확보되면 실제로 예측이 개선되는지 비교한다.
2. #855는 기존 화면에서 과거 출하량을 보여주는 데 쓴다.
3. 기술원 또는 감귤연구센터에 저장시험 원자료를 요청한다. 문의문은 위에 있다.
4. 저장고와 협력해 같은 수확 로트를 저장 조건별로 나누고 0·3·7·14일에 측정한다. 측정값의 변동을 보고 본 실험에 필요한 표본 수를 정한다.
