## 1. 실행 환경 및 `.env` 설정 (Windows CMD)

Python 3.10 이상을 권장합니다. **프로젝트 루트**에서 실행합니다.

```bat
cd /d "C:\SKN projects\jeju"

REM Conda 환경을 사용하는 경우 먼저 활성화 (환경명은 본인 설정에 맞게 변경)
conda activate test_env

python -m pip install -r requirements.txt
if not exist .env copy .env.example .env
notepad .env
```

`.env`는 `agents/`가 아니라 **프로젝트 루트**에 둡니다. `.env.example`의 `OPENAI_API_KEY=` 뒤에 OpenAI 플랫폼의 실제 API 키를 입력하고, `OPENAI_MODEL`을 사용할 모델 ID로 지정합니다. 현재 예시 파일은 `gpt-6-luna`를 사용하도록 작성돼 있습니다. 실제 계정에서 접근 가능한 모델을 선택하세요.

- `.env` 및 API 키는 Git에 올리지 않습니다. `.env.example`만 공유합니다.
- 공공데이터포털의 `DATA_GO_KR_KEY`는 **추가 경매자료 수집용**이며 Agent 실행에는 필요하지 않습니다.
- 운영체제에 같은 환경변수가 설정되어 있다면 그 값이 `.env`보다 우선합니다.
- ChatGPT 구독과 OpenAI API 사용료·결제 설정은 별개입니다.

## 2. Agent 실행과 테스트

```bat
python -m unittest discover -s tests -v
python agents\agent.py --show-tools
```

실행 화면의 `질문>`에 아래 예시를 입력합니다.

**사례 A — 정상 출하 비교**

> 조생귤 특등급 소 크기 5kg 상자 3톤을 가지고 있어. 7일간 보관할 경우 하루 보관비가 2만 원이고 전체 감량률은 2%야. 지금 출하하는 것과 비교해 줘.

**사례 B — 정보 누락** (새로 실행한 대화에서 테스트)

> 조생귤 3톤을 가지고 있는데, 7일 뒤에 출하하는 게 좋을까?

**사례 C — 미래 가격 가정**

> 조생귤 특등급 소 크기 5kg 상자 3톤을 7일 보관하고, 하루 보관비는 2만 원, 감량률은 2%야. 7일 뒤 가격이 2,700원/kg이라면 지금 출하하는 것보다 얼마나 이득일까?

**기대 동작:** 사례 A는 `compare_shipping` 호출, B는 부족한 등급·크기·포장 및 보관비·감량률을 요청, C는 **예측이 아닌 사용자 지정 가격 시나리오**로 차액을 계산합니다. B에서 모델이 먼저 조회 도구를 호출할 수는 있으나 데이터에 없는 규격을 임의로 확정하면 안 됩니다.

## 4. Python 계산 엔진만 단독 실행하기

OpenAI API 키나 인터넷 없이 계산 로직을 검증할 수 있습니다.

```bat
python agents\baseline.py --variety 조생귤 --grade 특 --size 소 --package-kg 5 --quantity-kg 3000 --days 7 --storage-cost-per-day 20000 --loss-pct 2
```

선택적으로 `--future-price-kg 2500`, `--current-price-kg 3000`, `--as-of 2026-10-23` 등을 추가할 수 있습니다.

베이스라인은 **손익분기 조건을 계산**할 뿐 미래 가격을 예측하지 않습니다. 가격 비교는 같은 시장·품종·등급·크기·포장중량의 경매 거래만 사용합니다.

## 5. 손익 계산 및 수치 일관성

- 즉시 출하 가정 매출 = **현재 기준가격 × 전체 물량**
- 보관 후 판매 가능 물량 = **전체 물량 × (1 − 누적 감량률/100)**
- 추가 보관비 = **지연일수 × 하루 보관비**
- 손익분기 단가 = **(즉시 출하 가정 매출 + 추가 보관비) ÷ 보관 후 판매 가능 물량**
- 가정가격을 입력했다면 차액 = **보관 후 물량 × 가정가격 − 추가 보관비 − 즉시 출하 가정 매출**

**중요:** 표시용 `2,446.81원/kg × 3,000kg`을 다시 계산하면 **7,340,430원**이 됩니다. 반면 원자료 총금액 `117,667,000원`과 총중량 `48,090kg`에서 계산한 정확한 가정 매출의 원 단위 반올림은 **7,340,424원**입니다. 6원 차이는 **단가 표시 반올림** 때문입니다.

이 문제를 방지하기 위해 **LLM은 질문 해석·도구 선택**, **Python은 수치 계산·최종 숫자 표기**를 담당합니다. 성공한 분석 도구의 결과는 Python에서 고정 형식으로 출력하므로, LLM이 임의로 다시 계산한 금액을 최종 출력에 사용하지 않습니다.

**시연 기준값 (서울가락, 2026-11-03 조생귤·특·소·5kg)**

| 항목 | 기대 결과 |
|---|---:|
| 최근 경락가격 | 2,446.81원/kg |
| 즉시 출하 가정 매출 | **7,340,424원** |
| 7일 뒤 물량 / 추가 보관비 | 2,940kg / 140,000원 |
| 손익분기 단가 | **2,544.36원/kg** |
| 원 단위 최소 단가 | **2,545원/kg 이상** |
| 필요 상승률 | **3.99%** |
| 7일 뒤 가격 2,700원/kg 가정 | **즉시 출하 대비 +457,576원** |

**주의:** 이 보호는 정상적으로 완료된 분석 도구 결과에 적용됩니다. LLM이 아예 도구를 호출하지 않고 응답하는 모든 경우까지 강제로 막는 보장은 아닙니다. 보관비·감량률은 입력 가정이며 경락가격은 농가 실수취가격이 아닙니다.

## 6. 인증 및 실행 오류 해결

- **401 `AuthenticationError`:** OpenAI API 키가 잘못됐거나 취소·만료된 경우 등을 확인합니다.
- **403 `PermissionDeniedError`:** API 프로젝트·모델 접근 권한을 확인합니다.
- **429 `RateLimitError`:** API 사용량 제한·결제 및 크레딧 상태를 확인합니다.
- **키가 맞는데 인증 실패:** `.env`보다 우선하는 CMD 환경변수가 있는지 확인합니다. 현재 CMD에서 기존 값을 지우려면 아래 명령어를 사용합니다.

```bat
set "OPENAI_API_KEY="
python agents\agent.py --show-tools
```

- `.env`를 바꾼 뒤에는 Agent 프로세스를 종료하고 다시 실행합니다.
- `ModuleNotFoundError`가 발생하면 활성화한 Python 환경에서 `python -m pip install -r requirements.txt`를 다시 실행합니다.
- Python 경로를 확인하려면 `where python`을 실행합니다. 가상환경을 선택했다면 해당 환경의 Python이 첫 번째로 나타나야 합니다.

## 7. 검증 범위와 해석상 주의

- 자동 테스트 **16개 통과**, 실제 OpenAI API 연결을 통한 도구 호출·결과 출력 확인(2026-11-06 검증).
- 관측가격의 데이터 종료일은 **2026-11-03**입니다. 이를 실시간 가격이라고 표현하지 않습니다.
- 동일 조건의 정확히 7일 전 데이터가 존재할 때만 과거 7일 가격 변화를 보여줍니다. **과거 변화는 미래 예측이 아닙니다.**
- 손익 비교는 두 출하 방식에 공통인 비용을 제외합니다. 보관으로 달라지는 기타 비용은 현재 자세히 모델링되지 않았습니다.
- '미상' 등급·규격은 원본 데이터의 누락 표기이며 실제 상품 등급을 추정해서 채우면 안 됩니다.
